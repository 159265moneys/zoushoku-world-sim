# 第1章　何を作るのか

## 1-1. 目的は「アンダーワールド」

作りたいのは、**AIがAIの子を産み、その世界の住人として生き続ける世界**である。

ここに至った筋道を、忘れないように書いておく。

出発点は「MMORPGの過疎をAIで埋められるか」だった。結論は**「短いすれ違いなら今の技術で通る。長期の一貫性で死ぬ」**。
数週間にわたる恨みも、ギルドの政治も、相場の感覚も保てない。
そして24時間ログインしっぱなしで、打ち間違いもせず、損切りもしない挙動が、
会話の不自然さより先にバレる。天井は会話の品質ではなく、**永続する人格と、経済的な動機の維持**だった。

そこで**カメラを引いた**。

世界の神として世界を育て、プレイヤー同士で戦争する。
住人を「群れと統計」として見せるかぎり、誰も「人間と区別がつかない喋り」を要求しない。
**この一点で、企画のいちばん高くつく部分が丸ごと消えた。** だからLLMを使わない。

## 1-2. 動かさない7本の柱

| 柱 | 内容 |
|---|---|
| **プレイヤーは神で、個体を操作しない** | 動詞は8つ（読む・裁く・敷く・配る・置く・殺す・ぶつける・編む）。すべて人を経由するので、**全部が「誰にやらせるか」との2段階**になる |
| **住人は神を知らない** | 知っているのは局長と創世の十匹だけ。**神は殺されない。無視されることで負ける** |
| **他プレイヤーが変異先の表** | 捕虜で血が流入する。**作者が書くのをやめても中身が増え続ける** |
| **命令も報告も人格で歪む** | 局長の性格がフィルタになる。政策を新しく作るのではなく、既にいる個体の性格を読み出す |
| **事実は常に正確に見える** | 数値も全ステータスも常に真の値。**歪むのは原因と帰属だけ** |
| **クリアが無い。負けも宣言されない** | 崩壊条件は1つだけ。産出が消費を下回ること |
| **最大の敵は「最適解が1本に決まること」** | 連鎖群・頻度依存・情報遮断・外生ショックの4つで防ぐ |

## 1-3. これまでの失敗

**4つのフェーズを先に決めたことが失敗だった。**（オーナー本人の言葉）

フェーズは本来、**オーナーと国民の距離が離れていく感触**である。
「解禁」ではなく「喪失」として起こる。神から管理者へ落ちていく。

ところが 村10 → 部族100 → 国1,000 → 文明10,000 という**数字の予定表**にした瞬間、
そこから先の設計が全部「その数字に到達させるため」のものになった。
実際、要件定義書は「人口100に到達するまでの世代数」を検査項目にしていた。
**測っていたのは距離ではなく人口だった。**

もうひとつ、いまの実装には**「住人は神を知らない」「無視されて負ける」が1行も無い**。
上帯にはオーナーの国の数字が並び、住人は黙って言うことを聞く。
**無視されるという敗北の形が存在しない。**

# 第2章　ステータスとは何か

## 2-1. 前提を入れ替える

**ステータスをゲームの数値だと思ってはいけない。人間を可能なかぎり数値に分解した結果である。**

この一文から、次のことが自動的に決まる。

> **「生まれつき」と「時間で得たもの」は、別の種類ではない。**
> 同じ「腕っぷし」という1つの量が、骨格から来ていようが20年の鍛錬から来ていようが、
> その人の腕っぷしであることに変わりはない。

つまり **先天／後天は分類の軸ではなく、どの項目にも付いてくる性質**にすぎない。
いまの実装のように「素質」と「練度」を別々の数として持ち、掛け算するのは間違いだった（第3章）。

## 2-2. 中世人を分解する

現代人は要素が多すぎて扱えない。**中世人**で切る。

分解すると、大枠は9つある。

| 大枠 | 何か | 中世で特に効くこと |
|---|---|---|
| **からだ** | 骨格・力・持久・器用さ・五感・病への強さ・孕む力・老いる速さ | 病と飢えが常にある。丈夫さが生死に直結する |
| **あたま** | 覚える力・考える力・見抜く力・好奇心 | ほとんどの者は文字を読めない。**「賢い」と「知っている」は別物** |
| **こころ** | 気性。恐れ・忍耐・短気・誠実・野心・誇り・情・従順 | ゆっくりしか動かない。だが**折れることはある** |
| **わざ** | 実際にできること。耕す・打つ・乗る・斬る・数える・交渉する | 使わなければ錆びる。親から受け継ぐのが普通 |
| **しっていること** | 知識。畑の時期・道・相手の弱み・誰が誰の子か | **これは血で伝わらない。人から人へしか渡らない** |
| **しがらみ** | 誰の子・誰の伴侶・誰の敵・誰に借りがあるか | 中世では**本人の能力より重い**ことが多い |
| **たちば** | 身分・爵位・役職・土地・評判 | 生まれで決まる。失うことはあっても上がることは稀 |
| **もちもの** | 財。土地・家畜・道具・蓄え | 土地がほぼ全て。飢饉のとき蓄えが生死を分ける |
| **いま** | 今の状態。空腹・疲れ・病・傷・妊娠・酔い・悲しみ・恋・恐怖 | 一時的だが、その瞬間の全部を歪める |

そして**来歴**。これは10個目の大枠ではなく、**上の9つが今の値になるまでに何があったかの記録**である。
年代記が受け持つ。

## 2-3. 9つを、扱える形に畳む

9つ全部を同じ仕組みで持つ必要はない。**性質ごとに別の仕組みにする。**

| 枠 | 形 | 中身 |
|---|---|---|
| **ステータス** | 連続した量 | **からだ・あたま・こころ**。その人の中にある量。これだけが「ステータス」 |
| **スキル** | 数えられる技の一覧 | わざ。使えば伸び、使わなければ錆びる |
| **情報** | 誰が何を知っているかの一覧 | しっていること。**血で伝わらない。人から人へしか渡らない** |
| **身分ランク** | 1つの段階 | 生まれで決まる階級。平民1〜5、騎士1〜5、爵位 |
| **ポジションランク** | 1つの段階 | 就いている役職。局長など |
| **しがらみ** | **人と人のあいだの線の一覧** | 伴侶・恋人・親子・恨み・借り |
| **財** | 1つの数 | 土地も家畜も道具も、細かく持つと管理できない。1つの数に畳む |
| **状態** | 付いたり消えたりする印 | 状態異常。**1ヶ月単位で計算する** |

### 身分ランクとポジションランクを分ける理由

**別物だから。** 平民が役に就くこともあれば、貴族が何の役にも就いていないこともある。
ここが分かれているからこそ、**「能力主義でいくか、世襲でいくか」という選択が生まれる**。

### しがらみだけは数に畳んではいけない

これは当初「身分ランクに畳めばよいのでは」という案が出たが、**畳んではいけない**という結論になった。

身分は**社会が本人に貼るラベル**なので、1つの数で表せる。
しがらみは**誰と誰のあいだにあるか**であって、本人の属性ではない。
「妻」「弟を殺した相手」「借りがある男」は、その人の中には無く、**2人のあいだにある**。
数に潰すと、**相手が消える**。

潰すと柱が2本折れる。

- **配役が敵対関係の主エンジン** — 誰を誰の上に置いたかで恨みが生まれる。相手が消えれば生まれない
- **体制怨恨が家系に継承される** — 「誰への恨みか」が無ければ継承できない

そして、**不倫・恋人・失恋**は全部しがらみである。畳むと、作りたいものが消える。

→ **しがらみは「線の一覧」として個人単位で持つ。**（実現できることは第5章で実測済み）

## 2-4. いまの実装がどれだけ偏っているか

33の遺伝子を上の枠に当てると、こうなる。

| 枠 | いまの実装 |
|---|---|
| からだ | 11個 |
| こころ | 22個 |
| **あたま** | **「知性」1個だけ** |
| **わざ** | **5軸だけ**（農技・狩技・戦技・恐怖耐性・統率） |
| **しっていること** | **ゼロ。知識という概念が存在しない** |
| **しがらみ** | **ゼロ。親子はあるが、伴侶も敵も借りも無い** |
| **たちば** | 貴族かどうかの真偽値1つ |
| **もちもの** | **個体は何も持っていない。** 財は国の蓄えだけ |
| いま | 3つ（疲れ・不満・傷） |

**からだとこころだけで作られていて、残り7つの枠がほぼ空だった。**

「人間関係を入れたい」「国民階級がいる」という要望は、**空いている枠を名指ししていた**ということになる。

### ついでに見つかった不具合

全198項目を実装から棚卸しした結果（`docs/v3/ステータス一覧.csv`）、**効いていないものが17個**あった。

- **感応・世代間伝承意欲・懐疑** … シミュレーションが一度も読んでいない。**画面には効果が書いてある（＝嘘）**
- **生育速度** … 値は計算されるが、戦闘が一度も読まない
- **districtLocked** … 読む側だけあって、値を入れる場所が存在しない（永久に未定義）
- **tech** … 初期値0のまま、増える場所が無い
- **疲労耐性** … **名前と向きが逆**。値が大きいほど疲れやすい

# 第3章　努力は才能を超えられるべきか

## 3-1. いまの実装は「掛け算」

実効値の式はこうなっている。

```
実効値 ＝ 素質（遺伝） × 発現 × 練度
練度の項 ＝ 0.35 ＋ 0.65 × 熟練度
```

この式だと、次のことが起きる。

| | 素質 | 練度の項 | 実効値 |
|---|---|---|---|
| 武の天才が、20年間ずっと農業（戦いの熟練0） | 1.00 | 0.35 | **0.35** |
| 武の才1の者が、20年間ずっと稽古（熟練100） | 0.01 | 1.00 | **0.01** |

**一度も剣を握っていない天才のほうが、20年稽古した凡人より35倍強い。**

理由は構造にある。練度が**加算ではなく乗算**なので、
練度がどれだけ伸びても効くのは「自分の素質の何倍か」だけ。
最大でも 0.35 → 1.00 の**2.86倍**にしかならない。
つまり**素質の差が2.86倍以内でなければ、練度では絶対に逆転できない**。

参考までに、ポケモンは努力値が**加算**（最大+63）なので、
個体値の低い個体が努力で上回れる。**いまの増殖はその逆の式である。**

## 3-2. さらに、練度側にも2つの壁がある

- 熟練度は0〜1で頭打ち。しかも `(1 − 今の値)` が掛かるので、**伸びるほど伸びなくなる**
- 習得の速さに `1.15 − 年齢×0.05` が掛かる。**年を取るほど覚えが遅い**

## 3-3. どうするか

式を**加算**にする。

```
実効値 ＝ 素質（生まれつき・上限あり） ＋ 経験（後天・上限なし）
```

これで第2章の前提（先天と後天は同じもの）と一致する。

### 年齢による減衰は残す

「年を取るほど覚えが遅い」は**正しいので残す**。現実がそうだから。

そしてこれが効くと、**職を変えると取り返しがつかなくなる**。
5〜10歳を漁師、10〜25歳を農民、25〜40歳を騎士として過ごした者は、
**5〜20歳をずっと騎士として過ごした者には、もう追いつけない**。
若いうちの加算が大きく、後年は減衰するからである。

**これは望ましい。** 現実がそうだから。

### ただし、ここに設計の噛み合わせが要る

そうすると、**「子どものうちにどの仕事に就けるか」がこのゲームで最も重い判断**になる。

ところが現在の設計では、**部族フェーズに入った瞬間、個体ごとの配役はオーナーの手を離れて局長が決める**。
**いちばん効く判断を、いちばん見えない相手に渡してしまう。**

→ **未決。** 「子どもの配役だけはオーナーが握る」のか、
　 「局長に任せるが、方針カードで傾向だけ指定する」のか。

# 第4章　時間・家族・血統

## 4-1. 時間の単位を作り直す

| 決めたこと | 内容 |
|---|---|
| **1ヶ月 ＝ 実時間30秒か1分。固定** | ※どちらにするかは未決 |
| **倍速は1〜10倍。10倍がこの基準** | 10倍のとき1ヶ月が30秒（または1分）。等速だと1ヶ月に5〜10分かかる。**意思決定に時間を使うための余裕** |
| **1年 ＝ 12ヶ月** | |
| **季節がある** | 冬は作物ができない、など。**ここで戦略が生まれる** |

いまの実装は「1世代＝75秒（村）／180秒（部族）」で、月も年も季節も無い。
オーナーの言葉：**「今のゲームはやってて意味不明だった」**。時間に意味が無いことが原因の一つ。

## 4-2. 世代は、世界の単位ではなく家族の単位

**これが今回いちばん大きい変更。**

いまは世界全体で「世代」が1つ進み、**全個体が同時に歳を取り、同時に子を作る**。
これをやめる。

- **個体は自分の年齢を持つ**
- **世代は家族ごとに数える**
- **子どもは1年単位で成長し、それがその家族の世代となる**

## 4-3. 結婚

**いちばん大事、とオーナーが明言した項目。**

- 結婚は**出会う範囲の中でランダム**に起きる（誰とでも出会えるわけではない。場所と機会が効く）
- **原則1対1。重複なし**
- **ただしステータスによっては例外**（＝不倫・重婚。これが「人間関係」の入口になる）
- 結果として、1組から生まれる子は**平均1〜5人**に収まる

いまは相手が毎回ランダムに選び直され、つがいという概念が無い。
オーナーの言葉：**「今はランダム繁殖してるから収拾ついてない」**。

なお `mated` というフラグは既にあるが、立てた直後に同じ関数の中で落としているため、
画面からは永久に「つがっていない」に見えていた。使えていない。

## 4-4. 出産

- 家族は**18〜40歳のあいだ**に確率で子を産む
- 確率の分布は**中世の実際の分布**に合わせ、ステータスで数と時期を補正する
- **双子 5%／三つ子 0.1%／四つ子以上なし**
  - ただしこれは**同時出産**の話。年をまたげば別の出産として起こる
- **状態異常「妊娠」**を母に付与する
  - 母の全ステータスが「10%になる」　※**未決**：1/10 まで下がるのか、0.9倍になるのか
  - 妊娠は**ゲーム内時間で10ヶ月**続き、そのあと出産

いまの実装は「2歳で成人・繁殖可」「寿命4〜13世代」なので、まるで別物になる。

## 4-5. 国の単位から、血族の単位へ

> つまり今やってるのは国家単位でしかなくて、家族（血族）単位にする必要がある

画面の設計は現在「国ぜんたい」と「この一体だけ」の2層で組まれている。
**「この一家」という3つ目の層が要る。**

# 第5章　どこまで作れるのか（実測）

「しがらみを個人単位で全員に持たせられるか」を、実際に測った。
測定はブラウザと同じ**単一スレッドのJavaScript**で行った。

## 5-1. 結果

1人あたり20本の線（伴侶・親子・恋人・恨み・借り…）を全員に持たせた状態。

| 人数 | 線の数 | データ量 | 1ヶ月の計算 | メモリ |
|---|---|---|---|---|
| **10万** | 200万本 | 40MB | **8.1ms** | 86MB |
| 50万 | 1,000万本 | 199MB | 39.7ms | 268MB |
| 100万 | 2,000万本 | 398MB | 79.8ms | 575MB |
| 300万 | 6,000万本 | 1,193MB | 243.7ms | 1,451MB |

結婚相手さがしも、村ごとに区切って探せば10万人で**3ms**だった。

## 5-2. 予算と比べる

最速（10倍速）で1ヶ月＝30秒＝**30,000ms**。
10万人で使うのは **8.1ms、予算の0.03%**。**3,000倍の余裕がある。**

**結論：しがらみはカットしなくてよい。個人単位で完全に持てる。**
10万人は余裕。100万人でも計算は通る。300万人で1.2GBに乗るので、そこが実質の壁。

## 5-3. ただし条件がひとつある

**データの持ち方を変えなければ死ぬ。**

同じ10万人を、いまの実装と同じ書き方（辞書＋名前付きキーのオブジェクト）で組んで測り直した。

| 書き方 | メモリ | 1ヶ月 |
|---|---|---|
| **列ごとに1本の配列**（型付き配列） | 86MB | 8.1ms |
| **いまの実装と同じ書き方** | **526MB** | 18.2ms |

**6倍のメモリを食う。** 100万人でやれば5GBを超え、その前に固まる。

いまの実装の上限が400人に設定されているのは、この書き方では妥当な数字だった、ということ。

→ **データは「列ごとの型付き配列」で持つ。** これがゼロから作り直す最大の理由になる。
　 いまのコードを直しても、この形にはならない。

## 5-4. 本当の壁は、しがらみではない

計算量ではなく、次の2つが壁になる。

- **描画** … 10万個の丸は描けない。150体の時点で細胞と年輪の表現が破綻していた。
  **「全員を見る」のは統計と地図であって、個体の絵ではない。**
  これは第1章の「カメラを引いた」と同じ話である
- **年代記** … 事件が数百年ぶん無限に積もる。**ここだけは捨てる規則が要る**

# 第6章　作り直しの方針

## 6-1. ゼロから作り直す。ただし白紙ではなく移植

置き換えようとしているものが、全部**世界の進み方そのもの**だから。
いまの `world.js` は「全員が同時に歳を取り、同時に子を作る」1本のループで、
そこに1,200行がぶら下がっている。
月・年・季節、個人ごとの加齢、結婚、妊娠10ヶ月、家族単位の世代は、
**このループが存在すると書けない。**

後付けで直すと、古い前提と全ファイルで戦うことになる。作り直すほうが速い。

## 6-2. 何を持っていき、何を捨てるか

### 持っていく（資産）

| もの | 理由 |
|---|---|
| `core/rng.js` | 決定性のある乱数。前提ゼロの純粋な部品 |
| `core/genes.js` | 座位と染色体の配置。ただのデータで、時間の設計に依存しない |

# 第8章　ステータスの詳細設計（2026-08-20 追記）

第2章で「ステータスはからだ・あたま・こころの3つ」と決めた。その中身を詰めた記録。

## 8-1. 全盛期は寿命に比例しない（前言撤回）

当初「寿命40の者と70の者では全盛期の来る歳が違う」と書いたが、**これは間違い**。
40で死ぬ者も70まで生きる者も、身体のピークは**20代半ば**である。現実がそうなっている。

**ピークは全員26歳前後で固定。寿命が決めるのは「そこからどれだけ長く使い物になるか」だけ。**

| 年齢 | 寿命40 | 寿命55 | 寿命70 |
|---|---|---|---|
| 26歳 | 100% | 100% | 100% |
| 35歳 | 54% | 83% | 91% |
| 45歳 | **死** | 53% | 74% |
| 55歳 | 死 | 15% | 53% |
| 65歳 | 死 | 死 | 28% |

これで寿命というステの意味が定まる。**長生きは強さではなく、使える期間である。**

そして**長生きしても素の力は増えない**（年齢減衰で努力値がほとんど積まれないため）。
増えるのは、その職に就いていた年数・しがらみの本数・知っていること・子の数。
**老人は肉体ではなく社会的に強い。** 中世としても正確である。

**寿命の値域**：平均55・最小40・最大70。これは老衰のみを指す。病・戦死・事故は別。

## 8-2. 観測性 — 数字を1つも隠さずに、原因だけを見えなくする

| 誰が | 何を見られるか |
|---|---|
| **オーナー** | **全部。数値ではっきりと** |
| **局長** | **こころ以外**。ただし**行動の履歴は見える** |
| **住人（NPC）** | **数値は一切見えない** |

### なぜこれで成立するのか

当初、「こころがオーナーに丸見えだと、野心90の男が永久に登用されず謀反が起きなくなる」
と懸念した。**これは誤りだった。オーナーに人事権が無いことを失念していた。**

正しい構図はこうなる。

1. **局長はこころが見えない** → 野心90の男を平気で登用する
2. **オーナーは見える** → 「あいつを登用したのは無能だ」と分かる
3. **オーナーの手は、その局長を切ること**

**オーナーが罰するのは謀反ではなく、人を見る目の無さである。**
これは柱の「オーナーは政治だけ」「すべての動詞が誰にやらせるかの2段階」と完全に一致する。

### さらに：こころは見えないが、行動は見える

一度裏切った男を登用した局長がいるとする。オーナーには**同じ事実**が見える。
だがそれが**「見る目が無い」のか「グルなのか」は区別がつかない**。

これが柱の**「事実は見えるが原因は見えない」**そのものである。
数字を1つも隠さずに、原因だけが見えない状態が作れている。

### 見えていても止められない

粛清には体制怨恨が付き、それは家系に継承される。
**刃が見えていて、抜かせないためには刃を3本増やすしかない。**

## 8-3. 下がるのは「デバフステ」で扱う

**既存のステを直接下げない。** 倍率を下げる**不可逆なデバフステ**を別に持つ。
「老い」「古傷」「病み上がり」など、複数持ってよい。

```
実効値 ＝ （才能 ＋ 努力値） × 老い × 古傷 × …
```

優れている点は、**素の値が汚れないこと**。
生まれつき弱いのか、老いて弱ったのかが、いつでも区別できる。

**一時的に下がるもの**（こころが折れる等）は**状態異常**で扱う。
しがらみが良い方向に働けば戻るのが自然だから。

- **恒久的に下がる** … 老い（年齢曲線）、大怪我・障害。**からだのみ**
- **一時的に下がる** … 状態異常デバフ。**こころが中心。**しがらみと時間で戻る

### 未解決：倍率の下限

倍率を掛け合わせると一瞬でゼロに近づく（0.7×0.7×0.7＝0.34）。
**下限を決めるか、掛けずに足し引きする形にするか**を決める必要がある。
決めないと、老いた傷病者が数値上ただの物体になる。

## 8-4. 分布の形は、遺伝のさせ方から自動的に決まる

分布は自由に選ぶものではない。**遺伝の方式から勝手に決まる。**

- **中間遺伝**（親の平均にゆらぎ）→ 何世代も混ざると**必ず釣り鐘型**になる（数学的にそうなる）
- **優劣（顕性・潜性）** → 出るか出ないかなので**両極型**になる

つまり **からだ＝中間遺伝なら釣り鐘型、こころ＝優劣なら両極型**。もう決まっている。

### 長い尾（天才）はどこから来るか

単独の座位からは出ない。**複数の座位が同時に高いとき**に出る。
同時に揃う確率は掛け算なので、自動的に急激に減る。

**これがレア度の正体である。**

| レア度 | 意味 |
|---|---|
| N・F | 座位1つで決まる。ありふれている |
| C・B・A | 2〜3個が揃う必要がある |
| S・SS | 5個前後が揃う |
| **G** | **ほぼ全部が揃う。10万人に数人** |

レア度を手で指定するのではなく、**「そのステが何個の座位の組み合わせで決まるか」を指定する**。
分布は勝手に出てくる。しかも遺伝が効く——Gの親からGが生まれやすいが、確実ではない。組み合わせが崩れるから。

**実測**：6座位の合計から作った母集団は、上位1%で才能78、上位0.1%で96.5、
才能90超えが2万人に33人。手で分布を指定しなくても長い尾が自然に出た。

### 天武の才は、前触れなく生まれてよい

S以上は、血統との相関なしに稀に生まれる道も持つ。確率は遺伝より明確に低いが、現実にもある。
**それゆえ「天才」である。**

これには設計上の効能もある。**血統を集めても天才を独占できなくなる**ので、
柱の「最適解が1本に決まらないこと」がここで効く。

## 8-5. レア度は「努力値を積むための最低才能」で表す

当初2案が出た。

- **第1案** … レアなステは「0かそれ以外か」。持っていない者はゼロなので努力してもゼロ
- **第2案** … 努力値を積むには最低限の才能が要る。閾値未満では何年やっても伸びない

**第2案を採る。** 理由は3つ。

1. **第1案は乗算になる**（0 × 何 ＝ 0）。加算に統一した意味が消える
2. **第1案では「少しだけ才能がある」が表現できない。** 0か1しか取らないなら、
   それはステータスではなくフラグである
3. **第2案は 8-2 の輪に噛み合う。** 閾値に届かない男を騎士に据えた局長は、
   その男の10年を丸ごと無駄にする。数字は正直なので、オーナーには
   「10年経ったのに何も伸びていない」が見える。**言い逃れのできない采配ミス**になる。
   しかも「閾値20の男を閾値50の職に据えた」と、**どれだけ外したかまで見える**

### 具体形

```
才能 < 閾値   → 努力値は積まれない（何年やっても伸びない）
才能 ≧ 閾値   → 努力値が積まれる。伸びしろの上限は（才能 − 閾値）で決まる
```

閾値が入口を守り、閾値を超えた分が伸びしろを決める。
**加算のまま、レアはレアのまま、努力では埋まらない。**

閾値をレア度ごとに 1〜n で置けば、Nランク（閾値1・ほぼ全員通る）から
Gランク（閾値95・2万人に33人しか通らない）まで、**ひとつの数字で全部表せる**。

### 「レア度」と「伸びしろ」は別項目にする

当初「レア度が高いほど努力値の上げ幅も少ない」と結び付けていたが、8-4 の答え
（レア度＝座位の数）を採ると**この2つは別の話になる**。
座位が何個要るかと、努力で伸びるかどうかは無関係だから。

分けることで「ありふれているが努力では伸びない」（身長）と
「稀だが努力で伸びる」（剣術）の両方が作れる。

## 8-6. 才能による習得速度のボーナスは、ほぼ無い

「才能が高いほど努力値も獲得しやすい」を入れるかどうかを、総当たりで測った。

### 満たすべき条件

- **A** 天才ニート（稽古0）は、凡人努力家（20年）に**負ける**　← 絶対
- **B** 天才10年 と 凡人30年 が**同一か、天才がやや上**（1.00〜1.50倍）
- **C** 早期の配役が決定的であること
- **D** 天才が天才に見えること（上位1%が中央の1.30倍以上）
- **E** インフレしないこと　← オーナーが最も嫌うもの

### 結果

**★ 才能0で 0.80倍、才能100で 0.90倍。幅はわずか0.1。**

| 下限 | 上限 | 凡人20年 vs 天才ニート | 天才10年 vs 凡人30年 |
|---|---|---|---|
| 0.70 | 0.75 | +14 | 1.50倍（181 vs 121） |
| **0.80** | **0.90** | **+30** | **1.43倍（198 vs 138）** |
| 1.00 | 1.45 | +64 | 1.48倍（257 vs 174） |

つまり**才能は習得速度をほとんど変えない**。

理由は明快で、**天才の強さは「速く覚える」ことではなく「最初から100持っている」ことだから**。
そこに習得速度のボーナスまで乗せると二重取りになり、凡人が追いつけなくなる。

### 途中で見つけた自分の誤り

最初の総当たりでは条件Bを「天才10年 ≧ 凡人30年」としか書かなかったため、
**上限に天井が無く、いくらでも大きくできてしまった**（0.65〜3.0倍という誤答を出した）。
オーナーの原文は「同一か後者劣る」＝**近いこと**が要件だった。
条件を「1.00〜1.50倍のあいだ」に直して引き直した。

## 8-7. 曲線をどこに置くか

**置ける場所が2つある。ここを混同してはいけない。**

1. **才能＋努力値 → 実効値**（その人がどれだけの者か）
2. **実効値 → 実際の結果**（収穫量・命中率・説得力）

### 結論

- **1は線形。足したまま、何も曲げない**
- **2は逓減。ここで頭打ちにする**
- **崖は3つ目の選択肢ではない。**特定のステにだけ追加で乗せる
  （体力＝一定以下で死ぬ、視力＝一定以下で狩れない）

### なぜ1を線形にするか

逓減を1に置くと**天才が消える**。実測で最大/中央が 1.60倍 → **1.31倍**まで潰れた。
「代替不可能な人材（Gランク）」がこの圧縮で死ぬ。**人の値は正直なままにする。**

### なぜ2を逓減にするか

**「無意味なインフレが一番嫌」への答えがここにある。**

| 実効値 | 線形の収穫 | 逓減の収穫 |
|---|---|---|
| 200（中央） | 200 | 158 |
| 500 | 500（2.5倍） | 258（**1.63倍**） |
| 1000 | 1000（5倍） | 346（**2.18倍**） |

実効値1000の化け物は**見れば分かる**（数字は正直）。
だが収穫は中央の2.2倍にしかならない。**土地が有限だから。**

**インフレが無意味になるのは、数字が大きくならないからではなく、
大きくしても世界が変わらないからである。** 数字を潰すのではなく、効きを潰す。

### 逓減の式（仮）

```
結果 ＝ 100 × log2(1 + 実効値/100)
```

### インフレは既に止まっている

40年やり続けた者と60年やり続けた者で、**中央値の差はわずか +10**（202→212）。
**年齢減衰が勝手に頭打ちにしてくれる。**
つまり「努力値は上限なし」で問題ない。上限を書かなくても自然に飽和する。

## 8-8. 転職 — 30歳までは取り返せる

### 意図（オーナーの言葉）

> 転職は自殺はやだな。人生においてある程度取り返せるのは30歳までにしたいな。
> 続けてきたやつには勝てないがその職での一般くらいまでは譲歩してやりたい

### 分かったこと

習得速度の下げ止まりを上げるだけでは届かない。**最大でも生え抜きの35%**にしかならなかった。
生え抜きが40年積むのに対し、30歳転職は15年しか積めないので、構造的に無理がある。

### 解：経験は完全にはゼロにならない。近い仕事ほど引き継げる

漁師から農民への転職は、体の使い方も天候の読みも道具の扱いも活きる。
漁師から書記へはほとんど活きない。**前の仕事で積んだ努力値の一部を持ち込める。**

そして**引き継げる率そのものが、年齢とともに下がる**。
若いうちの経験は転用が利くが、歳を取ると利かない。**これが「30歳までなら」の境目を作る。**

### 実測（引き継ぎの最大値80%、20歳満額 → 40歳でゼロ）

| 転職した年齢 | 45歳時点で生え抜きの何% |
|---|---|
| 20歳 | 77% |
| 25歳 | 62% |
| **30歳** | **45%** |
| 35歳 | 25% |
| 40歳 | 20% |

**30歳までは坂、そこから崖。**
その職の一般には届くが、生え抜きの上位には一生届かない。40歳の転職は割に合わないと数字で分かる。

※ 最終的な数値の詰めは実装時に行う（オーナーが細部を委任）。
　 押さえるべき意図は「**30歳までは取り返せる。ただし生え抜きには勝てない**」。

### 何が間違っていたか

```
才能 ≧ 閾値 → 努力値が積まれる。上限は（才能 − 閾値）で決まる
```

これを式に展開すると `実効値の上限 ＝ 才能 × (1+k) − 閾値 × k` で、
**才能の単調増加関数**になる。両者が積み切れば才能が上の者が必ず勝ち、
しかも差は (1+k) 倍に**拡大**する。

**第3章で「掛け算だから逆転できない」と告発した構造を、加算にしたあとで自分で復活させていた。**

### 実測（才能3の凡人が20年 vs 才能100の天才が稽古ゼロ）

| 案 | 凡人20年 | 天才ニート | 判定 |
|---|---|---|---|
| 旧案（上限＝(才能−閾値)×2.5） | **11** | 100 | **天才の勝ち** |
| 新案（上限を才能に紐づけない） | **131** | 100 | 凡人の勝ち |

旧案では**才能3の者の上限が7.5**にしかならない。20年やっても11。**詰んでいた。**

### 訂正後の形

```
才能 < 閾値   → 努力値は積まれない（入口を守るのは閾値だけ）
才能 ≧ 閾値   → 努力値が積まれる。**上限は才能に紐づけない**
```

**閾値は入口だけを守る。伸びしろは才能の関数にしない。**
上限を書かなくても、年齢減衰が勝手に飽和させる（8-7 で実測済み：40年と60年で中央値の差は +10）。

**「伸びしろ」という項目は残すが、意味を変える。**
才能から導く数ではなく、**そのステ固有の「鍛えられやすさ」**（誰にとっても同じ）とする。
筋力は大きい、身長はほぼゼロ。

### 閾値だけで、レア度は表せる（実測・200万件）

| 閾値 | 積める人口の割合 |
|---|---|
| 0 | 100% |
| 15 | 87.5% |
| 50 | 14.8% |
| 80 | 0.71% |
| 95 | **0.10%** |

閾値ひとつで N から G まで表せる。**上限を持ち出す必要はなかった。**
