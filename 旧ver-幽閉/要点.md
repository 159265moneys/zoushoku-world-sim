## これは何のゲームか

- AIがAIの子を産み、その世界の住人として生き続ける世界を作る
- プレイヤーは神。**個体を操作しない**
- 住人は神を知らない。**神は殺されない。無視されて負ける**
- クリアは無い。負けも宣言されない
- 崩壊条件は1つ。**産出が消費を下回る**
- 最大の敵は**最適解が1本に決まること**

- ゼロから作り直す。**ただし移植**
- 残す：乱数／染色体の配置／**遺伝の計算（最重要）**／戦闘の勝敗／用語辞書
- 捨てる：世界のループ／時間・繁殖・加齢／テスト（一度）
- データは**列ごとの型付き配列**。辞書だと6倍メモリを食う
- **上限400人 → 10万人**

## ステータス

- **人間を数値に分解した結果**。ゲームの数値ではない
- **先天と後天は同じ量**。分類の軸ではない
- ステと呼ぶのは **からだ・あたま・こころ** だけ
- 他は別の仕組み：スキル／情報／身分／ポジション／**しがらみ**／財／状態
- **しがらみは数に潰さない**。線の一覧として持つ（潰すと相手が消える）
- **101個確定**（からだ48・あたま24・こころ29）

### 計算

```
実効値 ＝ (才能 ＋ 努力値) × 老い × 古傷 × 状態異常
結果   ＝ 逓減(実効値)
```

- 才能：0〜100。一生不変
- 努力値：**上限なし**。年齢減衰で勝手に飽和する
- 閾値：才能がこれ未満なら**何年やっても伸びない**
- **掛け算をやめた理由**：旧式だと稽古ゼロの天才が、20年稽古した凡人より35倍強かった
- デバフは**倍率**。素の値は下げない（生まれつき弱いのか老いたのか区別するため）

---

## 遺伝

- 分布は**遺伝方式から勝手に決まる**。手で書かない
  - 中間遺伝 → 釣り鐘型（からだ）
  - 優劣 → 両極型（こころ）
- レア度＝**閾値ひとつ**で表せる（閾値95 → 人口の0.10%）
- **連鎖群は必須**
  - 無いと60世代で全ステ99.4／全員が完璧になる
  - 有ると49で止まる。200年回しても動かない
- **育種そのものに代償がある**
  - 1つに振り切ると、残り101ステ中48個が40未満に落ちる
  - 10個狙うと53個が落ちる
  - **狙っていないステまで落ちる**（多様性が失われるため）

## 年齢

- **ピークは全員26歳**。寿命に比例しない
- 寿命が決めるのは**衰えの速さ**だけ
- 寿命 40〜70、平均55（老衰のみ）
- **長生きは強さではなく期間**。素の力は増えない
- 増えるのは：在任年数・しがらみ・知識・子の数。**老人は社会的に強い**

| | 見えるもの |

| オーナー | **全部。数値で** |
| 局長 | **こころ以外**＋行動の履歴 |
| 住人 | 数値は見えない |

- オーナーの権限：**可否・粛清・発掘のみ**
- 発掘した者を局長の指揮下に入れられるが、**配属先は局長が決める**
- **こころが見えても壊れない**：野心と統率が同じ腕なので、忠誠を買うと無能を掴む

## 野心（ここが要）

```
野心 ＝ 素の野心 ＋ 知性が上位20%を超えた分×0.6 ＋ 立場による加算
```

- **立場で加速する。上がるが下がらない**（消えるのは寿命のみ）
- → **オーナーが引き上げた者だけが危険になる。自分で敵を作る**
- 左遷しても野心は消えない。**恨みが増えるだけ**
- → 隔離戦略の答え：**優秀で野心があり恨んでいる集落を、自分の手で作ることになる**

### 当たり：野心ゼロの知者

- 知性上位10%×野心20未満 → **89人に1人**
- 知性上位1% → **いない**
- 局長には「賢い男」としか見えない。**オーナーには当たりだと分かる**
- 逆も起きる。局長が野心90の男を良かれと思って抜擢する
- **守りたいが守れない**：出撃は軍務局長が決める。止めるには引き上げるしかない
- **引き上げれば野心が付く。守ろうとした瞬間に当たりでなくなる**
