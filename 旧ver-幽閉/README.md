## なぜ幽閉したか

**2026-08-26 に事故が起きた。**

土地設計のサブエージェントが `正典-統合ver.md` **だけ**を読み、
`world-sim-design.md` と `game/SPEC.md` にしか書かれていなかった前提
（**敵国はオンラインないしゴーストのプレイヤー／AIは繋ぎ／PvP**）を知らないまま、
**「8人が同じ地図を分け合う共有世界」を自分で発明した。**
それが1,313行ぶん正典に入り、オーナーの決定と正面から衝突した。

**原因は「統合verが抜粋だったこと」と「旧verが半分死んでいたこと」の2つ。**
どちらも、**旧verを残したまま参照させ続けたことから来ている。**

→ **全511節に処分を付け、生きているものを全部移送してから、ここへ閉じた。**
