## sim に期待しているデータ契約

検査器が観測に使っているフィールド。ここが欠けると対応する検査は SKIP になり、AAAの項目が確認できないまま残る。

| 使う場所 | 必要なもの | いま観測できているか |
|---|---|---|
| 劣性の潜伏・近親交配・雑種強勢 | `individual.geno[遺伝子] = [{v,rec,load},{v,rec,load}]`（アレル対）。`model.js` の `genes`（表現型）だけでは潜伏は原理的に測れない | ✅ |
| 近親交配の罰 | `individual.load`（劣性ホモで初めて効く遺伝的荷重） | ❌ |
| 戦死の内訳 90/10 | `individual.deathCause` に `war:stat` / `war:luck` を区別して入れる（または `world.deathTally`） | ✅ |
| 逃走の頻度依存 | `world.battles[] = {gen,n,deaths,stat,luck,routed,fleeFrac}` | ✅ |
| terror の粛清→謀反 | `world.purgeLog[gen]` / `world.rebelLog[gen]` | ✅ |
| merit vs dynastic | `world.bureauLog[] = {gen,bureau,id,house,houseRank,noble}` | ❌ |
| 年代記の遡行 | `event.trueCause`（上流の事件id）と `event.claimed` が別カラム、`trace(world,eventId)` | ✅ |

また以下は `src/core/model.js` の契約に**まだ存在しない**：

- `makeIndividual` は `genes`（表現型 0..1）しか持たない。**優性/劣性の潜伏を表現する場所がない。** AAA-5「心系の劣性が数世代潜伏して発現する」は、アレル対を持たない限り実装も検証も不可能。
- `individual.house` / 家系の識別子がない（merit vs dynastic の透過率検証に必要）。
- `deathCause` の語彙が未定義。テストは `war:stat` / `war:luck` を期待している。
