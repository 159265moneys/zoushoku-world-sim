## 問2. 勝ち筋は何本あるか

### 答え：型は **1本**（クラスタ 5個 → 「同じ型」と判定したものを統合して 1）

**まず「型」の定義**。ここを決めないと数は何とでも言える。

> 型 ＝ **相手ごとの得意不得意のパターン（かたち）**。
> 得意不得意が同じで強さだけ違うのは、別の型ではなく**同じ型の上手い下手**（それは問4で測る）。

上位集合は 32 方針（全 68 中）。
内訳は「どれか1国に対して最上位ティアに入った方針」∪「総合上位15%」。
総合上位だけで切ると、特定の相手にだけ刺さる専門家が落ちて勝ち筋を数え落とす。

各方針を「相手別の成績プロファイルから自分の平均を引いた**かたち**」で表してクラスタリングする。
平均を引かないと、単に強い方針と弱い方針が別の島になって本数が水増しされる。
パラメータ空間で割らないのは、成績に効かない死にカードの違いが型の違いに化けるため。

**クラスタ数の決め方**：シルエット係数の最大。ギャップ統計量は帰無参照の作り方に強く依存して
k が上限に張り付くので、採用には使わず診断として併記する。

```

```

**「本当に違う型か／同じ型のゆらぎか」の検定**

| 検定 | 数字 | 意味 |
|---|---|---|
| 測定誤差の床（実測） | **0.151** | 同じ方針を種の半分ずつで2回測って、かたちがどれだけブレるか。これ以下の差は差ではない |
| クラスタ間/内 距離比 | 0.505 / 0.394 = **1.280** | 1.0 なら島は無い |
| ラベル並べ替え検定 | p = 0.001 | 0.05以上なら k=1（勝ち筋は1本）に落とす |
| シルエット係数 | 0.12 | 0以下＝分かれていない |
| 一つ抜き識別率 | 93.8% | 偶然 20.0% / 多数派 37.5% |
| 同じラベルがパラメータでも分かれるか | 比 0.997 / p = 0.503 | かたちの型が別のカード設定として書けるか |

**クラスタ対ごとの内訳**。「同じ型」と判定して統合する条件は4つ：

```
  S/N < 1.0      重心間の距離が測定誤差の床の内側（そもそも差ではない）
```
