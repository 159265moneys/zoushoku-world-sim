# src/sim — シミュレーション中核

`ui` → `sim` → `core` の一方向依存。sim は DOM も window も `Date.now()` も触らない。
乱数は必ず引数で渡された `core/rng.js` の `RNG` から引く（`Math.random()` は1箇所もない）。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.js` | 公開API。ui と test はここだけを import する |
| `constants.js` | チューニング定数。バランス調整はここだけで済むようにしてある |
| `genetics.js` | 33座位／8染色体。優劣・中間遺伝・交叉・腕予算・遺伝的荷重 |
| `derive.js` | 導出層。実効値／七つの大罪／国民力／戦闘係数／産出・消費 |
| `world.js` | createWorld / stepTick / advanceGeneration / 置く / 読む |
| `chronicle.js` | 年代記。事件レコード・出所・遡行・保持 |
| `cards.js` | 方針カード11枚と、局長の人格による歪み |
| `petitions.js` | 具申の生成と裁定 |
| `battle.js` | 個体単位の戦闘・降伏・捕虜・国境処理・ゴースト |
| `rival.js` | 10の経営思想プロファイルと自動オーナー |
| `roster.js` | 10国を並行に走らせるロスター |

## 実装したもの

### 遺伝

- **心系＝離散の優劣**。対立遺伝子2つを持ち、優性が1つでもあれば劣性は隠れる。
  劣性ホモになった瞬間に潜伏していた値が表に出る。創世時の劣性は極端な値を引きやすくしてあるので、
  数世代潜伏したあと突然発現する挙動が出る（テストで実測できている）。
- **体系＝中間遺伝**。2本の平均＋ゆらぎ。
- **可塑（ch0）が減数分裂の交叉率そのもの**。低い血統は親のコピーに近く、カーストが固まる。
- **対抗アームの予算**。同じ染色体の A/B は `mean(A) + mean(B) = 1.0` に厳密正規化される。
  上限（超えたときだけ縮める）ではなく等式にしてある。上限だと世代を重ねるごとに
  下方ドリフトして1000世代で全員が虚弱になるため。
  **対立遺伝子と表現型の両方に掛ける**——心系はドミナンスで非線形なので、
  対立遺伝子だけ正規化しても表現型では予算を超えられてしまう（実測で染色体単位の違反が出た）。
- **遺伝的荷重**。劣性は「潜伏している値」だけでなく「潜伏している欠陥」も運ぶ（`allele.load`）。
  劣性ホモの座位でだけ発現し、産出・繁殖・戦闘・寿命の全部に掛かる `vitality` になる。
  これがないと劣性ホモ率が上がっても腐りはしないので、近親交配ペナルティも雑種強勢も成立しない。

### 素質・発現・練度

```
実効値 ＝ 素質(遺伝) × 発現(幼少期にその局面に置かれたか) × 練度(環境係数 × 実活動)
```

- **練度は一切遺伝しない。** 子は必ず全練度0で生まれる（テストで親子相関 r=0 を確認）。
- 伸び率は環境が決める：生育地（辺境／中心）・家業（親の役）・貧富（1人あたり食料）。
- 発現は幼少期（age ≤ 1）の2回だけ判定する。逃すと一生開かない。
  辺境で育つと戦の側が勝手に開き、中心部は開きにくい。
- **未発現の素質は `readGene()` がレンジでしか返さない**（真値±10%）。

### 欲求

- 七つの大罪 ＝ 既存遺伝子 × 感受性(8番)。すべてに感受性が掛かる。
- **すべての罪にプラスの出力がある**（怠惰＝長命・疲労耐性、暴食＝飢餓耐性、憤怒＝戦闘力、
  傲慢＝統率、強欲＝産出、嫉妬＝練度、色欲＝繁殖）。潰すと必ず何かを失う。
- 内発／外発は幼少期にその欲が「行為」で満たされたか「報酬」で満たされたかで決まる。
  内発は報酬ゼロでも動く（`unmetBySin` で未充足度が落ちる）。

### 怨恨（2種を分けてある）

| | 宛先 | 消えるか | 実装 |
|---|---|---|---|
| 体制怨恨 | 民衆 → 国 | 消えない。家系に継承 | `ind.regimeGrudge` ＋ `ledger` の出所ごと継承 |
| 個人怨恨 | 個体 → 個体 | 本人の死で消える | `ind.grudges[targetId]`、世代境界で死者分を削除 |

### 戦闘

- 個体単位。集計値の突き合わせはしていない。
- 勝敗は殲滅ではなく**団結の崩壊**。逃走が増えるほど団結が落ち、敗走カスケードになる。
- **逃走癖の頻度依存**：少数なら生き延び、多数だと敗走して逃げた者から死ぬ
  （`ROUT_FLED_DEATH + ROUT_FLED_CROWD × 逃走率`）。逃げた個体は戦功が付かず、
  繁殖機会も落ちる（`chooseMate` の `cowardice` ペナルティ）。
- 戦死は**ステータス由来90% / 完全ランダム10%**。決着後に総戦死数から逆算して
  流れ矢を引く（ラウンド中のHP撃破にだけ運死を付けると、敗走時の追い討ちが母数に入って
  実測2%にしかならなかった）。個体に `deathByLuck` / `deathDetail` が残る。
- 降伏はオーナー裁定。代価は戦況の関数（早く折れば安く、崩壊後は不可）。
  資源が動くのは降伏のときだけ。

### 年代記

- 事件レコードは `trueCause`（真の原因）と `claimed`（公表された帰属）を別カラムで持つ。
- 追跡対象5本（怨恨/民心/産出率/血統/帰属）の増分に原因イベントIDが付き、
  出生時に子へ引き継がれる。だから3世代後の一揆から原因の粛清まで `traceUp` で遡れる。
- 保持は到達可能性。生きている怨恨から辿れる事件は無名の農民の冤罪でも残す。

### 具申

- LLMは使わない。局長の人格ベクトル × 世界状態で11種のテンプレを重み付けし、
  **誰が × 誰を相手に × 何を賭けて**（予算/人材/名誉/命/方針）の積で見え方を散らす。
- 承認しても却下しても必ず誰かに怨恨が積む。無害な選択はない。

### 10国ロスター

プレイヤーの世界とまったく同じ `createWorld` / `advanceGeneration` で走る。
特別扱いは一切していない（同じ遺伝・同じ戦闘・同じ怨恨・同じ具申）。
自動オーナーは8つの動詞のうち **置く・裁く・殺す・敷く** を撃つ。

思想の差が血統の差になる経路は3本だけで、どれもラマルクではなくダーウィン：
1. **繁殖機会** — 地位・実績・オーナーの選好（`mating.prefer`）が交配相手の重みになる
2. **粛清** — 閾値を超えた形質の個体が消える
3. **生存** — 望まれた形質は中心部と良い配給に置かれ、望まれない形質は辺境に送られる

## 実装しなかったもの

SPEC の「v2に入れないもの」に従い、以下は枠だけか未着手：

- 実PvP／国交・亡命／P3・P4／疫病・災害／保因者検査／諜報局・教育局
- 戦争・生産以外の8局面（技術・経済・内政・繁殖・文化・育成・情報）
- オーナーの動詞のうち **配る・殺す・ぶつける・編む** は P3 以降。
  ただしライバル国の恐怖統治と可読性テストに必要なので `purge()` と `setCanon()` は
  実装してあり、UIには出していない
- 諜報水準による年代記の開示段階（`revealed` フラグは持っているが、投資で開く経路がない）
- 護衛は「随伴した体は他の役に就けない・運死が下がる」まで。護衛が身代わりに死ぬ演出はない
- 派閥の実体（関係値グラフのクラスタ）。個人怨恨の辺は持っているがクラスタ化していない

## 既知の穴

1. **8番染色体だけ腕予算の対象外**（`ARM_EXEMPT`）。設計文書上、8番の対抗は
   「感受性が高い／低い」であって「感受性 vs 他責」ではないため。
   ここに予算を掛けると高感受性×高他責＝扇動者という原型が構造的に作れなくなる。
   代わりに `enforceChromosomeCeiling()` が明示規則で「全座位が親2人を上回る」だけを塞いでいる。

2. **創世の二匹と、根付く前の村（人口6未満のP1）は餓死・事故で死なない。**
   個体数2から始める設計上、ここに平常の死亡率を掛けると1/4近くの世界が
   「第1世代でアダムが狩りの事故で死ぬ」で終わっていた。老衰だけは通している。

3. **性比に弱い自己補正がある**（人口24未満のとき）。小さい村で男ばかり生まれると
   次の世代が存在しなくなるため。人口が増えると効かなくなる。

4. **交配は村内婚（`ENDOGAMY`）である。** 成人男性が50人いる村で能力だけを見て
   相手を選ぶと事実上のランダム交配になり、劣性ホモ率が理論下限 q² から動かない。
   実測で閉鎖世界が 0.136、開放世界の下限が 0.1225——**閉じても腐っていなかった**。
   腐っていないものは治らないので雑種強勢も測れない。血の近さ（親子/兄弟=1.0、
   いとこ=0.5、同じ家=0.35）に応じて結ばれやすくし、`inbreedGuard` だけがそれを打ち消す。
   P1（村）では相手が数人しかいないので効かせていない。

5. **`terror` の粛清→謀反は、時間差の特異性までは実測できていない。**
   発生率の差は明確（0.34件/世代 vs laissez 0.006）で、`traceUp` の鎖も平均3世代前の
   粛清まで届いているが、粛清が毎世代一定量あるので lag別相関が平坦になる。
   「3世代後」を統計で示すには、粛清をパルス状に撃つプロファイルが要る。

   粛清はプロファイルの閾値（`purgeTrigger`）を超えたときにまとめて撃つ形にした。
   日程で毎世代撃っていたときは、粛清と謀反の相関が遅れ0〜6世代で完全に平坦になり、
   定常な相関と区別がつかなかった。オーナーは日程ではなく危険が見えたときに殺す、
   という形のほうが設計にも忠実である。

6. **オーナーごとの分化を成立させているのは選択圧3本の合算**（繁殖機会・粛清・生存）。
   200世代のドリフトは選択圧と同程度の大きさなので、選好は1遺伝子ではなく
   6遺伝子のベクトルにしてある。上げすぎると10国が10通りの極端な単一形質国になるので、
   今の重みは妥協点。

7. **近親交配の強さ（`ENDOGAMY`）は2つの検査の間で綱引きになっている。**
   村内婚を強くすると閉じた血統がよく腐る（近親交配・purist vs melting が通る）が、
   同時に遺伝的荷重が戦闘・繁殖に効いて逃走癖の平衡点が動く（頻度依存が揺れる）。
   3.0 が両者のいちばんましな点だが、どちらの検査も種数が3〜5本しかないため、
   閾値付近では乱数列の引き方で PASS と WARN が入れ替わる。
   **係数を動かして緑にするのはノイズへの過適合**なので、機構として根拠のある値で止めてある。

   なお `takeCaptives` は第2引数が RNG のとき `injectOutsideBlood` に委譲する互換経路を持つ
   （戦争を経ずに外来血だけを入れたいとき用）。本来の
   `takeCaptives(world, battle, axis, rng)` の形は変えていない。

8. **土地（`world.land`）は設計文書にない概念。** 産出の上限を決める資源がないと
   人口が発散するか、逆に「余剰がないと開墾できない」デッドロックで必ず絶滅した。
   生産局面の「規模係数（人数による逓増・逓減）」「土地消耗率／地力回復率」に対応させてある。

9. **ロスターの10国は同じ創始者から始まる**（`foundSeed` 固定）。
   国ごとに違う初期遺伝子を振っていたときは、創始者2体のくじ運が思想の差を呑み込んで
   クラスタ内分散 > クラスタ間距離になっていた。対照実験として正しい形にしてあるが、
   プレイヤーの世界は性格診断の回答から作るので、この固定は roster.js の中だけ。
