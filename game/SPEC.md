# 増殖 v2 ビルド契約

`world-sim-design.md`（設計文書）の**フェーズ1＋フェーズ2だけ**を動く形にする。

## プラットフォーム

ブラウザ。**素のESモジュール + Canvas + DOM。バンドラもフレームワークも使わない。**
`python3 -m http.server` で `game/index.html` を開けば動くこと。ビルド手順を増やさない。

## モジュール境界（絶対に越えないこと）

| ディレクトリ | 担当 | 他が触ってよいか |
|---|---|---|
| `src/core/` | **共有契約**（rng / genes / names / model） | 読むだけ。変更は要相談 |
| `src/sim/` | シミュレーション中核 | sim担当のみ書く |
| `src/ui/` `index.html` `style.css` | 画面 | ui担当のみ書く |
| `test/` | ヘッドレス検証 | test担当のみ書く |

**依存の向きは一方向**：`ui` → `sim` → `core`、`test` → `sim` → `core`。
sim は ui を知らない（DOMを触らない、windowを参照しない）。

## 絶対規則

1. **`Math.random()` を書かない。** 乱数は `core/rng.js` の `RNG` のみ。同じ種から同じ歴史が出ること。テストが成立しなくなる。
2. **`Date.now()` に依存した挙動を書かない。** 時間は `world.tick` / `world.gen` で進める。
3. **sim は純粋関数寄りに保つ。** `stepTick(world, rng) -> events[]` の形。描画のための状態を持たない。
4. **LLMを呼ばない。** 具申も報告も名前もテンプレート＋変数で作る。
5. 日本語のコメントでよい。識別子は英数。

## v2 に入れるもの

- 遺伝：33座位／8染色体／心系は優劣・体系は中間遺伝／可塑＝交叉率
- 素質・発現・練度の3項積。**練度は遺伝しない。** 伸び率は環境（生育地・家業・貧富）が決める
- 局面は**戦争と生産のみ**
- P2で3局（軍務・農業・民生）。局長の人格が命令と報告を歪める
- 欲求：七つの大罪を「既存遺伝子 × 感受性」から導出。内発/外発
- 怨恨：**体制怨恨**（消えない・家系に継承）と**個人怨恨**（本人の死で消える）の2種
- 年代記：事件レコード（真の原因／公表された帰属を別カラム）＋増分への原因ID付与
- 戦闘：個体単位。勝敗は殲滅ではなく**団結が折れる崩壊**。サレンダーはオーナー裁定
- 捕虜：P1終了時1体／P2は戦ごとに1〜5体。**勝者は軸を1つ選んで上位プールから抽選、敗者は全プールから抽選**
- 国境処理：誅殺／送還／受け入れ。**外国人は総合値の階級しか見えない**
- 対戦相手は v2 では CPU（ゴースト）

## v2 に入れないもの

実PvP／国交・亡命／残り7局面／疫病・災害／P3・P4／保因者検査／諜報局・教育局

## ビジュアル

- 住人＝**円 ＋ 縦長の目2つ**。それだけ。画像アセットはゼロ
- **色相 ＝ 血統の混合比**（出自。ステータス傾向ではない）
- **彩度 ＝ 練度**（熟練するほど鮮やか）
- **明度 ＝ 体力/年齢**（幼いと明るく、老いると暗い）
- 目：感応が高いほど大きく、恐怖状態では細くなる
- 村＝中心の多角形（辺の数＝発展段階）、資源＝小さい三角

## UI 原則

- **文字入力は一切なし。** すべてクリック。数値はスライダーかステッパー
- 方針は**名前つきカード ＋ 数値パラメータ ＋ オン/オフのトグル**
- オーナーの動詞は8つ：読む／裁く／敷く／配る／置く／殺す／ぶつける／編む
  （v2で解禁されるのは 読む・置く・敷く・裁く まで。配る/殺す/ぶつける/編む はP3以降なので枠だけ）
- **事実は常に正確に見える。歪むのは原因と帰属だけ。**

## 完成の基準（AAA）

1. 種を固定すれば同じ歴史が再現される
2. 1,000世代回して NaN・無限ループ・人口爆発・即死が起きない
3. 逃走癖・私欲・怠惰が集団に固定しない（頻度依存が効いている）
4. 全ステが親2人を上回る子が出ない（連鎖が効いている）
5. 心系の劣性が数世代潜伏して発現する例が観測できる
6. 3世代後の謀反から原因の粛清まで年代記で遡れる
7. P1が5〜10分、P2の1セッションが3〜10分で成立する
8. クリックだけで最初から最後まで通せる
