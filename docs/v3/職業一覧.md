# 職業一覧（中世・規模ごと）

ステの検算に使う。**どの職業からも参照されないステは削る。既存のステで書けない職業があれば足す。**

## 統合の方針

**「それ専門で食っている者がいるか」で判断した。** いない仕事は上位の職に吸収する。

- **水汲み・煮炊き・繕い・子守・パン焼き・醸造** → 家事（村では全部これ）
- **羊飼い・豚飼い・牛飼い** → 牧夫（村では1人が全部見る）
- **炭焼き** → 木こり
- **桶屋・屋根葺き** → 大工
- **紡ぎ手** → 織り（紡ぎは全women の日常作業で職ではない）
- **産婆** → 薬師（村の「賢い女」が両方やる）
- **夜番** → 職ではない。村の男の輪番
- **矢師** → 弓職人
- **鞍職人** → 馬具師
- **石鹸屋** → 蝋燭屋（どちらも獣脂。同じ人がやる）
- **御者** → 運び屋／**質屋** → 両替／**居酒屋** → 宿
- **製紙・製本** → 写本／**公証人** → 書記／**教師** → 学者／**薬剤師** → 医者
- **建築家・井戸掘り** → 技師／**楽師・役者** → 芸人
- **槍兵** → 歩兵／**弩兵** → 射手／**旗手・角笛** → 伝令
- **従軍鍛冶・従軍医** → 職ではない。鍛冶と医者が戦場にいるだけ
- **従士** → 職ではない。騎士になる前の段
- **城代・執事・侍従** → 家令／**造幣・関税** → 財務長官／**諜報** → 監察
- **街道管理** → 駅逓／**修道女** → 修道士／**巡礼案内** → 落とす

# 構造として気づいたこと

## 1. 村の職はほぼ全部が兼業

中世の村で「鍛冶だけで食う」者はいない。**畑を持ちながら鍛冶もする。**
専業が成立するのは町から（市が立って、作ったものを売れるようになるため）。

→ **村では1人が複数の職を持てる**必要がある。町からは専業。
　 **「置く」という動詞の意味が段階で変わる。**

## 2. 職業が現れる順番が、そのまま発展段階になる

- 粉挽き … **水車が要る**
- 両替 … **貨幣が複数種類ある＝交易している**
- 法律家 … **成文の法がある**
- 記録官 … **記録すべき歴史の長さがある**
- 異端審問 … **正統と異端の区別がある＝教義が固まっている**

→ **職業表が技術ツリーを兼ねられる。** 別に技術ツリーを作らなくてよい。

## 3. 国家運営の職は「治める対象」ができて初めて現れる

爵位＝治める土地、と同じ規則。村1つに宰相は要らない。
**役職の数が、そのまま統治の段数になる**（確定事項.md A-19b）。

# 教育機関（2026-08-21 追加）

**このゲームでは構造の中心に来る。** 理由は年齢減衰。
実測で **5〜20歳の15年は、25〜40歳の15年の約3倍**の努力値が積まれる。
**学校はその窓を占有する装置。** 誰をそこに入れるかが生涯を決める。

## 中世の教育は3本の梯子だった

**身分を越える道が3本ある**、というのがこのゲームに効く。

| 梯子 | 段 | 誰が上がれるか | 何が伸びるか |
|---|---|---|---|
| **手仕事** | 徒弟 → 職人 → 親方 | 平民。町の子 | 器用・体で覚える力・見て盗む力 |
| **武** | 小姓 → 従士 → 騎士 | 貴族の次男以下が主。**平民でも武功で入れる** | 筋力・度胸・馬・武具 |
| **聖職** | 学生 → 修道士 → 司祭 → 司教 | **唯一、平民が最上位まで行ける道** | 記憶・論理・言葉・文字 |

**聖職だけが平民から司教まで届く。** 史実でもそうだった。
**「賢いが身分が低い者」の唯一の出口**になる。

## 機関（7）

| 機関 | 規模 | 入れる年齢 | 誰が入れるか | いつ現れるか |
|---|---|---|---|---|
| **修道院学校** | 村・町 | 7歳〜 | 教会に預けられた子。**身分を問わない** | 修道院が建つ |
| **文法学校** | 町 | 7歳〜 | 商人・職人の子。**金が要る** | 町が文字を要る規模になる |
| **司教座聖堂学校** | 都市 | 12歳〜 | 聖職を志す者 | 司教座がある |
| **大学** | 都市 | 14歳〜 | 学費が払える者。**身分より金** | 都市に学者が集まる |
| **騎士の養育** | 貴族の家 | 7歳〜 | 貴族の子。他家に預ける | 騎士がいる |
| **ギルドの徒弟** | 町 | 10歳〜 | 親方が取る。**縁故が要る** | ギルドができる |
| **家庭教師** | 貴族の家 | いつでも | 貴族の子。**女子も含む** | 貴族が金を持つ |

**「他家に預ける」が効く。** 騎士の養育は自分の家では行わない。
**子を預け合うことで、家と家のあいだに線が張られる**（しがらみ）。人質でもある。

## 職（4）

| 職 | 規模 | なぜ要るか |
|---|---|---|
| **教師** | 町・都市 | 学者に統合したのは誤り。**教える者と学ぶ者は別の職** |
| **学寮長** | 都市 | 大学・学校の采配。誰を入れるか |
| **家庭教師** | 貴族の家 | 1対1。**身分の高い子だけが受けられる** |
| **写字生** | 都市 | 写本に統合していたが、**学校の中では独立した仕事** |

## これが設計に効くこと

### 1. 情報の枠が、初めて量を運べるようになる

**徒弟は1対1、学校は1対多。** 知識を大量に転送できる唯一の装置。
「情報は血で伝わらない。人から人へしか渡らない」と決めたので、
**渡す速さが機関の有無で決まる**ことになる。

### 2. 「早期配役が決定的」の受け皿になる

加算＋年齢減衰にした結果、子どものうちにどこへ置くかが生涯を決める。
**学校はその選択肢そのもの。** 畑に置くか、学校に入れるか。

### 3. 身分と能力の分かれ目が、入学の条件になる

- 修道院学校＝**身分を問わない**
- 文法学校＝**金が要る**
- 大学＝**身分より金**
- 騎士の養育＝**身分が要る**
- 徒弟＝**縁故が要る**

**「誰を入れるか」が世襲と能力主義の分岐点**になる。
オーナーの透過率（能力主義の度合い）が、ここで具体的な形を持つ。

### 4. 異端審問の前提が揃う

**教義がどこで固まるのか**が無いまま異端審問を置いていた。
司教座聖堂学校と大学が**正統を定義する場所**になる。

### 5. 学校を持てない村は、永久に賢くなれない

村13職には教育機関が無い（修道院学校だけが届きうる）。
**町にならないと文法学校が建たない。**
これが「村に留まる」という選択の代償になる。
