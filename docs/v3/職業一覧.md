# 職業一覧

ステの検算に使う。**どの職からも参照されないステは削る。既存のステで書けない職があれば足す。**

---

## 解像度の決まり

**「この職と別の職で、使うステが明確に違うか」で分ける。違わないなら統合する。**

- 刃物鍛冶・甲冑師・蹄鉄工・鋳物 → **同じステ（火・金属・腕力・手先）なので「鍛冶」1つ**
- 鍛冶と大工 → **違う（火と金属 vs 木と寸法）ので分ける**
- 渡し守・橋守・道普請・御者・荷運び → **「物を運ぶ職」「人を運ぶ職」の2つ**
- 隊商・関所・通訳 → **商人と行商に吸収**

歴史的な職名を並べない。**機能で括る。**

# 教育機関（7）と3本の梯子

**このゲームでは構造の中心。** 実測で **5〜20歳の15年は、25〜40歳の15年の約3倍**の努力値が積まれる。
**学校はその窓を占有する装置。**

## 3本の梯子

| 梯子 | 段 | 誰が上がれるか |
|---|---|---|
| **手仕事** | 徒弟 → 職人 → 親方 | 平民。**縁故が要る** |
| **武** | 小姓 → 従士 → 騎士 | 貴族が主。**平民でも武功で入れる** |
| **聖職** | 学生 → 修道士 → 司祭 → 司教 | **唯一、平民が最上位まで行ける道** |

**聖職だけが平民から司教まで届く。「賢いが身分が低い者」の唯一の出口。**

**「他家に預ける」が効く。** 騎士の養育は自分の家では行わない。
**子を預け合うことで家と家に線が張られる**（しがらみ）。**人質でもある。**

# 設計に効くこと

1. **鉱業が技術ツリーの根。** 鉄→鍛冶→武具。銀→貨幣→両替。塩→保存→冬を越す
2. **運ぶ職が「出会う範囲」を広げる。** 道が通れば隣村と縁組できる＝血が混ざる
3. **吟遊詩人が情報の枠を実装する。** 情報が人から人へ渡る経路の具体
4. **汚物処理が疫病を実装する。**「純血国は疫病で壊滅する」の前提条件
5. **死刑執行人が粛清の実行者。** 世襲の外れ者で、恨みの結節点
6. **賭博・風呂屋・祭りが、しがらみの生まれる場**
7. **学校の入学条件が、世襲と能力主義の分岐点。** オーナーの透過率がここで形を持つ
8. **職業表が技術ツリーを兼ねる。** 水車・貨幣・成文法・教義が、職の出現条件になっている
9. **村には修道院学校しか届かない。** 町にならないと賢い子を伸ばせない＝村に留まる代償
