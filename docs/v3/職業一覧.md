# 職業一覧（中世・規模ごと）

ステの検算に使う。**どの職業からも参照されないステは削る。既存のステで書けない職業があれば足す。**

## 統合の方針

**「それ専門で食っている者がいるか」で判断した。** いない仕事は上位の職に吸収する。

- **水汲み・煮炊き・繕い・子守・パン焼き・醸造** → 家事（村では全部これ）
- **羊飼い・豚飼い・牛飼い** → 牧夫（村では1人が全部見る）
- **炭焼き** → 木こり
- **桶屋・屋根葺き** → 大工
- **紡ぎ手** → 織り（紡ぎは全women の日常作業で職ではない）
- **産婆** → 薬師（村の「賢い女」が両方やる）
- **夜番** → 職ではない。村の男の輪番
- **矢師** → 弓職人
- **鞍職人** → 馬具師
- **石鹸屋** → 蝋燭屋（どちらも獣脂。同じ人がやる）
- **御者** → 運び屋／**質屋** → 両替／**居酒屋** → 宿
- **製紙・製本** → 写本／**公証人** → 書記／**教師** → 学者／**薬剤師** → 医者
- **建築家・井戸掘り** → 技師／**楽師・役者** → 芸人
- **槍兵** → 歩兵／**弩兵** → 射手／**旗手・角笛** → 伝令
- **従軍鍛冶・従軍医** → 職ではない。鍛冶と医者が戦場にいるだけ
- **従士** → 職ではない。騎士になる前の段
- **城代・執事・侍従** → 家令／**造幣・関税** → 財務長官／**諜報** → 監察
- **街道管理** → 駅逓／**修道女** → 修道士／**巡礼案内** → 落とす

# 構造として気づいたこと

## 1. 村の職はほぼ全部が兼業

中世の村で「鍛冶だけで食う」者はいない。**畑を持ちながら鍛冶もする。**
専業が成立するのは町から（市が立って、作ったものを売れるようになるため）。

→ **村では1人が複数の職を持てる**必要がある。町からは専業。
　 **「置く」という動詞の意味が段階で変わる。**

## 2. 職業が現れる順番が、そのまま発展段階になる

- 粉挽き … **水車が要る**
- 両替 … **貨幣が複数種類ある＝交易している**
- 法律家 … **成文の法がある**
- 記録官 … **記録すべき歴史の長さがある**
- 異端審問 … **正統と異端の区別がある＝教義が固まっている**

→ **職業表が技術ツリーを兼ねられる。** 別に技術ツリーを作らなくてよい。

## 3. 国家運営の職は「治める対象」ができて初めて現れる

爵位＝治める土地、と同じ規則。村1つに宰相は要らない。
**役職の数が、そのまま統治の段数になる**（確定事項.md A-19b）。
