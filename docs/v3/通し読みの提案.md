## Q-01　[時間軸／確信]　拠点は永久に1村のまま。段5以上は算術的に到達不能で、95職の80%が一度も生えない

**場所**：正典-統合ver.md L6389（#17 6-1）「**拠点 ＝ 中心間 3.5里以内で連結した村の集合（連結成分）**」／L6393「親から3.5里以内に落ちた子村は同じ拠点に入る」／L4796（#11-B 3.）「r = 4 + rng.f32() × 2   里（4〜6里）」／L6400「発展度 ＝ 暮らし向き × ln(拠点の総人数)」／L6395-6402（#17 6-2 段の閾値表）／L433（3-6b）「職業一覧の「家／村／町／都市」の4区分が、そのまま 1-2／2-3／4-5／6-7 に乗る。」

**問題**

分村の距離 r は下限4里で、r が縮む経路が11-Bに存在しない（失敗時は θ+=40°、それでも駄目なら r+=2 で伸びるだけ）。だから親子の村は必ず4里以上離れ、3.5里以内の連結は一度も成立しない。拠点は常に1村＝最大100人（30軒）。

「離す」           r = 4   + rng.f32() × 2    （現行のまま）→ 新しい拠点になる
★ 最小間隔3里（11-B 4.）は1文字も変えない。3.0里 ＝ 12区画
★ claim 半径は 0.5里（2区画）でも 0.6里（2.4区画）でも、2×2.4=4.8 < 12 なので
  どちらに転んでも claim 円は重ならない。Voronoi の分岐は発火しない（未決4件目に依存しない）
★ #17 6-1 の連結半径3.5里は動かさない

代金は既存の機構がそのまま取る（新しい定数ゼロ）：

検算：50村を寄せた首都＝5,000人 → ln=8.52 → 段7に要る暮らし向き **55.2**（天井73の中）。18村＝1,800人の大都市 → ln=7.50 → 段6に **45.3**。6村＝600人の都市 → ln=6.40 → 段5に **36.0**。#17 6-2 の表の村数の目安（段5=6〜18村／段7=50村〜）と完全に噛み合う。「離す」を選んだ国には 3-6b の「でかい村が並ぶだけ」が正しく起きる。

## Q-04　[時間軸／確信]　暮らし向きを上げるカードが100枚のどこにも無い。既定は −0.3/月なので、放置すれば暮らし向きは0に張り付き、段は永久に1のまま

**問題**

そのうえ、実装されたとしても縮尺が壊れている：
```
場が1つ立つ      → +1.0／月（要る人手 1人）
働き手10%を割く  → +0.5／月（55人の村で 5.5人）
→ 人手1人あたりで **場は労働の20倍効く**
```
場は #17 6-3 が「実際に立っている場の職の種類数（風呂屋・賭博・醸造・音楽家・俳優・剣闘士・給仕）」と定義しているので、7職＝7人＝働き手の12.7%で **+7.0/月**。同じ7人を「割く」に回すと +0.635/月。**「割く」というレバーは、場を1つ立てた瞬間に死ぬ。**3-6b L455「暮らし向きを上げるには物と場に人手と資源を割く必要があり、それは食料と武器に回らない」という代償が丸ごと無効になる。

**提案**

**1. 場を「速さ」から「天井」へ移す。**
```
天井 ＝ clamp(0, 100,  食の幅 × 5 ＋ 物の幅 × 3 ＋ **場の数 × 4** )
        上限 ＝ 8×5 + 11×3 + 7×4 ＝ 101 → clamp 100
実値 ← 毎月、天井に向かって   + 0.5 × (割いた働き手の割合 ÷ 0.10) − 0.3
```
これで「場は、どこまで上げられるかを決める」「人手は、上げる速さを決める」に分かれる。
検算（場7・食6・物5 → 天井73）：10%割いて +0.2/月 → 0から73まで365ヶ月＝30年。20%で +0.7/月 → 104ヶ月＝8.7年。割かなければ −0.3/月 で痩せる。**代償が復活する。**

**2. カードを実在させる。商会の10枚を組み替える（枚数は10のまま）。**
```
商会「分配」        → 「配給か市か」（3-6d の方針カード1枚。プリセット2択）に名前を確定
商会「賭博の黙認」   → 「**暮らし向きに割く働き手 0/10/20%**」既定10% に差し替え
                      （賭博は #17 6-3 の「場の職」なので、生えるかどうかは段と職で決まる。
                        カードで黙認/禁止を切るレバーは要らない）
#18 の村・街のつまみにも同名の1本を置き、継承（村←街←国）が親カードIDで通るようにする（P-15）
```

**代金**：商会10枚のうち1枚を差し替え、1枚の名前を確定。#17 6-3 の式2行を書き換え。3-6c の場の定義を #17 6-3 の7職に一本化（3-6c の「宴・祭り」は 祭祀局の「祭りの回数」カードが立てる場として7職の中に吸収）。#17 6-2 の段の閾値（40/95/145/230/340/470）は天井の上限が73→100に上がるぶん余裕ができるだけで、下げる必要は無い。壊す測定値ゼロ（暮らし向きは未実測）。
