（論理＝「＋場を読むが低い→正しいことを最悪の場で言い、味方まで敵に回す」／
場を読む＝「＋論理→正しさと場の空気が食い違うたびに黙るので本人が内側から壊れていく」）

## 直せなかった矛盾（設計の判断が要る）

### 1. 場を読む の対を「なし」にしてよいか（上の修正1の裏）

論理は**2つの敵**を持っている（体で覚える力／場を読む）が、列は1つしか持てない。
片方を落とすしかなかった。

**別の解が2つある。判断を仰ぎたい。**

- **案A（採用中）**：場を読む＝「なし」。6番の軸は 学者↔職人 のまま
- **案B**：場を読む ↔ 数の感覚。数の感覚の行は「数で言うので信用されない。理屈屋として嫌われる」と
  書いており、場を読むの「言ってよいことが分かる」の正反対になる。ただし**割り付け側に根拠が無い**
- **案C**：101ステを増やさずに、論理を2つの対に分けられる列（対になるステを複数可にする）を足す

**案Aを採ったのは、割り付け側の軸の定義を壊さないため。** 意味の損失は無い（敵対は相互関係の欄に残る）。

### 2. 「対を作れなかったステ」の数が 30 → **31** に増えた

`染色体の割り付け.md` は30個と書いており、内訳を「からだ21・あたま8・こころ1」としている。
修正1で場を読むが加わったので、**正しくは31個（からだ21・あたま9・こころ1）。**

**割り付け側の2つのファイルが、この1本化と食い違ったまま残っている。**

- `染色体の割り付け.md`：貼り付け用ブロックの `場を読む,6番,B,論理` と、
  「対を作れなかったステ（30個）」の表・内訳
- `ステ定義v2-あたま.csv`：場を読むの行の「対になるステ」

**私は他班の成果物を書き換えなかった。** 再び1本化するときに元の非相互が戻るので、
どちらを正とするか決めたうえで同期が要る。

### 3. 「相互関係」欄の書き方が、からだ と あたま・こころ で違う

| ファイル | 書き方 |
|---|---|
| **からだ49行** | 「弁舌も高いと大勢を一度に動かせる。」（地の文。句点で終わる） |
| **あたま23行・こころ29行** | 「＋弁舌→人を集められるので局長候補になる」（＋名前→ 形式） |

**内容は正しい。** からだの183件の参照も全部実在するステ名で、抜けも誤りも無かった。
だが**機械で読むなら形式が2つあるのは負債**（ホバー説明の自動生成、相互関係の自動リンクで詰まる）。

**直さなかった理由**：98文の文体を書き換えることになり、意味を削る事故のほうが高くつく。
**どちらの形式に寄せるか決めてもらえれば、機械的に揃える。**

### 4. あたま の中項目に「その他」が5件ある

`段取り` `機転` `観察` `集中` `学習速度` の5つ。
からだ（力・速さ・体つき・五感…）とこころ（欲する・立ち向かう・揺れる…）は意味のある名前が付いている。

**推測で名前を付けなかった。** あたまの中項目は現状 覚える7／考える5／人を読む4／伝える2／その他5。

### 5. 「自信の無い割り付け」が10件、割り付け側で未解決のまま乗っている

`染色体の割り付け.md` が自己申告している。**この1本化では判断しなかった**（割り付けを動かす権限の話なので）。
特に効くのは次の3つ。

- **5番「目 ↔ 耳と喉」に根拠が無い。** 割り付け側が解体案（視力・色の見分け・夜目→3番B、
  聴力・三半規管→1番B、声→1番A）を出しているが、1番が19座位になるので保留。
  **声もここに巻き込まれる**（依存先の息の長さ・肩幅が1番なのに本体は5番）
- **学習速度が全ステに掛かる唯一の乗数なのに、7番B腕に載せてある。**
  乗数ステを連鎖に載せたときに何が起きるかは実測されていない。**収束計で最初に見るべき箇所**
- **10番A腕の「誇り」が統率素質の代役。** `確定事項.md` A-7 の
  「野心を弾くと統率も一緒に落ちる」の実体が、統率素質という名前が101に無いため誇りで代用されている。
  統率素質を102個目として足すなら席は10番A腕。**足すかどうかは誰も決めていない**
