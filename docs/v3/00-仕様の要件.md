# 4章 フェーズ2「部族」

## 4-1 何が起きるフェーズか

| ID | 要件 | 出典 |
|---|---|---|
| **R-301** | 人口 10 → 100。 | 設計 573 |
| **R-302** | **P2は外来血の流入で幕を開ける。** 100体になるまでに何度も戦争するので、通過し終わった村は自国産の血のほうが少ない可能性がある。 | 設計 582 |
| **R-303** | 転換は「解禁」ではなく **「喪失」** として起こす。獲得ではなく剥奪として体験させる。 | 設計 567 |
| **R-304** | P2でオーナーが失うのは **直接配役**（配役ボタンが消える）。もう手で置けないので代理人を立てるしかない。 | 設計 1339 / 567 ※付録A-1 参照 |
| **R-305** | P2で起動するもの：**外来血の流入 / 局が3つ / 家系の分岐 / 透過率**。 | 設計 573 |
| **R-306** | P2の3局は **軍務・農業・民生**。局面は **戦争と生産のみ**。 | SPEC |
| **R-307** | P2で解禁される動詞は **敷く** と **裁く**。 | 設計 1339 |
| **R-308** | P2のセッションは **3局から報告**。まだ個体も追える。 | 設計 1870 |
| **R-309** | P2の捕虜は **戦争ごとに1〜5人を抽選**（フェーズ開始時の自国比 5〜25%、終了時 1〜5%）。**フェーズに入りたての戦争が一番おいしい。** | 設計 711 |

## 4-2 よそ者と暮らす

| ID | 要件 | 出典 |
|---|---|---|
| **R-310** | **最初の派閥はイデオロギーではなく出自。** 捕虜は怨恨を持って来る（力ずくで連れてこられた）。文化ミームが違う。関係値グラフに繋がっていない。「うちの国民」と「よそ者」の線が最初の分断になる。 | 設計 592 |
| **R-311** | 統治思想の第一問がここで出る。**混ぜる**（遺伝子が広がり雑種強勢が効く／怨恨と異文化が入る）か、**隔離する・使い潰す**（純血が保てる／血が濃くなり変異先が増えない）か。100体の段階で、読める規模で選ばせる。 | 設計 592 |
| **R-312** | **画面の見た目が同化のメーターになる。** P1＝単色 → P2前半＝斑（明らかに異物が混じっている）→ 同化が進む＝混色 → 隔離政策＝斑のまま固定。色が混ざる＝遺伝が混ざるが文字通り同じ処理であること。UIも数値も要らない。 | 設計 603 |
| **R-313** | **同化のメーターに使うのは「混血度（admixture ＝ 1 − 血統の最大成分）」であって、外来血の量ではない。** 隔離するとよそ者は自分たちだけで繁殖するので、量はむしろ増えたまま混ざり具合だけがゼロに張り付く。量で判定すると、隔離しているのに「混ざってきた」と表示されてしまう。 | 設計 2238（訂正3） |

## 4-3 家と血統（P2で起動）

| ID | 要件 | 出典 |
|---|---|---|
| **R-320** | 世襲は自動、**透過率は設計**。放っておけば軍人の子は軍人になる。ただし放置すると戦争の損耗で兵のプールが縮み、数世代で軍が枯れる。**透過性は「あったらいい」ではなく、シミュレーションが止まらないための必須部品。** | 設計 458 |
| **R-321** | 子の実際の役 ＝ **子の適性 × 親の許可**。親の許可を決めるのは非戦闘の人格遺伝子（頑迷/柔軟・野心・誇り・序列意識・情愛）。**それらも遺伝する** ので、硬直した家系と流動的な家系が両方勝手に生まれる。 | 設計 464 |
| **R-322** | 家に潰された有能個体は **被扇動係数と裏切り係数の入力になる**。外から来た捕虜が謀反を起こす経路に加えて、**内側で腐らせた才能が謀反を起こす**経路ができる。原因がオーナー自身の配役ミスなので可読性が高い。 | 設計 480 |
| **R-323** | **透過率 ＝ 制度の緩さ × 測定精度。** 制度を緩めても測れなければ結局家柄で決まる。 | 設計 1470 |

## 4-4 裁く／敷く（P2の心臓）

| ID | 要件 | 出典 |
|---|---|---|
| **R-330** | **裁く＝セッションの心臓。** 毎セッション、局長が **2〜5件** 何かを求めてくる。**オーナーは能動的に統治しない。世界が動き、それに可否を出す。** | 設計 1268 |
| **R-331** | **無害な選択が存在しない。** どちらを選んでも誰かが不満を持つ。却下し続ければ局長が腐り、承認し続ければその局が肥大する。 | 設計 1268 |
| **R-332** | 具申は **局長の人格 × 世界の状態** から自動生成する。作者が書くのはテンプレートだけ。 | 設計 1268 |
| **R-333** | 具申は中立な要望ではなく **権力闘争の手**。予算を取り、他局の人材を引き抜き、讒言で陥れる。オーナーが裁いているのは政策ではなく権力闘争であり、**どちらを承認しても必ず誰かが強くなる。** | 設計 1202 |
| **R-334** | **敷く＝方針カード。** 各局に10個程度の名前つきカードを、オン/オフのトグルと数値パラメータで置く。複数オンにすれば暗黙のAND、優先順位はドラッグで並べ替える。 | 設計 530 / SPEC |
| **R-335** | **派遣・育成・応戦方針・降伏条件・護衛の付与は、すべてカードに畳む。** 置けるのはカードの粒度までで、その先の運用は局長のもの。 | 設計 1268 / 1329 |
| **R-336** | **命令は人格で歪む**：`オーナーの指令 → 局長の人格フィルタ → 実際の条件式 → 全個体が動く`。頑迷な局長は自分流に読み替え、野心的な局長は指令を超えて拡大する。**オーナーは方針を決めているつもりで、実際は「方針を持った人間を選んで」いる。** | 設計 1380 |
| **R-337** | 残すのは **局長の歪み** だけ。「30%と命じたのに頑迷な局長は40%でやった」は読めるので残す。「30%と打ったのにシステムが別の意味に取った」は読めないので**排除する。** | 設計 545 |
| **R-338** | 局長の振る舞いは、その個体の遺伝子ベクトル（野心・保身・頑迷・誇り・情愛・統率）を局の固定アクションセットに通した関数でしかない。**政策を生成する必要はなく、既に存在する個体の性格を読み出すだけ。** | 設計 1367 |
| **R-339** | 局長の武器は **「不作為」**。権限の範囲内で、やらないことでできる（農業＝備蓄を薄く保つ／軍務＝精鋭を無駄な戦に出す／民生＝…）。**表面上は順調に見え、全部が3世代後に効く。** | 設計 1162 |
| **R-340** | 謀反の巧拙は **知性の関数**。低知性＝露骨ですぐバレて誅殺される／中＝不作為で無能と区別がつかない／高＝積極的な偽装で原因究明そのものが失敗する。**全員を賢くするのではなく、知性相応に振る舞わせる。** | 設計 1179 |
| **R-341** | 任命は **2軸のリスク判断**（知性 × 野心）。「低野心×高知性＝理想だが希少」「高野心×高知性＝最強かつ最悪」。**賢い部下は有能で危険、愚かな部下は安全で無能。** | 設計 1191 |
| **R-342** | **裁可待ちは溜めない。** 未処理の具申は次の世代に入る時点で局長が自分の人格に従って処理する。復帰したプレイヤーが見るのは山積みの未決箱ではなく「不在中に軍務局長はこう決めた」という結果。 | 設計 1904 / 1818 |

# 12章 完成の基準（AAA）

`SPEC.md` の8項目をそのまま要件化したもの。**これが通らなければ完成ではない。**

| ID | 基準 |
|---|---|
| **R-A1** | 種を固定すれば同じ歴史が再現される |
| **R-A2** | 1,000世代回して NaN・無限ループ・人口爆発・即死が起きない |
| **R-A3** | 逃走癖・私欲・怠惰が集団に固定しない（頻度依存が効いている） |
| **R-A4** | 全ステが親2人を上回る子が出ない（連鎖が効いている） |
| **R-A5** | 心系の劣性が数世代潜伏して発現する例が観測できる |
| **R-A6** | 3世代後の謀反から原因の粛清まで年代記で遡れる |
| **R-A7** | **P1が5〜10分、P2の1セッションが3〜10分で成立する** |
| **R-A8** | **クリックだけで最初から最後まで通せる** |

### 実測で立証済みの数値（v2で回した結果。退行の基準線として使う）

| 主張 | 実測 |
|---|---|
| 決定性 | 歴史ハッシュが完全一致（24/24） |
| 全ステが親2人超えの子 | 80,393件の出生で **0件**（1座位単位では平均8/33が親超え＝進化の余地は残る） |
| 心系の劣性が潜伏 | 18,097件。うち99.9%が2世代以上。**中央値12世代** |
| 逃走・私欲・怠惰は固定しない | 1001世代×3種で固定せず（0.29 / 0.53 / 0.36） |
| 戦死のステ由来／運 | **90.4% / 9.6%** |
| 練度は遺伝しない | 77,062件で相関 r=0、子は全件0 |
| オーナーごとのクラスタに割れる | クラスタ間0.858 > クラスタ内0.497、**識別率94%**（偶然10%） |
| 純血国は腐る | 純血 劣性ホモ0.176／人口103.7 vs 融和 0.113／179.1 |
| 透過率が血統構造を変える | 上位1家系が局長を占める率 世襲99.4% vs 実力主義72.4% |
| 3世代後の謀反から遡行 | 謀反536件中466件（**86.9%**）成功。隔たり平均2.6世代 |

### 方法論の掟

- **係数を動かして検査を緑にするのは、ノイズへの過適合。** 機構として根拠のある値で止める。
- **sim単体とUI単体をいくら検証しても、繋いだ状態は検証されない。** 13項目が緑のままゲームが起動していなかった実例がある（`api.js` のフォールバックが実simに無い名前を黙って mock に差し替えていた）。**継ぎ目を見張る検査を最初に書くこと。**
