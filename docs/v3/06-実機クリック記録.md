# 実機クリック記録（初見と同じ経路を人手で通した記録）

日時: 2026-08-20 / 実施: Claude（アプリ内ブラウザで実クリック）
経路: `http://localhost:8837/game/`（?dev なし。保存種族なしの初回状態から）
窓: 1440 × 900

**結論から言うと、P1の一周（2匹 → 10体 → 初戦 → 捕虜 → 部族）は通った。**
「戦いに行けない」は導線が消えているのではなく、**画面が言っていることと数字が食い違っていて、
何が起きたのか分からないまま進んでしまう**のが実体。以下、押した順に記録する。

---

## 1. 表紙 → 60問

- 表紙は問題なし。`sim` バッジは出ない（修正済みの確認）。
- 60問は「1文＋7段階」。点の位置が固定されているので速い。ここは良い。
- **[重大] 6つの軸の名前が出ない。** 問題を答えている最中、画面下に6本の帯があり、
  ラベルは「まだ中央」だけ。何の軸を動かしているのか最後まで分からない。
  22問目に初めて「烈／振れる」という語が出るが、**この語の意味はどこにも書かれていない。**

## 2. 診断結果の画面

- **[重大] 「この二匹を置く」がスクロールしないと押せない。** 結果画面の高さは 1128px、
  窓は 900px。下 228px（＝開始ボタンと「答えを直す」）が最初は見えない。
  スクロールできる手がかり（影・矢印）が無い。**マウスホイールでは動くが、End キーでは動かない。**
  初見が「始めるボタンが無い」と判断する確率が高い。
- **[致命] 数字の意味がどこにも無い。** 最初の二匹のカードに
  `勤勉 -30` `序列意識 +18` `柔軟 -17` `情愛 +17` `他責 -32` `野心 +27` `団結傾向 -20` と並ぶ。
  何に対しての ±か、高いと何が起きるかが一切書かれていない。オーナーの言う
  「代謝17だったらなんなん？」がそのまま起きている。
- **[重大] 6軸の説明が暗号。** 各軸の下に `4番 決まった場所を守る。危ない橋は渡らない`。
  「4番」は染色体の番号で、プレイヤーには何の意味も無い。しかも**「8番」が2回出る**。
- **[重大] 種族コード「安己血疑烈外」** — 漢字1文字が6つ並ぶ。小さいラベル（安定/個/身内/疑/振れる/他責）は
  付いているが、どちらが良い/悪いのか、ゲーム内で何が変わるのかが分からない。
- 危うさの欄（「誰も上を目指さない。局長が育たず、空位が埋まらない」）は良い。
  **これと同じ密度の説明が、他の全項目に必要。**

## 3. 村フェーズ（第0〜4世代）

- 開始直後は 人口2（アダム・イザナミ）。盤面は**三角形1つと点線の円だけ**。
  畑も狩り場も訓練場も、背景としては存在しない。→ 村map班の主題。
- **[重大] 人口と仕事の数が合わない。** 第2世代で 人口6 なのに、仕事タブは
  「畑1体・狩り1体・模擬戦0体・無役0体」＝ 2体しか出ない。子ども4体がどこにも出ない。
  プレイヤーは「4体はどこに行った？」となる。
- 1世代 = 実時間2分（×1）。×8 で15秒。初見は×1で始まるので、
  10体に届くまで**8分**かかる。SPEC の「P1は5〜10分」の上限に、待つだけで届く。

## 4. 10体の節目 ← ここが最大の破綻

第4世代でモーダルが出る:

> **10体になった** — 隣のシャーレが見えている
> 村は10体で止まります。これ以上は増えません。
> 先へ進む道は戦いだけです。…
> 規模 5対5 ／ 連れ帰る数 勝っても負けても1体

**このモーダルが出ている画面の上帯には「人口 13」と表示されている。**

- **[致命] 「10体で止まる」と宣言した瞬間に、13体になっている。**
  さらに右の「いまやること」も「戦って1体を連れ帰らないと、村は10体のまま止まる」と言っている。
  画面が3か所で同時に嘘をついている。オーナーの「10人でとまらない」はこれ。
- 実測（ヘッドレス）では、止めずに放置すると第11世代で162体まで増える。フェーズは「村」のまま。

## 5. 初戦

- 相手選びは P1 では正常。国の強さ 27 / 28 / 41 / 43 と散らばり、「互角」「格上」の印も出る。
  （※フェーズ2の途中から全員が同じ値 7 に潰れる別バグがある。別記）
- **初戦は 5対5 で成立した。** 仕様どおり。
- **[重大] 敵味方に同じ名前が出る。** 戦場に「アダム」（自軍・赤）と「アダム」（敵軍・緑）が同時にいる。
  戦場のラベルには所属が付かない。左右と色でしか区別できない。
- 戦闘は約8秒で決着。ログは「我らの〜」「アガルタの〜」と所属が付いていて読める。ここは良い。
- 負けた。団結 0 対 100、戦死0体、逃走3体。
  **[中] 「なぜ負けたか」が分からない。** 逃げた3体が誰で、なぜ逃げたのか（恐怖？練度？）の説明が無い。

## 6. 捕虜・国境

- 「戦のあとを決める」→ 国境画面。負けたので相手の全プールから抽選。ここは通った。
- **勝った場合も通る（訂正）。** 当初「勝つと `captiveOptions()` で落ちて詰む」と書いたが、**これは誤り**。
  実Chromeで勝ち筋を最後まで通したところ、軸選択（総合／武力／知性／統率／繁殖性／器用／頑健）→
  抽選（アガルタのアダム・上位1%）→ 受け入れ まで例外なく通った。コンソールエラーもゼロ。
  最初の例外は、こちらが書いた使い捨ての検証スクリプトが `captiveOptions()` を
  UI と違う引数・違う順番で呼んでいたことが原因。**UI の経路にこのバグは無い。**
- 負けたとき、受け入れを押したあと **人口が 13 → 12 に減った**（1体受け入れたのに1体減）。
  戦死は0体と表示されていた。勝ったときは 13 → 14 と正しく増える。
  **負け戦のときだけ人口の勘定が合っていない。**

## 7. 部族へ

- 「村が部族になった」モーダルは出た。導線としては通る。
- **[重大] その画面の人口が 20。** 前の画面で12だったものが、1世代で20になっている。
  「村は10体で止まる」と言われた直後に、2倍になっている。
- **[重大] 食べものが「45 減っている」** に反転。部族になった瞬間に飢餓へ向かい始める。
- **[重大] 盤面がほぼ真っ黒。** 人口20のはずが、シャーレに見えるのは2体だけ。
  フェーズ移行の直後に描画が壊れている（起動直後の暗転とは別の事象）。

## 追記：実Chromeでの再走（勝ち筋）

Claude in Chrome がつながったので、実Chromeで**勝つ経路**を最後まで通した。

- 60問 → 診断結果 → 二匹を置く → ×8 → 第4世代で10体の節目 → アガルタ（やや格下・27）に勝利
- **「10体で止まる」と宣言するモーダルの上で人口13** — アプリ内ブラウザと完全に同じ。再現性あり
- 勝利後の軸選択・抽選・受け入れは**全部通った**。コンソールエラーなし。
  → 「勝つと詰む」は取り消す（上記）
- 人口 13 → 14。勝ち筋の人口勘定は正しい
- **[新] 連れ帰った捕虜の名前が「アダム」。自国にも既に「アダム」がいる。**
  同じ名簿に同名が2体並ぶ状態が、ゲームの最初の節目で確実に発生する
- **[新] 戦闘中、団結バーが「あなた 0 / 相手 0」と両方ゼロなのに「こちらの勝ち」と出た。**
  勝った側の団結が0のまま表示されている
- **[新] 戦闘の進行が requestAnimationFrame 依存。** タブが前面にないと戦闘が進まない
  （10秒待って団結が 99→99 のまま）。世界の時計は setInterval に直してあるのに、
  戦闘だけ rAF のまま（`ui/panels/battle.js`）。裏で戦闘が止まる
- **[新] 60問すべて同じ答えを押すと、6軸すべてが「中央」に戻る。**
  双極尺度としては正しいが、60回同じ操作をした結果が「どの方向にも強くない」では、
  答えた意味が消える。画面はそれを説明してはいる（「偏りのない種族は…」）が、救いにはなっていない
- **[新] トーストが画面左下の凡例に重なる。** 「種族：灼ける順民族」が「色 血すじ 濃さ 熟練」を隠す
