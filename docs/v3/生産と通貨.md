# 第0部　1行の決定

## 0-1　街には家も住人も無い ── 「市の立つ村」を指定する

正典1-4／10-D／項目15（L4428「10万人・1,000村・**100街**」）のとおり、**街は村9〜10個を束ねた箱であって居住地ではない。**人は必ず30軒の村に住み、街が建つ経路は世界のどこにも無い。

```
街ができた月（村が9つ以上・10-D）:
  配下の村のうち「最も軒数が多い村。同数なら最も古い村」を 市の立つ村（seat）に指定する
  ★ 新しい容器を作らない。街が持つのは seat の村ID と 配下の村IDの一覧と、7本の市場価格だけ
  ★ 市場在庫 ＝ seat の村の蔵そのもの。新しい蔵を作らない
  ★ 蔵の容積も storeCap(seat) ＝ 60 × 軒数 のまま。★ 街だけを容積から免除しない
  ★ seat の村では 専業が成立する ＝ その村の職の兼業係数 f をすべて 0 にする
     → seat は糧を1粒も作らない。消費80／月を必ず外から買う。**これが通貨の理由そのもの**
```
`assignWork` も `syncHouses` も 11-B も一切触らずに「専業になるのは町から」（職業と役職と身分.md）が成立する。
**造幣が起きる唯一の場所（seat）が、蔵の天井が最も強く効く場所になる。**（甲 1-8 の穴が構造的に消える）

## 0-2　扶持 ── 74職のうち51職に収入経路が無かった

**貨幣が立つまで、財は全員 0。**村の蔵は共有なので、誰が何の職でも食える。
これで #3 の 強欲 S ＝ `50 + 50×(0−0)/(0+1)` ＝ **全員 50 → U=0.231 → X=0.0420** となり、**#4-(d) の定常値（不満③ 31.5）が1点も動かないまま再現される。**校正のやり直しが構造的に不要になる。

**貨幣が立った月から、財は「扶持」1本だけで生まれる。**

```
毎月・村（と街）ごとに1回:
  配分点  s_i = w_職(i) × (1 + 0.5 × 役職の段Q_i + 0.3 × 爵位の段P_i)
     w_職 : A/B/C（物を動かす職）1.4 ／ D（人に掛かる職）1.0 ／ E（軍・平時）0.8
            役職だけの者 1.0 ／ 農奴・乞食 0.2
     ★ 対象は「12歳以上で job が学生でない者」だけ
  必要額 W* = b_max × Σs        b_max = 糧の市場価格 × EAT_ADULT × 3
  扶持の総額 W = min( purse , W* )      b = W / Σs
  wealth_i += b × s_i
  purse   -= W
  家計の買い戻し:  wealth_i -= wealth_i × 0.06 ;  purse += Σ(wealth_i × 0.06)
     ★ 村がまとめて買うので、個人の買い物ループは作らない
     ★ 上の2行は人ループ②の中で 乗算2・加算1。人ループの回数は増えない
```
**国家運営9役職・宗教2役職・軍 だけが国庫から払われる**（b_国 ＝ 国庫の12ヶ月移動平均収入の60% ÷ Σs）。
**村長・司祭・町長・市場監督・学寮長・隊長は村／街の purse から。**

```
未払いの代金（★ 一般の職には積まない。村の蔵が共有なので貨が無くても食えるため）:
  役職者と軍だけ:  不満③ += 0.20 × (1 − ρ) ／月     ρ = b / b_max
```
rD③ = 0.0040×k（k=0.98）なので、ρ=0 が続くと定常 ③ は **51.0**（謀反圏）。**賃金の途絶は国を倒す。**

**これで 4-4④（財）が ①（ステ→産出）の単調関数になる穴が閉じる。**財を決めるのは「役職の段 × その村が市に届くか」であって、産出量ではない。3-1「貴族より富んだ平民」が成立する（下の検算）。


## 6-2　貨は「総量」を持たない（★この設計の芯）

> **貨が在るのは3ヶ所だけ ── 個人の `wealth`・村と街の `purse`・国庫の `treasury`。**
> **市の売買は purse ↔ purse、口銭は purse → treasury、扶持は purse/treasury → wealth、**
> **家計の買い戻しは wealth → purse。すべて閉じている。**
> **系に入る唯一の注入口は造幣。出る口は無い。**

```
これで得られること:
  1. 「発行総額」という4つ目の量を持たなくてよい（帳簿の二重化が起きない）
  2. 甲の「1:1 で読み替える」が要らない。**造幣の前は財が全員0で、canon の定常値そのもの**
  3. 乙の「国庫が年 −67,000銀」が構造的に起きない（b_国 は収入から決まる。§6-4）
  4. 貨の総量が実物に一切効かない ── 効くのは**分布**だけ。#3 の強欲Sも 10-B も分布しか読まない
```

**貨が満ちるまでの時間（★これが「通貨を入れると起きること」の本体）**
```

★ そのあいだ 財の分布は粗く、10-B の五分位も #3 の強欲 S も動きが鈍い。
  **貨幣は宣言した月に効き始めるのではなく、数年かけて効いてくる**
```

## なぜこの形か
## なぜこの形か

**1. 物は7本。「消費先が違うか」と「場所に縛られるか」の2つでだけ割った。**
乙の4本は正しい圧縮だが、鉱夫・製錬・鍛冶が `職業ステ.csv` で別の中核ステを持つ3職なのに入力が同じ「素」1本に潰れ、実際に乙自身が §2-4 と §4-1 で矛盾した（村では品を作らないと書きながら、村で品を作る選択肢で柱7を証明した）。甲の13本は村ループが13幅になり、溢れの処分と価格と移送が13回になる。**7本は「地金」を足して鉱夫→製錬→鍛冶を3職として立て、「塩」を落として札にした結果**であって、中間の値を取ったのではない。捨てた案＝布を独立の列にする：冬の死亡と産出の両方を具1本に載せても、具は戦争・疫病・不満・繁殖のどれも直せないので一本道にならない。

**2. 「札は存在を許すだけ。効きは必ず密度」に統一した。**
乙の16本の札は全部「1人いれば村全体に効く」で、#4-(f) の見出し「閾値表 ── 崖を作らない」に正面から反していた。とくに汚物処理1人の ×0.60 は、村の潔癖平均が40ポイント動くのと同じ効きを採用1人の真偽値が上書きするもので、柱4（連鎖群で能力を縛る）が金で買えてしまう。**札を「その職が生えてよいか」の門に降格し、効きを `1 ± a × min(1, 頭数/(母数×ρ))` に一本化すると、1人目が最大・2人目も0でない・飽和がある、が同時に立つ。**そして国の技術札の「一度立ったら消えない」をやめて猶予60ヶ月にしたことで、正典1-5 のフェーズ4「技術の伝承ロス」が初めて機構になり、著述家が「それを止める唯一の職」という自分の説明どおりの仕事を持つ。

**3. 街に新しい容器を作らず、「市の立つ村」を指定した。**
両案とも街に市場在庫や軒数を持たせていたが、**街には家も住人も無い**（1-4 のズームの段・10-D・項目15 の「1,000村・100街」）。seat を1村指定すれば、市場在庫はその村の蔵になり、蔵の天井（60×軒数）が造幣の起きる場所にそのまま効く。甲が「通貨は蔵の天井から生まれる」と書きながら `TOWN_SPEC` を容積から免除していた矛盾が、構造的に消える。そして seat の職の兼業係数を0にするだけで「専業になるのは町から」が成立し、`assignWork` も `syncHouses` も 11-B も1行も触らない。

**4. 貨に「発行総額」という4つ目の量を作らなかった。**
甲は造幣能力が必要量の1/1,000で「1:1の読み替え」が物理的に不可能だった。乙は課税対象を2回別々の数で書き、国庫が自己申告と逆符号で年 −67,000銀だった。**どちらも「貨の総量が何かに一致しなければならない」という縛りから来ている。**採ったのは、貨が在るのは wealth・purse・treasury の3ヶ所だけで、系に入る唯一の口が造幣、出る口が無い、という閉じた形。総量は何も決めず、決めるのは分布だけ。#3 の強欲Sも 10-B の五分位も 4-4④ も、読むのは分布だけなので、これで足りる。

**5. 造幣の前は財を全員0にした。**
`50 + 50×(0−0)/(0+1) = 50` は canon の校正済み定常値（強欲 U=0.231・X=0.0420・不満③ 31.5）をそのまま再現する。**帳簿上の財を作らないことが、校正のやり直しを不要にする唯一の書き方だった。**甲は「造幣の月に財が動かない」と書いたが、甲の帳簿財は造幣より前から非ゼロになるので、測る月そのものを間違えていた。

**6. 扶持を1本引いて、財を「産出量の関数」から切った。**
甲は財を産出寄与に比例配分しており、役職18・軍10・知5・医2・娯楽7 を含む51職の財が永久に0だった。それは 3-1「身分と富も別に持つ。1本にすると貴族より富んだ平民が作れず、商人が生まれず、商会も立たない」に反し、4-4④ が①の単調関数になって #13【A】の既定ソートを壊す。**扶持を purse から w_職 × (1+0.5Q+0.3P) で配ると、財を決めるのは「役職の段 × その村が市に届くか」になり、街の首邑の商人（0.266枚/月）が無役の男爵（0.075枚/月）を上回る。**

**7. 国庫の扶持を「収入から決める」形にした。**
b_国 ＝ 収入の60% ÷ Σs にすると、国庫は定義上マイナスにならず、溜め込みもしない（余りは救恤へ自動で流れる）。乙の破綻が構造的に起きない。そして失敗のモードが「国庫が破産する」から「役職者と軍の ③ が積む」に移り、税率カードが両側に代金を持つ本物の摘みになる。

**8. 学費の代金を #3 から努力値の窓へ移した。**
甲の「学校に入れた子は ACT が積まれないので必ず外発になる」は #3 §2 の source 列（強欲＝GIVE 固定）と §3（暴食・怠惰・色欲は常に外発）で発火しない。**代わりに 5〜20歳の努力値の窓（正典2-1 の年齢減衰・職業一覧の「3倍」）を奪う形にすると、親方になる道と学者になる道が同じ窓を奪い合い、しかも「入口の閾値を通らない子に払った金はまるごと無駄になる」が付く。**家は能力の数字が見えず、オーナーだけが見える ── 正典3-1 ★「その無駄を拾い上げることだけが、オーナーにできること」が、通貨を入れて初めて「無駄」という具体を持つ。

**9. 国際交易を捨てた。**
甲の数少ない正しい判断。他国と物を売買すれば相手国の需給から鉱・炉・鍛冶の量が読め、柱7の装置3（情報遮断）が壊れる。外貨の入り口を戦利品と捕虜だけにし、両替率に相手国の fineness を入れつつ **その fineness は誰にも表示しない**ことで、両替職が仕事を持ちながら柱5（事実は正確・帰属は歪む）を破らない。

**10. オーナーの動詞を1つも増やさなかった。**
国庫を動かすのは財務長官、価格を立案するのは商会局長。オーナーは方針カード3枚に数値を置き、差し止め一覧を止めるだけ。#14 の表には行を1つも足していない（改鋳は商会の「交易・分配・価格」の軽い予定に載せる）。動詞は8つのまま。
