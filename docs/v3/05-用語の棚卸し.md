## 0. 先に結論

1. **画面に出ている語の約6割が「説明されないまま数字だけ出ている」。** 特に33座位のバーは、
   ラベルと0〜100の数字しかない。ホバー説明も凡例もない。`bar()`（`src/ui/dom.js:53`）に
   説明を差す口が無いので、**そもそも仕組みとして説明できない**。
2. **同じものが画面ごとに違う名前で出ている。** 最悪は「強さ／国力／国の強さ／熟練／練度／腕」。
   1つの値に3〜4通りの呼び名があり、初見は別物だと思う。11組見つかった（§4）。
3. **表示されているのに sim が一切読んでいない座位が3つある**（感応・世代間伝承意欲・懐疑）。
   さらに inspector は「感応＝気配に気づく力」と**効果を書いてしまっている**。
   仕様書の原則「事実は常に正確に見える」に真っ向から反する。
4. **一番きつい日本語が出るのは「きまり」タブ**。ここは `ui/cards.js` のやさしい文面ではなく
   `sim/cards.js` の素の label が出る（`ui/adapter.js:370` `name: c.name || c.label`）。
   「団結がN%を切ったら降伏具申」「N%の家系を辺境へ」「備蓄をN日分確保」がそのまま出る。
   `ui/cards.js` のやさしい文面は **sim の読み込みに失敗したときしか使われない死んだコード**。
5. 60問（`questions.js`）の文面だけは例外的に読みやすい。ここは触らなくてよい。
   ただし結果画面の種族名（梟雄族・簒奪族・郷党族・順民族・勘定族…）と接頭辞（灼ける・黙する）は読めない。

## 3. 表示されているのに何も起きない語（＝嘘になっている数字）

`src/sim` 全ファイルを grep して、**プレイヤーの個体に一度も読まれない**座位。

## 5. 仕組みとしての穴（作り直しで必ず要るもの）

1. **`bar()` に説明を渡す口が無い**（`src/ui/dom.js:53-71`）。
   `name` は文字列しか受けず、`title` 属性も付かない。ホバー説明を全項目に付けるには、
   ここに `hint` を足して `<span class="nm" title=...>` か独自ポップアップを出す必要がある。
2. **CSS にツールチップのスタイルが1つも無い**（`style.css` に `.tip` / `.tooltip` 系ゼロ）。
3. **用語辞書がどこにも無い。** 説明文が `inspector.js` の `BODY_NOTE` / `MIND_NOTE`（2行の平文）に
   6語ぶんだけ埋め込まれている（`inspector.js:30-31`）。33座位＋5練度＋国の数値＋役名を
   一箇所で持つ辞書（例 `src/ui/glossary.js`）が要る。
   形は `{ key: { label: 'やさしい表示名', one: '一言', high: '高いと〜', low: '低いと〜', dead: true } }`。
4. **「高いと何が起きるか」を書ける根拠が `derive.js` にしかない。**
   辞書を書くときは §1 の表をそのまま使えば、数字を嘘にせずに済む。
