## いちばん重い3件

### 重1. 8-5 の「上限」が、第3章の目的をそのまま無効にしている

第3章（改訂 168〜229行）の告発はこうだった。

> 素質の差が2.86倍以内でなければ、練度では絶対に逆転できない（189行）

ところが 8-5（改訂 584〜595行）はこう書く。

```
才能 ≧ 閾値 → 努力値が積まれる。伸びしろの上限は（才能 − 閾値）で決まる
```

フォーマット63〜64行では `上限は（才能 − 閾値）× 伸びしろ`。伸びしろ係数を k、閾値を T とすると

```
実効値の上限 ＝ 才能 ＋ （才能 − T）× k ＝ 才能 ×（1 + k） − Tk
```

**才能の単調増加関数である。** つまり2人が両方とも積み切った場合、才能が上の者が必ず勝つ。しかも差は (1+k) 倍に拡大する。腕力の例（フォーマット90行、k = 2.5）だと才能差が **3.5倍に増幅**される。

第3章が壊すと宣言した「才能が努力を支配する構造」は、乗算から加算に変えても**そのまま残っている**。変わったのは「才能ゼロ努力の天才が勝つか」だけで、「努力で順位が逆転するか」は依然としてノーである。

### 重2. 8-6・8-7・8-8 の実測は、8-5 の上限なしで回されている

8-7（改訂 681〜685行）は明言する。

> つまり「努力値は上限なし」で問題ない。上限を書かなくても自然に飽和する。

そして 8-7 の逓減表（改訂 663〜668行）は 実効値 200（中央）／500／1000 を並べる。才能の上限は100（フォーマット61行）なので、実効値1000は **努力値900** を意味する。8-5 の上限を当てると、才能100・閾値15・k=2.5 で努力値の上限は 212.5、実効値の上限は 312.5。**実効値1000 の個体は原理的に存在しない。** 8-7 の表の3行目は成立しない。

中央値も合わない。8-7 は「実効値200が中央」と置くが、才能中央50・閾値15・k=2.5 なら実効値の上限は 137.5 で、**中央値が200に届かない。**

8-7 の「40年で202、60年で212」（683行）も同じ。才能中央50でこの値になるには k ≥ 4.3 が要る。8-6 の「凡人20年 vs 天才ニート +30」（改訂 625行）も、上限なしの前提でしか出ない。

**つまり 8-6 / 8-7 / 8-8 の数値は、8-5 を採用した瞬間に全部引き直しになる。** 文書はこれに一言も触れていない。付録（改訂 431行）は「練度は0〜100で頭打ち → 後天は上限なしにする」と覆したことにしているが、8-5 が上限を復活させている。**付録の3件目は本文で生き残っている。**

さらにフォーマットの計算式ブロック（62〜64行）は、同じ4行の中で

```
努力値  … 0〜∞。上限なし。ただし年齢減衰で自然に飽和する
        …
        上限は（才能 − 閾値）× 伸びしろ
```

と、**上限なしと上限ありを同時に書いている。**

### 重3. 15項目フォーマットに「染色体・対抗アーム」の欄が無い

元設計の収束防止装置の1本目は連鎖群である（world-sim-design.md 35行）。

> 1. **連鎖群** — 敵対する遺伝子を同じ染色体に載せ、全ステ最強を構造的に禁じる

元設計はこれを「確率ではなく構造で保証される」（254行）と位置づけ、「トレードオフをステータスの中に書く（武力↑なら食料消費↑）のは**補助**でいい」（238行）と明言している。CSVの33遺伝子は全部が染色体番号と体系／心系を持っている。

**15項目にはその欄が無い。** #8 遺伝率と #9 遺伝方式はあるが、「何番染色体の、どちら側のアームか」「対になるのはどのステか」を書く場所がない。#3・#4 の「組み合わせ」は相乗効果の記述であって連鎖ではない。

このフォーマットで全ステを書き切ると、**装置1が定義から消える。** 残るのは #2「高いと悪い面」を人手で1つずつ発明する方式で、これはまさに元設計が「補助でいい」と格下げしたやり方である。掟の欄（フォーマット105〜107行）が「2をなるべく作らないと最適解が1本になる」と書いているのは、装置1を失った自覚のないまま、その穴を人力で埋めようとしている状態にあたる。

4-3（264行）「1組から生まれる子は平均1〜5人」。4-4（275行）「18〜40歳のあいだ」。**平均1〜5人は4倍の幅**で、上端なら人口爆発、下端なら絶滅する。6-3（385行）は「人口爆発しない・絶滅しない」を**作り直しで失われる性質**として挙げているが、新しい時間軸での代替の不変条件が書かれていない。第7章の未決リストにも無い。

### F-2. 8-7 の「60年やり続けた者」が寿命と合わない

改訂 683行「40年やり続けた者と60年やり続けた者で、中央値の差はわずか +10」。60年働くには最低でも65歳が要る。8-1 の寿命は**平均55・最大70**（469行）。この比較の対象は人口のごく一部にしか存在しない。しかも 8-1 の年齢曲線では65歳（寿命70）は28%なので、実効値212は世界には59としてしか現れない。**「インフレは既に止まっている」の根拠が、老い係数を掛ける前の値で語られている。**

### F-3. 2-3「わざは使わなければ錆びる」に対応する仕組みが8章に無い

改訂 103行は わざ を「使わなければ錆びる」と定義するが、8章の努力値には**減衰も忘却も無い**。年齢による習得速度の低下（フォーマット67行）は「新しく積む速さ」であって、既に積んだものは減らない。転職しても前職の努力値が消えるとは書かれていない（8-8 はむしろ引き継ぐ側の話）。錆びる仕組みが定義されていない。

### F-4. 8-2「見えていても止められない」の3行が、8-3 と競合する

改訂 500〜504行「粛清には体制怨恨が付き、それは家系に継承される」。CSV `個体の状態 / 心 / regimeGrudge`（家系に62%継承）で実装済みだが、**改訂 2-3 の8枠のどこにも「体制怨恨」の置き場が無い。** しがらみ（人と人のあいだの線）でもなく、状態（付いたり消えたりする印）でもなく、こころ（遺伝するステ）でもない。2-3 の分類が現行実装をカバーしきれていない。
