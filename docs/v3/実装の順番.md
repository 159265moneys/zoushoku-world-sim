## 2. 収穫係数（年の作柄）

```
平均1.0・ばらつき0.15・0.5〜1.5 で切る。世界に1本。畑にだけ掛ける
```

**★ これが無いと 厳冬・凶作 が丸ごと発生しない**（どちらも「収穫係数が◯◯未満」が唯一の発生条件）。
さらに #9 の「一本道を作らない」という担保が、収穫係数のばらつきに依存している。

**厄災の付属品ではなく、厄災の前提。**

## 3. 身分・爵位・役職（#10）

**ここが社会の底。**入らないと：

```
立場 = 0        → 傲慢の不満が全員1.000に張り付く（満たす道が無い）
                → 影響力が上がらない → 宗教も謀反も起きない
                → 不満④の出口（役職 −25／叙爵 −10）が開かない
```

- 列は **+7バイト/人**だけ
- **乱数を1回も引かない設計にできる**（昇級も世襲も決定論）→ 基準線が動かない
- `desire.js` の `unmetPride(0, 0, ...)` を `unmetPride(爵位, 役職, ...)` に変える**1行**が入口

★ B-17（番号と、次男が農奴になる問題）を先に決めること。

## ★ 順番を間違えるとどうなるか（実例）

私は「#8 宗派が次」と決めて着手した。**宗教が起きるには影響力35が要り、影響力には役職が要る。**
実測で影響力の最大は 16.7 だった。**作っても1件も起きなかった。**

同じ形の罠が、調査で他に5件見つかっている：

- **#7 は #8 が前提**（宗派が無いと異端がいない）
- **#9 は収穫係数が前提**（無いと厳冬・凶作が発生しない）
- **#18 は役職と局が前提**（局が無いと取り合いが起きない）
- **#19 は通貨が前提**（未確定なので着手できない）
- **派閥は B-14 が前提**（線が張られないと塊が無い）
