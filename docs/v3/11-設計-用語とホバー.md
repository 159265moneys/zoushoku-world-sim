対象コミット: `80e6a54`（ブランチ `ui-rework`）
担当: デザイン班（情報設計と用語）
前提文書: `docs/v3/00-仕様の要件.md`（特に R-905 / R-933）、`docs/v3/05-用語の棚卸し.md`

この文書が決めるのは **画面に出る言葉と数字の形** だけです。

## 1. 言葉の絶対規則（4つ）

書くたびに迷わないよう、規則は4つに絞ります。

### 規則1｜二字漢語の名詞を、和語の動詞に開く

画面に名詞を置かない。誰が何をするのかを書く。

| 出さない | 出す |
|---|---|
| 具申 | 〜と言っている |
| 温存 | 戦に出さない |
| 叙勲要求 | ほうびがほしい |
| 粛清 | 殺す |
| 帰化 | 国に入れる |
| 配給 | 食べものを配る |
| 世襲 | 役目を親から子へ継がせる |
| 派遣 | 戦に出す |
| 隔離 / 融和 | 分けたまま / 混ぜる |
| 産出 / 消費 | 作る量 / 食べる量 |
| 備蓄 | 食べもの |
| 発現ウィンドウ | 子どものうちだけ |
| 潜伏形質の発現 | 隠れていた力が出た |

### 規則2｜敬語を使わない

`〜されたい` `賜りたい` `具申いたす` は全廃。願いは全部「〜したい」「〜してほしい」。
オーナーへの敬語も無し。オーナーは神ではなく、画面の前にいる中学生です。

### 規則3｜1文は40字以内。1つの用件に本文1文＋補足1文まで

補足が2文になったら、それはホバー説明に入れる内容です。

### 規則4｜数字を出すときは、同じ視界に3つを置く

**数字・単位・どちらが良いか。** 1つでも欠けたら出さない。

- 悪い例：`代謝 17`
- 良い例：`大食い 17 ／ 100`＋ホバーで「高いほど食べる量が増える。戦いの手数も増える」

## 2. 数字の見せ方（統一ルール）

### 2-1. 数値は3種類しかない

| 種類 | 使うもの | 書式 | 例 |
|---|---|---|---|
| **めもり** | 内部が 0..1 の状態量すべて（生まれつき33・腕5・疲れ・不満・気分・恨み・戦う気持ち・使える力） | **0〜100 の整数。単位記号は付けない。必ずバーを添える** | `勤勉 77` |
| **わりあい** | 本当に「全体に対する割合」であるもの（カードの値・血すじの比率・順位・混ざり具合） | **整数 ＋ `%`** | `上位 30%` / `よそ者の血 38%` |
| **かず** | 個数・年齢・世代・食べもの・国の強さ | **整数。小数を出さない** | `人口 14` / `8歳` / `第 6 世代` / `食べもの 118` |

**禁止事項**

- 同じ量を、ある画面では `0.65`、別の画面では `65%` と出す（現状の民心がこれ）。
- 小数を出す（現状の `国への恨み 2.3`、`産出 12.4`）。**小数は1桁でも読ませない。**
- 上限の分からない生の数を単独で出す（現状の `国への恨み`）。

### 2-2. 上限の無い数（国の強さ）だけは特別扱い

`nationPower` は 0〜100 に収まりません。**単独で出してはいけません。必ず比較の相手と一緒に出します。**

- 悪い例：`国の強さ 42`
- 良い例：`うちの国の強さ 42 ／ アガルタ 66（1.6倍）`

理由：この数字は「各局の出力を潰した一つの濁った数字」（設計文書）であり、
絶対値そのものには意味がありません。意味があるのは差だけです。

### 2-3. 既知の破綻：`国への恨み` の閾値が到達不能

`main.js:307` は `w.regimeGrudge >= 4` を「危険」、`>= 1.5` を「くすぶる」としています。
しかし `world.js:386` の `w.regimeGrudge` は **各個体の `clamp01` 値の平均＝0..1** です。
1.5 にも 4 にも決して届かないので、**この表示は永久に「なし・緑」のまま**です。

→ **めもり（0〜100）に直す。** 段階は `0〜24 落ち着いている` / `25〜49 くすぶる` / `50〜74 危ない` / `75〜100 いつ暴れてもおかしくない`。

### 2-4. 色の意味（4つだけ）

| トークン | 色 | 意味 | 使う場所 |
|---|---|---|---|
| （既定） | 文字色そのまま | ふつう。何も起きていない | 大半 |
| `--warn` | 黄 | 減っている・注意 | 食べものが減っている、疲れ、不満 |
| `--bad` | 赤 | このままだと死ぬ／人が死んだ | 飢餓、戦死、暴動、恨み |
| `--ac` | 青緑 | **あなたが決めたこと・いま選ばれているもの** | 選択中のボタン、オンのカード、任命した長 |
| `--good` | 緑 | 増えている・安全 | 食べものが増えている、気分が良い |

**規則**

1. **色だけで意味を伝えない。** 必ず短い言葉（`増えている` `ぎりぎり` `危ない`）を同じ行に置く。
2. **同じ量には同じ色。陣営で色を変えない。**
   現状の戦闘画面は自軍の「団結」バーを満タンでも赤（`hue=0`）で描いており、色が勝敗と逆に読めます。
   → 戦う気持ちのバーは **自軍も敵軍も同じ配色**にし、値そのもので `--bad` / `--warn` / 既定 が切り替わるようにします。
3. **血すじの色相（`lineage`）は良し悪しを一切表さない。** 良し悪しの色と同じ場所に置かない。

### 2-5. 数値と形容が別の量を指してはいけない

現状：`食べもの 118`（在庫）の下に `ぎりぎり`（＝作る量÷食べる量の比）が付いています。
初見は必ず「在庫118がぎりぎり」と読みます。

→ **形容は必ず、同じ行の数値に対する形容にする。** 別の量の話をするなら、その量の数字も出す。

```
食べもの   118      あと 9 世代分
作る量     11 → 食べる量 13     減っている
```

## 3. ホバー説明の仕組み

### 3-1. なぜ `title` 属性ではいけないか

1. 出るまで約1秒かかる。33本のバーを見比べる作業に1秒×33は乗らない。
2. 見た目を変えられない。3行（一言・高いと・低いと）を段組みできない。
3. 長文が途中で切られるブラウザがある。
4. 現在の値（`この子: 77`）を差し込めない。

→ **独自のツールチップを作ります。** ただし要素ごとの配線はしません。

### 3-2. 構成（3ファイル）

```
src/ui/glossary.js   辞書。内部名 → { label, unit, one, high, low, ... }（第4章）
src/ui/tip.js        ツールチップ層。document に委譲リスナを1本だけ張る
style.css            .tipcard / [data-term] のスタイル
```

### 3-3. 契約（この形で実装する）

**glossary.js**

```js
export const TERMS = {
  '勤勉': {
    label: '勤勉',            // やさしい表示名。読める語は変えない
    unit:  'scale',           // 'scale'|'pct'|'count'|'age'|'gen'|'index'|'none'
    group: 'strong',          // 'strong'|'normal'|'chief'|'dead'（並び順とまとまり）
    tag:   '畑',              // '畑'|'戦'|'増'|'心'|'血'|''（行の右の小さな印）
    one:   '言われなくても手を動かすか。',
    high:  '畑の取れ高が最大1.35倍。畑に置かれるのを望む。',
    low:   '疲れにくく少し長生きするが、取れ高が落ちる。',
    note:  '',                // 補足（無ければ空）
  },
  // ...
};

export function term(key)            // → 辞書エントリ or null
export function label(key)           // → 表示名。無ければ key をそのまま返す（落ちない）
export function missing(keys)        // → 辞書に無いキーの配列（開発用の自己点検）
```

**tip.js**

```js
export function installTips()        // main.js の起動時に1回だけ呼ぶ
export function T(key)               // → el() に流せる属性オブジェクト {'data-term': key}
```

**dom.js の変更（ここが要）**

```js
// 変更前： bar('勤勉', 0.77)             ← 表示文字列を直に渡していた
// 変更後： bar('勤勉', 0.77)             ← 同じ見た目だが「内部名」として解釈する
export function bar(key, value, opts = {})
export function tile(key, value, sub)
export function stat(key, value, opts)
```

`bar()` は内部で
`label(key)` を引いて表示名を出し、
`data-term="<key>"` と `data-term-value="<0〜100の整数>"` を **ラベルの `<div class="nm">` に**付けます。
呼ぶ側は何も書きません。**辞書に載せた瞬間、全画面のその項目に説明が付きます。**

表示名を上書きしたい稀なケースだけ `opts.label` を許します（例：捕虜の軸ボタン）。

### 3-4. ふるまい（決定事項）

| 項目 | 決定 | 理由 |
|---|---|---|
| 開く条件 | `mouseover` して **120ms** 経過 | 通りすがりで開かない。速度は `title` の1/8 |
| 閉じる条件 | 離れて **80ms** | バーとバーの間を横切っても消えない |
| **クリック** | **ピン留めする（開いたまま固定）** | ①3行の説明を読む間にマウスを動かすと消えるのは事故。②固定できると、真下のバーの数字と見比べられる。③トラックパッドは行き過ぎる。**採用する。** |
| ピンの解除 | もう一度クリック / 外側をクリック / `Esc` | |
| ピン中の挙動 | 他の項目にホバーしても切り替わらない | 読んでいる途中で内容が変わるのを防ぐ |
| ボタンの内側 | **ピンしない**（ホバーだけ出す） | ボタンの本来の動作を奪わない |
| キーボード | `focusin` でも開く。ただし `tabindex` は自分から付けない | 33本のバーで Tab 順を汚さない。PC専用・マウス前提（R-934） |
| 位置 | 対象の右。画面端に近ければ左へ反転。上下も同様 | 1280px 前提。幅は 300px 固定 |

### 3-5. 目印（これが無いと誰も気づかない）

`[data-term]` には **点線の下線**（`border-bottom: 1px dotted var(--tx3)`）と `cursor: help` を付けます。
説明のある語が一目で分かるようにするためです。目印が無いツールチップは存在しないのと同じです。

見出し（`h3.sec`）に説明が付く場合は、見出しの右端に小さく `?` を出します。

### 3-6. ツールチップの中身（レイアウト固定）

```
┌──────────────────────────────┐
│ 勤勉                      0〜100 │  ← 表示名 ／ 単位
│ 言われなくても手を動かすか。      │  ← one（必ず1文）
│ ──────────────────────────── │
│ 高い  畑の取れ高が最大1.45倍。    │  ← high
│       畑に置かれるのを望む。      │
│ 低い  疲れにくく少し長生きするが、 │  ← low
│       取れ高が落ちる。            │
│ ──────────────────────────── │
│ この子  77                      │  ← data-term-value があるときだけ
└──────────────────────────────┘
```

`?dev=1` のときだけ、最下段に `内部名: 勤勉` を灰色で足します。

### 3-7. 抜けを作らせない仕組み（これが本題）

「1つずつ手で書くと必ず抜ける」ので、**抜けたら分かるようにします。**

1. **起動時の自己点検（`?dev=1` のみ）**
   ```js
   missing([
     ...GENE_NAMES,                    // 33
     ...SKILLS,                        // 5
     ...Object.values(ROLE),           // 6
     ...Object.values(DISTRICT),       // 2
     ...Object.values(BUREAU),         // 3
     ...api.CARDS.map(c => c.id),      // 12
     ...CAPTIVE_AXES.map(a => a.key),  // 7
     ...EVENT_KINDS,                   // 20（§4-10）
     ...DERIVED_KEYS,                  // §4-4, §4-5
   ]);
   ```
   1件でも返ってきたら `console.error` ＋ 画面右下に赤いバッジ「辞書に無い語 3件」。

2. **実行時の罠**
   `bar()` / `tile()` / `stat()` が辞書に無いキーを受けたとき、
   `?dev=1` なら **ラベルを赤背景**で出す。本番ではキーをそのまま出して落とさない。

3. **ヘッドレス検査に1本足す**（`game/test/glossary.js`）
   上の `missing()` を node で回して、1件でもあれば FAIL。
   ブラウザを開かずに「辞書に穴が空いた」ことが分かるようにします。
   これがあれば、sim にカードや事件種別が増えたときにテストが落ちます。

## 4. 用語辞書

**この章の表は、そのまま `TERMS` に写せます。** 列がフィールドに1対1で対応します。

> 列の対応: `内部名`＝キー ／ `表示名`＝`label` ／ `単位`＝`unit` ／ `一言`＝`one` ／ `高いと`＝`high` ／ `低いと`＝`low`

「高いと」「低いと」は **実装を読んで書いてあります。**推測は1つもありません。
根拠は `derive.js` / `world.js` / `battle.js` / `cards.js` / `constants.js`。

### 4-1. 生まれつき｜からだ（11）

| 感応 | **気配に気づく** | dead / 心 | **いまの版では、あなたの村では何にも効かない。** | 隣の国の人選びには効く。 | — |

### 4-2. 生まれつき｜こころ（22）

こころの値は **隠れて、数代あとに出てくることがあります**（優性・劣性）。
この1文は、こころのまとまりの先頭に本文として常時出します。

| 内部名 | 表示名 | group / tag | 一言 | 高いと | 低いと |
|---|---|---|---|---|---|
| 胆力 | **度胸** | strong / 戦 | 怖くても動けるか。**子どものうちに戦か狩りに置かないと分からないままになる。** | 恐怖に耐えて逃げなくなる。国の強さにも入る。 | 固まって、逃げる。 |
| 保身 | **逃げぐせ** | strong / 戦 | 危ない場所から離れたい気持ち。 | **戦場で逃げる。**長になりたがらない。戦・狩り・畑をいやがるので、置いても力が出ない。 | 踏み止まる。責任を引き受ける。 |

### 4-3. 腕（5）

まとまりの見出しは **「腕」**。副題は「使った仕事だけ伸びる。子には受け継がれない。」
`unit` は全て `scale`。`group: 'skill'`。

**伸びの速さを決めるのは4つ**（`world.js` の `gainSkills`）。この4行は腕のまとまりの先頭に本文として出します。

> 村はずれに住むと **1.33倍**早い ／ 食べものが乏しいほど早い（最大1.25倍）／
> 若いほど早い（大人になった直後がいちばん速く、歳とともに落ちる）／
> 「上下が気になる」が高いほど早い（最大1.25倍）。**腕は子には一切受け継がれません。**

| 内部名 | 表示名 | 一言 | 高いと | 低いと | どこで伸びるか（速い順） |
|---|---|---|---|---|---|
| 恐怖耐性 | **逃げにくさ** | 戦場で踏み止まれるか。 | 逃げなくなる。**生まれつきの「度胸」より、こちらのほうが効く（6対4）。** | 逃げる。 | 戦 ≫ 訓練 > 狩り |
| 戦技 | **戦いの腕** | 戦い方を体が覚えているか。 | 守りと体力が増える。「戦いの才」の効きも上がる。 | 才があっても実戦では出せない。 | 戦 ≳ 訓練 ≫ 狩り |
| 統率 | **まとめた経験** | 人を動かしたことがあるか。**生まれつきの「人をまとめる才」とは別物。** | 味方の底上げが増える。 | 才があっても号令が通らない。 | 戦 > 訓練（それ以外では伸びない） |
| 農技 | **畑の腕** | 畑仕事の慣れ。 | 畑の取れ高が増える。「手先の器用さ」「力を合わせる才」の効きも上がる。 | 取れ高が伸びない。 | 畑だけ |
| 狩技 | **狩りの腕** | 狩りの慣れ。 | 狩りの取れ高が増える。 | 取れ高が伸びない。 | 狩りだけ |

**`group` の意味と、個体パネルの並び順（D-12）**

| group | 見出し | 中身 |
|---|---|---|
| `strong` | **よく効く（どこに置くかは、ここを見て決める）** | 戦いの才・度胸・手先の器用さ・勤勉・丈夫さ・逃げぐせ・心の振れ幅 |
| `normal` | **効く** | 上の表の残り |
| `skill` | **腕** | 5つ |
| `chief` | **長にしたときだけ効く** | 頑固・切り替えが早い・切り捨てられる・好奇心 |
| `dead` | **いまの版では効かない**（既定で折りたたむ） | 気配に気づく・教えたがり・疑い深い・育ちの早さ・覚えの早さ |

`tag` は行の右端に出す1文字の印：`畑` `戦` `増` `心` `血`。
「代謝17だったらなんなん」に対する最短の答えが、この印と `strong/normal/dead` の並びです。
