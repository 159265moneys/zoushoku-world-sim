# 1. このゲームは何か

## 1-1. 画面に出す説明（そのまま使う文言）

いちばん最初の画面（診断の前）に、この形で出す。**この4行と2つのボタン以外を置かない。**

```
増殖

あなたが作った生き物が、勝手に増えて、勝手に死んでいくのを見るゲームです。

まず60問に答えてください。その答えが、そのままあなたの種族の性格になります。
生き物は2体から始まります。
あなたは1体ずつに命令できません。できるのは4つだけ。
  見る ／ どこに置くか決める ／ きまりを作る ／ お願いに「はい」か「いいえ」で答える

       [60問に答える（3分）]     [おまかせで始める]
```

世界が開いた最初の1画面には、必ずこの1行を出す。**このゲームの構造そのものなので、省略しない。**

> **村は10体でいっぱいになります。そこから先へ進む道は、隣の国と戦うことだけです。**

## 1-2. 内側の説明（実装者向け・画面には出さない）

- **遺伝のシミュレータであって、経営ゲームではない。** オーナーは資源を持たない。持っているのは権威だけで、**すべての行為は誰かに恨まれる**（R-918）。
- 遊びの本体は**淘汰装置としてのオーナー自身**（R-427）。臆病な個体を戦争に送れば死に、武の才能だけが残って繁殖する。方針を敷いているつもりで、実際は自分の国民の遺伝子構成を何世代もかけて作っている。
- 戦争の目的は勝敗ではなく**捕虜＝外来の血**（R-203 / R-733）。閉じた血統は腐るので、戦争には恒久的な経済理由がある。
- **事実は常に正確に見える。歪むのは原因と帰属だけ**（R-009）。数字は嘘をつかない。嘘をつくのは局長だけ。
- **負けを宣言しない。クリアも無い**（R-010 / R-011）。崩壊条件は「産出率が消費を下回る」の1本だけ。

## 1-3. 初見が30秒で分からなければ失敗とみなす3つ

| # | 30秒で伝わるべきこと | どこで伝えるか |
|---|---|---|
| 1 | 自分は1体ずつに命令できない | 表紙の4行 ＋ S-24（部族になった） |
| 2 | 村は10体で止まり、先へ進む道は戦いだけ | 世界が開いた最初の1画面 ＋ 上帯の `N / 上限M` ＋ S-20 |
| 3 | 画面の数字は全部、ホバーすると「高いと何が起きるか」が出る | `[data-term]` の点線下線（R-971） |

# 2. 遊びの筋（通し・所要時間つき）

数字は全部 `10-設計-進行ロジック.md` の実測（node で `src/sim` を回した結果）に基づく。推測値は無い。

## 2-1. 全体の流れ

```
診断（60問 または おまかせ）
  ↓
第0世代・2体で世界が開く
  ↓  ← 直接配役だけができる。局は無い。報告も無い
人口10 = 村がいっぱい（世界が完全に止まる）
  ↓  ← 「隣へ行く」以外に押すものが無い
初戦（5対5・隣村ゴースト）
  ↓
戦後 → 捕虜1体 → 国境（受け入れ／殺す／送り返す）
  ↓
次の世代境界で 部族（フェーズ2）へ
  ↓  ← ここで直接配役を失う。3局・きまり・願いが起動する
人口100 = v2の終端（世界は止めない）
```

**順序を入れ替えてはいけない**（R-201）。フェーズ移行が初戦より先に来ると、初戦の時点で配役ボタンが既に消えていて、P1で唯一持っていた動詞を使う場面がないまま剥奪される。

- 時計は**世界の時計だけを数える**。診断・モーダル・戦闘のあいだ世界は止まっているので、見積りと実際の経過が一致する。

## 2-3. P1（村）で起きること・起きないこと

| 起きる | 起きない |
|---|---|
| 直接配役（畑・狩り場・訓練場／まんなか・村はずれ） | 局・長・きまり・願い・報告（R-111） |
| 個体を1体ずつ見る（10体全員の名前を知っている・R-110） | 世襲（透過率を 0.9 に固定するので、家柄は存在しない・D-ロジック-06） |
| 食べものの赤字を備蓄で食い潰しながら進む（正常な姿） | 飢饉（実測 餓死 0/20） |
| 人口10で世界が完全に止まる | 10を超えて増え続けること |

## 2-4. 初戦で必ず起きること

| 必ずそうなること | 実測 |
|---|---|
| 5対5 | 40/40 |
| 相手は「隣村」（国ではない）。練度は 0〜0.30 | 40/40 |
| 勝率はほぼ五分 | 48% |
| 勝っても負けても捕虜ちょうど1体 | 40/40 |
| 戦死の85%は決着**のあと**（敗走の追い討ち）に出る | 38/45体 |

最後の行が、戦争の呼び出し順を決めている（R-952）。**戦闘画面は戦死が確定するまで閉じない。**

## 2-5. P2（部族）で起きること

- **失うもの：直接配役**（R-303 / R-304）。転換は「解禁」ではなく「喪失」として体験させる。消えるのは**初戦の後**（X-02の裁定）。
- **起動するもの：外来血の流入 / 3つの組 / 家系の分岐 / 透過率**（R-305）。移行の瞬間に `transparency` が 0.9 → 0.5 に戻り、`hereditary` カードが握る。**これが「世襲が起動する」瞬間**。
- 動詞が2つ増える：**敷く**（きまり）と **裁く**（願い）（R-307）。
- 戦争は自由（R-205）。ただし **人口16以上・不応期2世代（実時間6分）・国境に捕虜が残っていない** の3条件。**満たさないときもボタンは出し、理由と残り時間を分秒で書く**（R-943）。
- 終端は人口100。世界は止めない（R-011）。100より先は保証しない領域であることを1行で断る。

**地形名と役名は同じ語**にする（`狩り場`／`狩り`、`訓練場`／`訓練`）。置いた場所と役が対応して見えないと意味がない。

### 芯になる3つ

1. **角度＝仕事、半径＝住まい。** `ROLE` と `DISTRICT` は直交する2軸なので、片方だけ出すと「村はずれに住まわせる」というオーナーの主レバー（R-915 / R-422）が画面から消える。**村はずれの境は破線1本**で読める。
2. **耕地の角度幅 ∝ `world.land`。** 農夫を耕地の中にだけ詰めると、`landFactor = 1/(1+2.5×(働き手/土地−0.7))` が**混み具合の絵**そのものになる。説明文は要らない。
3. **食べものは「蔵の詰まり ＋ 1世代線（consumption×12）」＋「産出と消費の流れ（三角）」。** 現状の「三角を最大30個並べる」は `clamp(world.food/4, 0, 30)` で頭打ちなので**備蓄118と62が同じ絵**になる。1世代線があれば「あと少しで1世代ぶんを割る」が絵で出る（実測：人口10・世代9で 備蓄52 / 上限80 / 1世代の消費46）。

### 守ること

- 地面は**彩度20%以下・明度25%以下**に固定し、区別は色相の向きと模様（畝・木・走路・小屋・岩）で付ける。個体の色（＝看板）と競合させない。
- 模様の乱数は `new RNG(world.seed ^ 定数)`。**同じ種なら木や岩の位置まで完全に同じ世界が出る**（`Math.random()` 禁止の検証にもなる）。
- **人が0人の区画は沈める（アルファ×0.45）が、ラベルは「訓練場 0人」と出したまま消さない。** 空っぽの訓練場は初戦前に見せるべき絵（R-116）。
- **やらないこと**：家の数を人口から作って増やす／木を増やす／装飾を段階で足す／川や山（環境係数は2値しかないのに5個の地形に見せるのは嘘）／立体表現／ミニマップ・ズーム・パン。

# 対立と裁定

班どうしで決定が食い違った箇所を全部並べる。**どちらを採るかと、その根拠**を書いた。裁定できないものは openQuestions に上げた。

## X-01 ★最大の対立｜個体の記号体系

- **`13`（キャラ班・17:22）／`15`（描画班・17:23）**：色相＝血すじ／**彩度＝練度**／**明度＝年齢**／**目の大きさ＝感応・目の細まり＝恐怖**。OKLCH・楔・輪3スロット。
- **`07-A-4` / `A-5`（オーナー・17:29）**：**彩度・明度・目を撤廃。** 年齢＝大きさ＋年輪、熟練＝細胞の数、血統＝色相のみ。明度は「弱っている」だけ。状態は全部アイコン。

**裁定：`07-A-4` / `A-5` を採る。**
根拠は3つ。①**A-4/A-5 のほうが後で、オーナーの直言であり、文書自身が「仕様書のほうが古い。この A-4 が優先する」と明記している。** ②`13` の実測がまさに A-4 の判断を裏づけている（彩度＝練度は村人の練度が中央値0.000で色差ΔE7〜9＝隣国の色ゆらぎと同じ、明度＝年齢は実効幅0.08、目＝感応は死んだ座位）。**オーナーは「読めない」と言い、キャラ班は「読めていない」と測った。結論は同じ。** ③A-4 が撤廃した3チャンネルの行き先は A-5 で全部裁定済みなので、決定に穴がない。
`13`/`15` から残すものは 6-1 の表に列挙した（色相ラダー・OKLCH・格子・当たり判定・名札・生死の演出）。**これらは A-4/A-5 と衝突しない実装手段であって、記号の意味づけではない。**

## X-02 直接配役が消えるのは10体か100体か（`00` 付録A-1）

- 設計 1339：P2で失う＝10体到達時。設計 567：100体を超えた瞬間。
- **裁定：`D-ロジック-19` を採る。消えるのは「初戦の後（phase が TRIBE になった時）」。** 10体でも100体でもない。R-201 が「初戦より前に消してはいけない」と言い、R-303 が「喪失として起こす」と言う。**両方を満たす点は初戦の直後しかない。**

## X-03 混血を「中間色」で描くか「楔」で描くか

- **`07-A-4`**：「血統｜色相（据え置き）｜**混血は中間色**」
- **`13` §3-1**：中間色（円環上の加重平均）は壊れている。**外来血25%でも相手の色相が180°付近なら色相ずれ0°で純血と完全に同じ色**になる。120°の相手でも外来6.3%で3°しかずれない。捕虜1体→子50%→孫25%→ひ孫12.5%と薄まるので、**平均色では3世代で消える**。
- **裁定：暫定で楔（扇形）を採る。ただしオーナー確認（Q-3）に上げる。**
  根拠：R-312「画面の見た目が同化のメーターになる」と R-313「メーターは混血度（1−最大成分）であって外来血の量ではない」は仕様の看板であり、実測で中間色はこれを満たせない。A-4 の「中間色」は**チャンネルの割り当て表の「据え置き」欄**に書かれた記述であって、新しい符号化の指示ではない。楔は色相以外のチャンネルを一切増やさないので、A-5 の絶対規則（色に新しい意味を載せない）にも触れない。
  **ただし年輪（年齢）と細胞（熟練）も体の内側を使う**ので、体の内側の予算配分（楔＝塗り／年輪＝同心の細線／細胞＝粒）を先に決めないと3つとも読めなくなる。これは Q-4 と同じ宿題。

## X-04 P2の1世代の長さ

- 設計文書「約20分（暫定）」／`core/model.js` 現状 60分／**`D-ロジック-12` 180秒**／`12` U-2 のUI班希望 90秒。
- **裁定：180秒（3分）を採る。** 実測の根拠がある唯一の案（100体まで平均8.2世代 × 180秒 = 25分、1セッション1〜3世代 = 3〜9分で R-A7 が成立する）。20分は「不在中も世界が進む」非同期運用を前提にした数字で、v2 に非同期運用は無い。90秒だと100体まで12分で、P2の重み（100体・何度もの戦争）に対して速すぎる。**オーナー確認は残す（Q-2）。**

## X-05 個体パネルは盤面を覆うか、寄せるか

# 10. 実装の順序

**判断基準は「最短で通しで遊べるに届くか」。** 各段の終わりに**必ず検証が通ること**を条件にする。前の段が終わるまで次へ行かない。

# openQuestions（オーナーへの残件）

裁定できなかったもの、およびオーナーの明示的な判断が要るものだけを並べた。**これ以外はこの文書で決着している。**

- **Q-1｜個体から「目」を無くしてよいか。★最優先**
  `07-A-4` は「目つきってなに？」に続けて **「目ごと撤廃」** と書き、個体を「細胞のかたまり」として描くと言っている。一方で**同じ `07` の A-1 の制約欄**は「個体の見た目は『円＋縦長の目2つ』のまま（既定の方針Cを維持）」と書いており、`R-930`（SPEC・オーナー確定）も同じ。**同一文書の中で正反対のことが書かれている。**
  この文書は後から書かれた A-4 の字句を採って**「目は描かない（円＋年輪＋細胞）」で裁定した**が、これは生き物の見え方を根本から変えるので確認が要る。
  代案：**目は残すが、何のデータも載せない固定の形にする**（大きさも細まりも変えない）。この場合 A-4 の「感応・恐怖を目で表すのをやめる」は満たされ、R-930 も守られる。

- **Q-2｜P2の1世代を3分にしてよいか。**
  設計文書は「P2は1世代20分（暫定）」だが、それは不在中も世界が進むことを前提にした数字で、v2に非同期の運用は無い。20分のままだと **R-A7「1セッション3〜10分」が原理的に成立しない**（1セッションで世代が1つも進まない）。実測に基づき **180秒** に倒した（100体まで25分）。P1は75秒（10体まで5分）。

- **Q-3｜混血を「楔（扇形）」で描いてよいか。**
  `07-A-4` は「混血は中間色」と書いているが、実測で中間色（色相の加重平均）は**外来血25%でも相手の色相が180°付近なら純血と完全に同じ色**になり、捕虜1体→子50%→孫25%→ひ孫12.5%の薄まりが**3世代で画面から消える**。R-312「画面の見た目が同化のメーターになる」が成立しない。
  暫定で楔（割合ぶんの扇形に塗り分ける）に倒したが、**楔・年輪・細胞の3つが体の内側を取り合う**ので、中間色に戻すなら早めに言ってほしい（その場合は「混ざり具合」を盤面ではなく数値と個体詳細だけで見せることになる）。

- **Q-4｜熟練の「細胞の数」は最大何個か。数えられない密度になったらどうするか。**
  `07-A-4` が描画班に出した宿題で、まだ数字が決まっていない。決める必要があるのは3つ：①**熟練の上限に対応する細胞の個数**（腕は5軸あるが、細胞の数は合計を段階化する前提でよいか）②**細胞が潰れて団子にならない下限の半径**（人口が増えると個体は小さくなる）③**数えられない密度になったときの代替表示**（段階リングなど）。
  1体あたりの描画予算 10μs も、細胞を足したぶん測り直しが要る。

- **Q-5｜60問を飛ばす「おまかせで始める」を本番の入口に出してよいか。**
  現状、初見は3〜5分の診断を終えるまで世界を1秒も見られず、実機記録では**ここが離脱の第一原因**になっている。出す場合は「開発用の抜け道」ではなく、**回答を既定値で埋めた本物の種族が作られ、診断結果の画面も普通に出る**正規の入口として作る（R-102 には反しない）。

- **Q-6｜戦闘の係数（`derive.js` の `nerve` と `battle.js:329` の団結の落ち幅）を触ってよいか。**
  実測で**初戦40戦のうち11戦（4戦に1戦）は戦死も逃走も出ない**。R-105③「攻撃力の天才が恐怖で固まって死ぬのを目撃できる」が成立しない。sim を触らない範囲でできるのは「団結の推移と誰が最初に怯んだかを主役にする」ことまで。**看板の場面を確実に出すには sim の係数側に手を入れる必要がある。**（C-4「sim は書き換えない」の例外を1つ増やすかどうかの判断）

- **Q-7｜初戦で捕虜を誅殺／送還したらどうするか。**
  R-302「P2は外来血の流入で幕を開ける」と R-750「受け入れ／誅殺／送還の3択」が両立しない。
  暫定は**3択を出し、選んだ結果を正直に告知する**（「よそ者を入れなかった。村は単色のまま部族になった」）。初戦だけ「受け入れ」に固定するか、このままか。

- **Q-8｜名前プールの重複そのものを直すか。**
  10国とも創世2体が「アダム」「イザナミ」で、捕虜として同名が村に入る（実機で第6世代に村の名簿に イザナミ×2）。プールは実質119名で、使い切ると「レミエル十世94」を配る。
  UI側は名札と全画面の `名前（国名）` 表記で読めるようにするが、**根（`core/names.js`）を直すかどうかは sim 側の判断**。`core/` は共有契約なので勝手に触らない。

- **Q-9｜人口100に達したあと、続けさせるか。**
  「このまま続ける」を選べるようにしたが、実測では130〜237まで伸びて大量餓死する（保証しない領域）。その旨を1行で断る形にしてある。100で世界を止める案もある。

- **Q-10｜「組／長」でよいか。**
  「局」を消す代わりに **戦の組・食べものの組・暮らしの組** とした（農業局を「畑の組」にしないのは狩りも受け持つため）。別案（かしら／係／かた）があれば早めに。**全画面に波及する。**

- **Q-11｜効かない5座位（感応・世代間伝承意欲・懐疑・生育速度・技術習得）を実装するか。**
  この文書は「実装せず、`いまの版では効かない` と正確に書いて `dead` 群に置く」で裁定した。実装するなら sim 班の作業で、辞書の `dead` フラグを外すだけで画面は追随する。

- **Q-12｜色覚多様性への対応が要るか。**
  自国＋外来5の6色は、どう最適配置しても4視覚での最小色差が ΔE 6.9 が上限（ΔE 10 で「明らかに別の色」）。**色だけで6つの血すじを見分けさせることは原理的にできない。**
  A-5 の絶対規則（判断は色ではなく形とアイコン）を守れば実用上は足りるが、**対応が不要なら形の記号をさらに減らして絵を簡素にできる。**
