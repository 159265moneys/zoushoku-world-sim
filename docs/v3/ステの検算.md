# ステの検算

95職 × 101ステ。`職業ステ.csv` を機械照合した結果。

---

## 0. 統合の検証結果

| 項目 | 結果 |
|---|---|
| 総行数 | **ヘッダ1＋95行**（家3／村15／町26／都市24／軍10／国家運営9／宗教3／外れ者5） |
| 職業名 | **95/95 が職業一覧.md と完全一致**。過不足・重複ゼロ |
| 規模 | **95/95 一致** |
| ステ名 | **全2762参照すべてが101リスト内**。リスト外の名前ゼロ |
| 列数 | 全行8列。値にASCIIカンマ・改行ゼロ |
| 1職あたり参照数 | 23〜32個（平均 29.1）。最少＝乞食23・乳母23、最多＝外交使者32 |
| 101ステの使用率 | **99/101（98%）** |

### 構造上の瑕疵（4件・全て軽微）

1. **軍務長官** … 入口の閾値に `理解の速さ` があるが、中核にも効くにも入っていない。**閾値は中核か効くのどちらかに含まれているべき**。他94職は全て満たしている
2. **農奴・乞食** … 中核ステが「なし」（規定は3〜6個）。担当者が「就くのに要るステが1つも無いから外れ者」として意図的に空にしたもの。**仕様として認めるなら規定を「外れ者は0可」に直す**
3. **兵站・財務長官の `貪欲`** … 邪魔なステかつ伸びるステ。意図的（欠乏を毎日見る役なので育つ／年を経た兵站ほど横領する）。**矛盾ではなく、この表で最も面白い挙動**
4. **農奴の `他責`** … 同上（外れ者を溜めるほど体制怨恨が濃くなる）

## (a) どの職からも参照されないステ ── 2個

| ステ | 判断 |
|---|---|
| **学習速度** | **削ってはいけない。** 定義CSV自身が「全ステの努力値の伸びに掛かる唯一のステ」と書いている。全職に等しく掛かるので、特定の職の欄に書くと「他の職には効かない」という嘘になる。**A-4の計算式側に置くステで、職業表の対象外** |

**→ 「参照ゼロ＝不要」は成立しなかった。** 職業表は101ステのうち99個を実際に使い切っている。
ただし後述のとおり、**参照ゼロより「方向が固定されているステ」のほうが設計上の問題は大きい。**

## 削る／統合の提案

### A. 「職業表で検算しないステ」に切る ── 3個（削らない）

| ステ | 理由 | 置き場所 |
|---|---|---|
| 学習速度 | 全ステの努力値の伸びに掛かる。特定の職に書くと嘘になる | **A-4の計算式** |
| 寿命 | 全ステの使える年数を決める。職の欄には入らない | **A-4のデバフ（老い倍率）** |
| 双子の生まれやすさ | 職に紐づかない純血のステ | **生殖の枠** |

**→ 職業表の検算対象は 98ステ。この3つは「参照ゼロ／極小が正しい」。**

### B. 統合すべき ── 6件（-6枠）

| # | 統合 | 数字の根拠 | 理由 |
|---|---|---|---|
| 1 | **疲労の抜けやすさ → 持久力** | 4職中3職が持久力と共起。単独は剣闘士のみ | どちらも「続ける力」。**職から見た差が出ていない** |
| 2 | **瞬発力 → 敏捷** | 走力との共起0／反射との共起1／敏捷との共起3（4職中） | 中項目「速さ」5ステ中4つが1桁参照。**最も細分化しすぎたブロック** |
| 3 | **リーチ → 身長** | 両方使う職は騎士1つだけ（リーチ7職・身長6職） | 中世の武器の間合いは**身長の従属変数**。伸びしろも「ほぼゼロ」で同じ |
| 4 | **老いの速さ → 寿命**（→ 統合して「老い」1つ） | 共起0職。老いの速さは**5職とも邪魔**、寿命は**3職とも効く** | **同じ軸の裏表が別ステになっている。** A-4の老い倍率に両方入る |
| 5 | **双子の生まれやすさ → 繁殖力** | 双子0職・繁殖力2職 | どちらも「何人生まれるか」。分ける意味が職から出てこない |
| 6 | **歯の丈夫さ → 腹の丈夫さ** | 4職中2職が共起。単独は仕立て・音楽家（糸を切る／管楽器）で代用に近い | 「食えるか」の軸が2つに割れている |

### C. 統合を検討したが**残す**べき ── 4件

| ステ | 参照 | 残す理由 |
|---|---|---|
| **手の大きさ** | 10職（効4／**邪6**） | 参照は少ないが**邪魔として6回立っている**。織り・武具職人・細工師・仕立て・外科医・射手が「手が大きいと務まらない」。**万能封じに効いている数少ないからだステ** |
| **想起の速さ** | 17職 | 短期の記憶との共起8。単独9職（村長・町長・司祭・司教・家長・教師・学者・宰相・著述家）は全部「その場で引き出す」職で、覚えているかとは別 |
| **寒さへの強さ** | 15職（中核0・**邪魔0**） | 暑さとの共起1で綺麗に分かれている。**ただし今のままでは死んでいる。** A-19の地図（北の村／南の村）と繋がないと、効くだけで誰も困らないステになる |
| **傷の治り** | 7職（効くのみ） | 軍6職＋武具職人に集中。残すが「効くだけのステ」で中核・閾値・伸びに一度も立たない |

### D. 差し引き

```
101 − 6（統合）＋ 4（追加：獣を御する力／火の見極め／肺の強さ／空を読む）＝ 99
```
**枠を増やさずに、4班が見つけた穴を全部埋められる。**

### E. ステより先に直すべきこと（構造）

1. **邪魔0のステ21個に、罰の面を1つずつ作る。** これが検算の最大の成果。とくに上位8個。案：
   - **観察** … 細部に気づきすぎて手が止まる → 物を運ぶ職・歩兵・農奴（反復労働）で邪魔。あるいは**見てはいけないものを見る** → 使用人・牢番
   - **忍耐** … 耐えるので退かない → 鉱夫・船乗り・斥候（**崩れる坑道と沈む船から逃げない**）。**耐えるので訴えない** → 農奴が反乱しない
   - **長期の記憶** … 忘れられない → 死体処理・牢番・死刑執行人・傭兵は**忘れられる者だけが続く**
   - **数の感覚** … 分け前の不公平に気づく → 農夫・自警団（村の共同労働で不和を生む）
   - **段取り** … 先を組む者は命令の穴に気づく → 歩兵・従順と衝突（**軍と国家班が歩兵の「理解の速さ」で既に使った理屈**）
   - **図太さ** … 恥じないので慢心する → 細工師・写本・外科医（精度の要る職）
   - **体で覚える力** … 体が覚えた型は直せない → 技師・錬金術師・演出家・著述家（**前例が邪魔になる職**）
   - **人読み** … 読みすぎると情が動く → 死刑執行人・異端審問・徴税吏・監察
2. **職業表に「入口となるスキル」列を足す。**（読み書き問題の正しい解）
3. **こころ29ステのうち閾値に立つのが8個しかない。** A-4の閾値の仕掛けがこころにほぼ効いていない。
4. **社交は村15職で一度も中核／効くに立たなかった**（牧夫・猟師・皮なめしで邪魔のみ）。市と祭で積まれるステなので**町以降で初めて効く**。村では死んでいると割り切るかの判断が要る。**創意も同じ**（村では大工の邪魔のみ、都市の技師・錬金術師・演出家・著述家で中核）。
   **村＝前例が正しさ／都市＝創意が中核、という反転は意図どおりなら成功している。**

## 参考：4班が挙げた「判断に自信の無い職」（オーナー判断が要るもの）

| 職 | 論点 |
|---|---|
| **塩職人** | 海水を煮る側で書いた。**岩塩を掘る側なら中身はほぼ鉱夫になる** |
| **教師** | 入口の閾値に `理解の速さ`（閾値＝非常に高い／伸びしろ＝ほぼゼロ）を置いた。**町に教師が構造的にほとんど生まれない**という強い設計判断になる |
| **演出家** | 中核に `創意`（レアSS）。**都市に演出家がほぼ生まれない**。仕様か事故か |
| **粉挽き** | 中核＋閾値に `数の感覚`（レアS）。村の段階でこの重さは過剰かもしれない。また**村で唯一の非兼業職**として書いたが A-19b に根拠が無い |
| **駅逓** | 「街道と早馬」の一行だけ。宿駅の網を敷く役として書いたが、**早馬そのものなら伝令と重複** |
| **家令** | 宰相・兵站と近い。差別化は「主人の食卓と毒見」（味覚・毒への強さ）。弱ければ宰相に吸収可 |
| **賭博** | **胴元**として書いた。打つ側なら別のステ |
| **風呂屋** | 理髪・瀉血・按摩をどこまで兼ねるかで中核が変わる |
| **両替** | 贋金の判別を触覚＋色の見分け＋数の感覚で書いた。目方（天秤）なら数の感覚だけで足りる |
| **乳母** | `乳の出`（女のみ）が中核かつ閾値。**入口の閾値が性別で確定する唯一の職** |
| **家長・農奴・乞食** | 職というより役／居場所。家長は他17職と重ねて持つ前提。農奴・乞食は中核が空 |
