## ★ 3つ守れば足りる。1つでも欠けると溢れる

```
1. 死んだ人の席を使い回す              ← いまは使い捨て（38万席＝630MB になる）
2. 席を2倍ずつ伸ばさず、10万ちょうどで確保  ← 2倍だと 13万席になり 31% が空席のまま常駐
3. 死者の記録はディスクに置く            ← メモリに置くと 58MB 増えて溢れる
```

## ★ いちばん大きいのは「こころの drift」124バイト

**これを入れる日が、いちばん大きく基準線を動かす。**

# ② 月次の順番

**順番そのものが意味を持つ。**入れる場所を間違えると、その月ぶんズレる。

```
1日ごと
  出産 → 血のつながりの線を張る → 先天障害の抽選

月ごと（いまの順）
  ①  歳をとる・死ぬ
  ②  死んだ人の近親に「喪」を積む
  ③  寡婦・家の数え直し・家督の継承
  ④  仕事を振る
  ⑤  霧・産出・食べる・飢える
  ⑥  状態の月次（疲労・発育不全・喪の薄れ・傷の治り）
  ⑦  自分への不満の出口（結婚・子が1歳・家督・初就労・60歳）
  ⑧  地縁の線（年1回）
  ⑨  評判（風化と出来事）
  ⑩  不満と恨みの薄れ
  ⑪  欲7つ → 日常の圧を6本の不満へ配る
  ⑫  努力値が積まれる
  ⑬  結婚 → 分村
  ⑭  受胎・産後
```

# ③ 測定台帳

## 動くもの・動かないもの

| 台帳 | 何を測る | 動くか |

| M-01〜M-04 | 育種（上位20%を親に60世代） | **ほぼ動かない**。世界を走らせないため。★ ただし「こころの drift」を入れる日だけは確認する |


## ★ 取り直しの掟

```
1. 乱数の消費順が変わる変更をしたら、統計の検査は必ず落ちる。落ちたことを「壊した」と読まない
2. 落ちた検査は、係数をいじって緑に戻さない。新しい種で測り直し、台帳を更新する
3. 決定性そのもの（同じ種で2回まわして一致）は、乱数の使い方を変えても緑のまま。そちらが本当の不変条件
```

★ **12ストリームに分けたので、「使っていないストリームを引いても他は動かない」は保証されている。**
だが**実際に引き始めれば世界は変わる。**保証されているのは「理由なく壊れない」ことだけ。

## ★ 検査が種を直書きしない

「N年生き延びた世界」を要る検査は、種を直書きすると**世界が厳しくなるたびに巻き添えで赤くなる**
（今日2回起きた）。`livingWorld(年数, 最低人口)` で**要件のほうを書く**。

# ④ 並列でやってよいもの・だめなもの

| | |
|---|---|
| **並列でよい** | 正典を読む・矛盾を洗う・数を書き出す・依存を辿る（**今日やったこと**） |
| **並列でよい** | 互いに触らないモジュールを書く（例：厄災 と 検索画面） |
| **絶対に並列にしない** | ①個体の列 ②月次の順番 ③検査ファイル ④測定台帳 |

**①〜④は1人が持つ。**各班は「どこに何バイト足したいか」「月次のどこに入りたいか」を
**申告するだけ**にして、実際に書き込むのは1人。
