## A. これを決めないと層B（区画の展開）が1行も書けない

### A-1 ★致命　16区画の並べ方が決まっていない
§3-2 は「母地形 → 16区画の内訳」しか決めていない。**4×4 のどこに何を置くかが無い。**
ところが claim の13区画の円は 16枚のうち**11枚しか掬わない**（残り2枚は東と南の隣）。
実測：§2-2 の標準村（畑6・森3・牧草1・拠点地1）が取れる世界は
**並べ方が raster なら 67/100、column 66/100、scatter 26/100。2.6倍動く。**
森林の枚数の中央値も raster 5枚 vs scatter 2枚。
→ **未定義の並びが、村が建つかどうかを支配している。**

**あわせて決めたいこと**：上書き（川r枚・海湖1〜3枚・鉱脈4枚）が**どの区画を食うか**も未定義。
丘＋川等級2＋石 の席では、平野が 8−2−4＝**2区画**まで落ちうる。
§2-2 の致死ライン（畑にできるのが3枚）の下。
＞ 案：「上書きは平野を最後に食う（森林→山→荒地の順に食う）」の1行

### A-2　荒地区画の地力を 0 で始めるか
§3-2 は「畑になりうる区画は里マスの肥沃度をコピー」。
§9-3 は抜け道1（荒地→牧草地→畑）を**「荒地の地力は0」の一点で**塞いでいる。
★実測：草原の里マスの平均肥沃 **6.20**、湿地 **9.05**。草原の展開は 平野12・**荒地4**。
→ 字義どおり実装すると草原由来の荒地が地力6.2で始まり、**塞ぎが破れる。**
＞ 案：§3-2 に「ただし荒地区画の地力は0で始める」を1行
