# 02 バグ：P1導線（2匹 → 増える → 初戦 → 部族）

デバッグ班A。**実際に動かして**確かめた結果。
確かめ方は2つ。どちらも同じ結論になった。

1. **ヘッドレス再現**：`adapter.js` 越しに、`main.js` の `loop` / `onGeneration` /
   `announceFirstWar` / `startWarFlow` と `panels/*.js` が呼ぶのと**同じ順番**で叩いた。
   スクリプトは `scratchpad/harness.mjs`（api.js の解決ロジックを写したもの）と
   `A_probe.mjs` / `A_fuzz.mjs` / `A_roster.mjs` / `A_time.mjs` / `A_win.mjs` / `A_lock.mjs`。
   `A_fuzz.mjs` は「待つ世代数 × 相手10国 × 降伏のタイミング × 国境の3択」で **720通り** 回した。
2. **本物のブラウザ**：`python3 -m http.server` で `game/index.html` を開き、
   60問に答え、×8で回し、10体 → 初戦 → 捕虜 → 部族まで1周した。

いま分かっている結論を先に書く。

- **sim も adapter も、初戦を最後まで通せる。** 720通りで例外はゼロ。ブラウザでも1周できた。
  「戦いにいけない」の原因は sim 側の破綻ではない。
- 壊れているのは**画面が言っていることと、世界で起きていることの食い違い**である。
  10体で止まると書いてあるのに止まらない。5対5と書いてあるのに5対1になる。
  降伏は高くつくと書いてあるのにタダである。
- オーナーが見た「5対2・国の強さが全部7」は、**開発用の「部族フェーズから開始」ボタン**を
  押した経路で確実に再現する（後述 A-10）。

## 実測タイムライン（×1、初見の速度）

1世代の実時間は `core/model.js:12` の `GEN_MS`。**村＝2分、部族＝60分**（60秒ではない）。

| 出来事 | 村で戦わずに待った場合 | 初戦をすぐ受けた場合 |
|---|---|---|
| 人口10到達（モーダル「10体になった」） | 6〜8分（第3〜4世代） | 6〜8分 |
| 初戦 | — | 6〜8分 |
| 部族（フェーズ2）へ | **来ない** | 66〜68分（次の世代境界が60分後） |
| 備蓄ゼロ | 16〜18分（人口41〜62） | 68分〜 |
| 人口100超 | 26〜38分（フェーズは「村」のまま） | 546分〜 |
| 30世代後 | 人口78〜95、フェーズ1 | 人口46〜134、フェーズ2 |

読み方：

- **初見は8分でフェーズ2に着く。そこから次の1手まで60分待たされる。**
  ×8を押しても7分30秒に1手。部族になった瞬間に、ゲームがほぼ止まる。
- **戦いに行かないと、20分で飢えが来て、30分で100体を超え、それでも画面は「村」と表示し続ける。**

## バグ一覧

### 致命

#### A-1 村が10体で止まらない。「これ以上は増えません」は嘘

- 場所：`game/src/sim/world.js:456-472`（フェーズ移行）／`game/src/ui/main.js:218`（文言）
- 事実：`world.js` は10体に達すると `pendingFirstWar` を立てて**フェーズ移行だけ**を止める。
  繁殖は一切止めない。`main.js:218` は「村は10体で止まります。これ以上は増えません。」と書き、
  モーダルを閉じるときに `main.js:235` が「押すまで村は10体のまま。」とトーストまで出す。
- 実測（`A_time.mjs`、戦わずに待つ）：

  | 世代 | 3 | 6 | 9 | 13 | 19 | 25 |
  |---|---|---|---|---|---|---|
  | 人口 | 10 | 36 | 62 | 119 | 117 | 127 |
  | 画面の表示 | 村 | 村 | 村 | 村 | 村 | 村 |

- 再現手順：起動 → 60問に答える → 10体到達のモーダルで**「もう少し村を見る」**を押す → 待つ。
- なぜ問題か：モーダルが提示した2択の片方が、そのまま世界の嘘になる。
  初見は「10体で止まる」を信じて放置し、20分後に127体の飢えた村を見る。

#### A-2 初戦が5対5にならない。相手が1〜3人の国になることがある

- 場所：`game/src/sim/battle.js:244-250`（`matchEnemyForce` は `min(5, 相手の人口)`）／
  `game/src/ui/panels/opponents.js:52`（「相手が誰でも 5対5 の同じ条件に揃えられる」）
- 事実：初戦は自軍5体で固定されるが、敵は**相手国の人口が5人未満ならその人数しか出ない**。
  隣の10国は勝手に走っていて、滅びかけの国が出る。国力の**昇順**に並べて
  「迷ったら、いちばん上を選ぶ」（`opponents.js:53`）と助言するので、
  **いちばん弱い＝いちばん人口が少ない国**が選ばれやすい。
- 実測（`A_roster.mjs`、いちばん上の国を選んだ場合の規模）：

  | 世代 | 0 | 1 | 2 | 3〜10 | 11 | 12〜13 | 14 | 15 | 16〜20 | 21〜 |
  |---|---|---|---|---|---|---|---|---|---|---|
  | 規模 | 5対2 | 5対3 | 5対4 | 5対5 | 5対3 | **5対2** | 5対3 | 5対2 | **5対1** | 5対5 |

- 再現手順：10体のモーダルで「もう少し村を見る」を10世代ぶん待つ →
  「戦いに行く」→ いちばん上の国（アッシュル、2人）を選ぶ → **5対2**。
  `A_fuzz.mjs` の `[mix/待10/相手0]` がこれ。
- なぜ問題か：看板の場面（5対5で個体が識別できる）が成立しない。
  しかも直前に「相手が誰でも5対5に揃えられる」と読ませている。

#### A-3 降伏がタダ。1クリックで初戦が終わり、捕虜まで手に入る

- 場所：`game/src/ui/adapter.js:479-489`（`A.surrender`）
- 事実：sim の `surrender()` は賠償を `options`／`price`（`{食料10, 人0}` など）で返す。
  adapter は `raw.food ?? raw.resources ?? 0` を読むが、sim にその名前の値は無い。
  **常に 0 になる。**
  そのうえ `battle.opponentRuthless` はプレイヤーの戦では誰も立てないので、
  **降伏は必ず受理される**。
- 実測（`A_win.mjs`、開幕即降伏）：

  ```
  賠償={"food":0,"captives":0,"accepted":true} 自軍戦死0 捕虜1体 firstWarDone=true
  sim が用意していた賠償=[{資源で払う:食料10},{折半:食料5+人1},{人で払う:人1}]
  ```

- 再現手順：「戦いに行く」→ 相手を選ぶ → 開幕直後に**「降伏する」**を1回押す →
  「戦のあとを決める」→ 捕虜1体を受け入れる → 次の世代で部族になる。
- なぜ問題か：画面は「早く降りれば安く済み、粘るほど代償は大きくなる」
  （`panels/battle.js:31`）と書いている。実際は**いつ降りても無料**。
  戦闘は見なくてよいものになり、sim が用意した3つの賠償の選択肢は一度も画面に出ない。

### 重大

#### A-4 「10体になった」モーダルが11〜16体で出る

- 場所：`game/src/ui/main.js:229`（題名）
- 事実：`pendingFirstWar` は世代境界で立つ。その世代の繁殖はすでに済んでいる。
  実測：mix=10体、yes=14体、mid=**16体**。ブラウザ実機では11体で出た。
- なぜ問題か：「事実は常に正確に見える」の原則が、いちばん最初の節目で破れている。
  上の人口カウンタが16と出ている横で、モーダルが「10体になった」と言う。

#### A-5 方針カードの既定値が1枚も入っていない。12枚とも「切」で始まる

- 場所：`game/src/ui/cards.js:41-46`（`seedCards`）／`game/src/sim/world.js:48`（`w.cards = defaultCards()`）
- 事実：`createWorld` が `defaultCards()` で12枚すべてを `{on:false}` で先に埋める。
  `seedCards` は `if (world.cards[c.id]) continue;` で飛ばすので、**1枚も書き込めない**。
  さらに `ui/cards.js` の12個のidのうち **9個は sim に存在しない**
  （`send_top_pct` `spare_elder` `escort_talent` `drill_share` `farm_share`
  `stock_floor` `frontier_farm` `child_protect` `mercy`）。`setCard` は `null` を返して終わる。
- 実測：起動直後の `world.cards` は12枚すべて `on:false`。ブラウザでも同じ。
  看板であるはずの「外来血を混ぜる」も**切**のまま。`world.mating.foreignBias` は一度も設定されない。
- なぜ問題か：「きまり」タブは 40% / 7歳 / 50% と数字を表示するので、
  効いているように見える。実際はどれも効いていない。
  フェーズ2の第一問（融和か隔離か）が、既定では存在しないことになっている。

#### A-6 相手の「国の強さ」が初戦の勝敗と無関係

- 場所：`game/src/ui/panels/opponents.js:52-56`
- 実測（`A_win.mjs`、同じ種族で10国すべてと初戦した）：

  | 種族 | 力26 | 力45 | 力66 | 力98 | 力100 | 力124 | 力147 |
  |---|---|---|---|---|---|---|---|
  | mid | **負け** | 負け | 負け | 負け | **勝ち** | **勝ち** | 負け |

  他の2種族は10戦10勝。つまり**種族で決まっていて、相手の数字では決まらない**。
- なぜ問題か：数字を1つだけ見せて選ばせる設計なのに、その数字が結果と無関係。
  さらに「迷ったら、いちばん上（＝いちばん弱い相手）を選ぶ」という助言が、
  mid では**確実に負ける選択**になっている。

#### A-7 5対5で誰も死なない。看板の場面が成立していない

- 実測（`A_win.mjs`、初戦30本）：自軍の戦死は**合計1体**。29本は戦死ゼロ。
  決着は5ラウンド前後、団結が折れて終わる。
- 事実：`constants.js` の意図は「5対5なら、攻撃力天才が恐怖で固まって死ぬのを目撃できる」。
  実際に画面に出るのは「◯◯が背を向けた」が3行と、数秒後の勝敗表示だけ。
- なぜ問題か：この戦闘が「素質と練度は別物」を教える唯一の場面。
  誰も死なないので、何も教わらないまま終わる。

#### A-8 部族になった直後から1世代60分

- 場所：`game/src/core/model.js:12`（`GEN_MS = {1: 2分, 2: 60分}`）
- 事実：初見は**8分**でフェーズ2に着く。そこから次の世代境界まで**60分**。
  ×8でも7分30秒。`announcePhase2` は「急ぐときは右上の ×8 を押す」と書いてあるが、
  ×8が最大倍率。
- なぜ問題か：「3人の長を選ぶ」を終えた瞬間、画面から用件が消えて何も起きなくなる。
  初見はここで閉じる。

#### A-9 隣の10国が暴走・全滅する。国力差が17対5138になる

- 実測（`A_roster.mjs`）：

  ```
  gen 0  相手10国すべて 力7 / 2人（同じ創始者・同じ回答なので完全に横並び）
  gen16  力5/1人 …… 力2385/113人   ← 最弱と最強で477倍
  gen21  1国が滅んで一覧から消える
  ```

  自国の「国の強さ」も1世代で **40 → 7 → 8 → 78 → 14** と乱高下する
  （食料と民心が乗った式なので、備蓄が尽きた世代に潰れる）。
- なぜ問題か：相手選びの画面が「全部 格上」だけになり、選ぶ意味が消える。
  トップバーの「国の強さ」も、初見には理由の分からない乱数に見える。

#### A-10 開発用「部族フェーズから開始」がロスターを1世代も進めない ← オーナー報告の再現経路

- 場所：`game/src/ui/main.js:598-600`（`demoSetup`）
- 事実：`runGens(6)` は**自国だけ**6世代進める。`api.stepRoster` を一度も呼ばない。
  そのまま `listOpponents(state.roster)` を読むので、相手10国は**第0世代のまま**。
- 実測：第0世代のロスターは `力7 / 2人` が10国横並び。ここで初戦をすると **5対2**。
  → オーナーの「初戦が5対5にならない。相手ゴーストが2体しか出ず5対2。
  ロスターの10国も全部『国の強さ7』で横並び」と数字まで一致する。
- 再現手順：`?dev=1` で開く → 「開発用：部族フェーズから開始」を押す。
- ついでに `demoSetup` は `takeCaptives(w, b, '攻撃素質', rng)` を呼ぶが、
  `'攻撃素質'` は捕虜の軸に存在しない（正しくは `総合/武/知/統率/繁殖/器用/頑健`）。黙って総合に落ちる。

#### A-11 ロスターが1回でも落ちると、以後ずっと止まったまま（無言）

- 場所：`game/src/ui/main.js:176`
  `try { if (api.stepRoster) api.stepRoster(state.roster, state.rng); } catch (e) { /* ロスターは無くても続く */ }`
- 事実：`advanceRoster` は10国ぶんの `advanceGeneration` を回す。
  **どれか1国で例外が出ると、10国すべてがその世代以降永久に止まる。**
  例外は握りつぶされ、コンソールにも何も出ない。
- なぜ問題か：止まったロスターは「力7 / 2人」に張り付く。
  つまり A-10 と同じ絵（5対2・国力横並び）が、開発用ボタンを押さなくても起きうる。
  今回の720通りでは `stepRoster` は落ちなかったが、落ちても誰も気づけない作りになっている。

#### A-12 起動直後、シャーレが真っ黒

- 場所：`game/src/ui/main.js`（`startWorld` が `app.hidden = false` の直後に `new Dish(...)`）／`dish.js:38-45`

#### A-13 P1に「模擬戦」の枠があるが、村では模擬戦は存在しないことになっている

- 場所：`game/src/ui/panels/roles.js:12`／`game/src/sim/world.js:568`
  （`const drillShare = w.phase === PHASE.VILLAGE ? 0 : ...`、コメントは「演習はP2から」）
- 事実：画面には「模擬戦：食べ物は作らないが、安全に戦いの腕が伸びる」という置き場所がある。
  sim は村では模擬戦の割合を0に固定している。
  そこへ置いた個体は `assignRole` が `roleLocked` を立てる（`world.js:995`）ので
  **自動配役から永久に外れ、寿命が来るまで食べ物を作らない**。
  `roleLocked` を外すAPIは存在せず、フェーズ2では `assignRole` が `null` を返す（`world.js:990`）。
- 再現手順：起動直後にアダムとイザナミを両方「模擬戦」へ置く → 2人とも死ぬまで産出ゼロ。

#### A-14 「無役」が置き場所として並んでいる

#### A-15 敵味方に同じ名前が出る

#### A-16 ヘッドレステストがUIと違う順番を踏んでいる

- 場所：`game/test/integration.js:336-341`
- 事実：テストは `captiveOptions → settleWar → takeCaptives → borderDecision` の順。
  UI（`panels/border.js`）は `captiveOptions → takeCaptives → borderDecision → settleWar` の順。
  **戦後処理と捕虜取りの前後が逆。** さらにテストは相手に `makeGhost` を使うので、

- なぜ問題か：オーナーの言う「テストは全部PASSするのにUIの順番だと落ちる」の構造的な原因。

## 再現に使ったもの

```
scratchpad/harness.mjs   api.js の解決順（adapter → sim → mock）を写した土台
scratchpad/A_probe.mjs   初戦の規模／勝ち・負け・降伏・ゴースト各分岐／フェーズ2直後の候補
scratchpad/A_fuzz.mjs    720通り（種族3 × 待ち5 × 相手4 × 降伏4 × 国境3）
scratchpad/A_roster.mjs  隣の10国が世代ごとにどう見えるか
scratchpad/A_time.mjs    ×1 での実時間タイムライン
scratchpad/A_win.mjs     初戦の勝率と降伏の代償
scratchpad/A_lock.mjs    roleLocked が外れないことの確認
```

ブラウザ側：`cd game && python3 -m http.server 8791` → `http://localhost:8791/index.html`。
60問 → ×8 → 10体モーダル → 隣のシャーレ → 5対5 → 勝ち → 総合で1体 → 受け入れる →
世界へ戻る → 次の世代で「村が部族になった」 → 3人の長を選ぶ、まで通った。
この経路では例外は1件も出ていない。
