**いつ生まれるか（目方 → 刻印 → 釣り銭 → 遠隔 → 熔けない の5段）**

| 段 | 相 | 中身 |
|---|---|---|
| 目方 | **村** | **刻み銀**だけ。行商が持ち込んだ銀器を鏨で切り、天秤で計って払う。掘って作るのではないので鉱夫のいない村でも財が成立する。村の値段はすべて「街に出したらいくらか」の目安 |
| 刻印 | **街** | 鉱夫と製錬が立ち銀が採れる。**まず銀貨**（刻み銀の目方を刻印で保証したもの）。街長が鍛冶・細工師と組んで私鋳し、街ごとに目方も純度も違う |
| 釣り銭 | **街** | 銀貨だけでは釣りが出ないので遅れて**銅貨**。金地金は街でも採れるが打つ権威が無いので金貨にならず、蔵か装身具のまま眠る |

**両替が立つ理由**：「貨幣が複数ある」からではなく「**貨幣がバラバラだから**」。街ごとに私鋳された銅貨・銀貨の目方と純度を読み替える者が要る。都市・国で造幣が財務局長の専管に移っても両替は死なない ── 他国の貨幣と、街の頃に打たれた古い貨幣が尽きないから。実体は**天秤と分銅・試金石**の2つで、道具はステを上げず、**色の見分けと観察**が高い者だけが贋を弾く。

**造幣差益と改鋳（オーナーのカード）**：額面から地金と手間を引いた残りが2〜3割。改鋳率 d（銀の含有を減らした率）に対し、**その年の全国民の 不満③ に +20×d を直接加算**。d=0.25 で+5点（定常31.5を16%押し上げる）。**3回続けると怠業の閾値45を跨ぐ。**改鋳を繰り返すと本物と偽貨の純度差が縮み、ついに見分けがつかなくなる ── そこが貨幣の死ぬ点で、以後は全取引が天秤と試金石を通る（＝村の刻み銀に戻る）。

## 4. 腐敗と保存と季節

**腐敗（月あたりの目減り）**

| 帯 | 月 | 中身 |
|---|---|---|
| 実質腐らない | 1% | 穀・粉・豆・干し草・塩・蜂蜜・蜜蝋・種籾。蔵の天井で溢れる分は別 |
| 保存食 | 8% | 塩漬け肉12ヶ月／燻製肉8／干し魚6／チーズ3〜6／乾パン24 |
| 生鮮 | 夏秋50%・冬25% | 乳（3日）・生肉（2ヶ月）・魚・卵・野菜・果実 |
| 根菜だけ | 10% | 土室。冬に生鮮の枠を持たせるのはこれだけ |

**素材は腐らない。例外が5つだけで、そこが全部ボトルネックになっている。**
生皮は剥いで3日（岩塩で漬けるか、その日のうちに皮なめしへ）／焼き石灰は水に触れると死ぬ（1ヶ月以内に使う）／木材は乾燥6ヶ月・板材3ヶ月（生木で建てた家は狂って傾く）／粘土は凍らせると使えない／鉄と鋼は濡らすと錆びる（獣脂を塗って蔵に置く。**火災で消えないのは鉄と石だけ**）。
消耗品の年あたり破損率：刃物と農具10%／木の容器と器25%／布20%／革15%／石と金床0%。修理は元値の1/4。修理できる職が村に居ないときだけ買い直しになる。

**秋の屠殺（塩が冬を決める機構）**
10月、干し草の荷数が家畜の要る量に足りない頭数だけ潰す（牛40荷・羊25荷・馬50荷・豚は森で足りる）。出た生肉は、**塩がある村では塩漬け肉と燻製肉に変わって冬を越し、塩の無い村では2ヶ月で腐る。**塩がある村は冬の蔵が3割厚くなる。これが「塩→保存→冬を越す」の実体で、村フェーズに塩を置かない理由でもある。

**季節（1〜3月春・4〜6月夏・7〜9月秋・10〜12月冬）**
- 春：春穀（大麦・燕麦・豆）を播く。蔵が最も細る端境。**飢饉が立つのは3月**
- 夏：草を刈って干し草にする。乳が最も出る。羊毛の刈毛（初夏・年1回）
- 秋（収穫期3ヶ月＝疲労の負荷1.3）：刈り入れ。木の実。9月に冬麦を播く。麻の収穫。**蜜と蜜蝋は8〜9月**
- 冬：畑は0。**10月に屠殺。**狩りは×0.8。干し魚が干せるのはこの寒風の時期だけ
- **冬に止まる**：畑・石切（石が凍って割れる）・粘土掘り・煉瓦の乾燥・染料の発酵・砂金取り
- **冬にしかできない**：伐採（水が少なく狂わない）・良い毛皮の猟・干し魚
- **冬に回る**：鉱山・製錬・鍛冶・織り・伐採・狩り・冬漁。冬の産出はこの7つに寄る
- 冬は明かり（蝋燭）と毛織と塩の消費が3倍。薬草は春〜秋しか採れず冬に切れる（**冬の病が重く出る理由**）
- 断肉日（金曜と四旬節）は肉が品書きから全部消えて魚の一皿が主役になる

## 5. 重さのデバフ（式）

**★ 入力はすべて「素の値（才能＋努力値）」を読む。実効値は読まない。**（正典 第7部#1 の明文。実効値を読むと 持久力→T→r→P→持久力 で閉じたループになる）

```
耐荷 T[kg] ＝（最大筋力の素値×0.5 ＋ 体幹の素値×0.3 ＋ 持久力の素値×0.2）× 0.20
着慣れ c   ＝ clamp(0, 1, その装備を着けて過ごした年数 ÷ 8 ×（0.6 ＋ 体で覚える力の素値 ÷ 250））
実効重量 W'＝ 全装備の重さの合計 W ×（1 − 0.30c）
負荷率  r  ＝ W' ÷ T
移動デバフ P ＝ clamp(0, 0.50, 0.65 ×（r − 0.35））
```
**W ＝ KIT_W[rank_kit] ＋ Σ(wear のビットが立っている品の重さ)。**装備が変わった月だけ引き直す。

**かかる先（全部 stats_v3.csv に実在を確認済み）**
敏捷・走力・持久力・瞬発力・平衡感覚・柔軟性・反射 に ×(1−P)。息の長さ・疲労の抜けやすさ に ×(1−P÷2)。
部位の追加：具足は走力にさらに ×0.96（足に付く重さ）。鉄縁の大盾は走力にさらに ×0.85。馬鎧は馬の走力に −25%（人の W には乗らない）。

**★ 装備は第4のスロット。国民力①には掛けない。**
```
実効値[i] ＝（才能＋努力値）× M[枠] × Π(例外倍率[i]) × Π(装備倍率[i]) ＋ Σ(装備の実点加算[i])
国民力①   ＝（才能＋努力値）× Π(永続5個) × Π(例外倍率)      ← 装備倍率も装備加算も掛けない
```
これが無いと**鎧を脱いだ瞬間に国民力①が上がり**、正典4-4「捕虜は①だけを持って入る。②③④はゼロから積む」が壊れる。捕虜は国境で王冠も印章指輪も財も装備も置いてくるので②③④が実際にゼロになる ── **向こうで何者だったかが値段に乗らないのは、値段に乗る物を全部置いてきたから。**
装備の±（視力+8・打たれ強さ+30・手先の器用さ−8 など）は**実効値への加算**。加算後の下限だけ0で止め、上限は clamp しない。眼鏡の狙い（老いた写本工を救う）は実効加算でないと成立しない（実点+8 は45歳で実効+4.2にしかならない）。

**★ 関門は装備を着ける前の値で判定する。**戦弓の「握力70以上・息の長さ50以上」、鎖帷子の「手先の器用さ60以上」は、素の値＋M[からだ]まで。装備倍率は乗せない。**でないと、支給した装備がその装備を使うための関門を割る。**

**検算①（歩兵・素の値 最大筋力80・体幹70・持久力70 → T＝15.0kg）**
第4段〈平服1.2＋詰め布3.5＋木槍2.0＋木の盾2.5＝9.2kg〉 r＝0.613、**P＝0.171**。走力が2割弱落ちる程度。
第3段〈平服1.2＋詰め布3.5＋鉄の穂の槍2.0＋鉄の兜2.0＋革鎧6.0＋円盾3.0＝17.7kg〉 r＝1.180、**P＝0.50（上限に張り付く）**。
→ **第3段を中央値の兵に配ると移動デバフが上限に張り付く。だから軍務局長は最大筋力の高い者から第3段に上げる。装備が兵の選抜を決める。**

**検算②（騎士・素の値 最大筋力140・体幹120・持久力120 → T＝26.0kg）**
第1段の人が背負う重さ＝平服1.2＋詰め布3.5＋板金16.0＋面頬兜3.0＋小手1.2＋具足2.4＋鋼の剣1.3＋円盾3.0＝**31.6kg**（馬鎧30は馬に乗るので入らない）。
着慣れなし r＝1.215 → **P＝0.50（上限）**。7歳から「騎士の養育」で着て育った者は c＝1 で W'＝22.1、r＝0.851 → **P＝0.326**。
→ **板金鎧は、子供のうちから着せた者にしか使えない。**武功で成り上がった平民の騎士に第1段を支給すると動けなくなる。3本の梯子の「武」が身分と結び付いている理由が、ここで数字になる。

## 12. 上位互換を1つも置かない

**素材の側に上位互換は無い。**鋼は錬鉄の上位ではなく用途が違う（釘に鋼は要らないし鋼の鍬は割れる）。青銅は鉄の下位ではない（錆びないので鐘と軸受けは青銅でしかできない）。麻布は毛織の下位ではない（帆と包帯は麻でないと駄目）。
**食料は 量・格・持ち・値段 の4つのうち必ず何かを捨てる。**黒パン→白パンは腹が同じで格だけ上がり値が3倍。生肉→塩漬け肉は持ちが6倍になる代わりに格が1.5→1.3へ落ちる。**保存は改良ではなく取引。**粥→黒パン→白パンは身分の階段であって性能の階段ではない（3つとも1膳）。エール→葡萄酒→蜂蜜酒→蒸留酒も、上の酒ほど強く酔うが4つとも S暴食 には同じ扱い。
**道具の上位は「効きが強い」ではなく「値が下がる」か「別の窓が開く」。**錘→糸車は量が×3。羊皮紙→紙は値が1/11（書ける人ではなく書かれる量が変わる）。獣脂蝋燭→蜜蝋蝋燭は煤が出ない（写本と教会だけが必要とする）。木器→陶器→ガラス器は機能が同じで満足だけが上がる。**上位が出ても下位は消えない**（平民は下位を使い続ける）。
**上位互換が並ぶのは装備の側だけ**で、そこも 鉄の剣→鋼の剣で+10%、鉄の剣→名剣で+20%しか伸びない。

### 補足

- **指摘 A-8 で「産物が無い」とされた6職は第7節で全部埋まった** ── 粉挽き→水車／船大工→漁船・帆船／大工→木造家屋・蔵・厩・橋／石工→石造教会・塔・城壁・大聖堂・水路／技師→水路・城壁・攻城櫓・下水／工兵→破城槌・攻城櫓・投石機。
- **指摘 C-5 で「95職に存在しない」とされた6職名は、職を1つも増やさずに吸収した**（縄綯い→運ぶ職の付帯設備／染め手→織り／屋台の売り子→給仕／祭祀の役→司祭・司教／石鹸職→醸造の桶の転用／製紙職→粉挽きの水車の転用）。
- **文明フェーズの14品も既存職で作れる**ので新職は立てない（高炉＝製錬の親方／紙＝粉挽き／羅針盤＝細工師／白金の焼結＝錬金術師／帆船＝船大工の親方／銑鉄＝製錬）。**職業一覧の空き5枠は空けたまま。**
- 職業一覧側で直すのは3箇所だけ ── 見出しの「町(22)→街26」「都市(18)→都市24」、フェーズ名「町→街」、役職名「財務長官・軍務長官→財務局長・軍務局長」（正典 #10-D の Q＝局長 が第7部の傲慢Uの式に直接入っている確定値なので、職業一覧側を寄せるほうが安い）。
