## ★B-1. 実測 63.9% の個体で、細胞が上限に当たる ★最重要

`13 §9-2 scaleFor()` と `13 §4-4 cellCap()` をそのまま実装して、実際の世界に当てた
（20種 × 25世代 = 500世代サンプル / 延べ31,814体。`/tmp/probe2.mjs`）。

```
人口の段の分布（500世代）
  ≤23     124回 (S=32, 細胞19個)
  24-35    38回 (S=26, 細胞19個)
  36-54    49回 (S=21, 細胞 7個)
  55-83   117回 (S=17, 細胞 7個)
  84-122  133回 (S=14, 細胞 3個)   ← いちばん多い
  123-199  37回 (S=11, 細胞 3個)
  200+      2回 (S= 9, 細胞 3個)

細胞が上限に当たった個体   63.9%
年輪が4本描けない個体      98.5%
```

**3人に2人が「3個 ＋ 詰まりの輪」になる。**
`13 §4-4` は「**この上限は、実際にはほとんど効かない**」「効くのは人口が83を超えて全体倍率が14以下に
落ちたときだけ」と書いているが、**世代の 34% がその範囲に入っている**（84-122 が133回、123-199 が37回、200+ が2回）。

そして上限に当たった個体は全員おなじ「3個＋詰まりの輪」になるので、
`13 §4-1` が「**この差こそが『誰を戦に出すか』の判断材料**」と呼んだ差（畑だけ＝5個 / 狩り＝9〜13個）が、
**プレイヤーが最も多くの人を抱えている場面で消える。**

- **食い違い**：`13 §4-4`「ほとんど効かない」 vs 実測 63.9%。
- **実装上の根拠**：`sim/world.js:283` の `gainSkills`（腕は単調増加）／
  `sim/constants.js:19 MAX_POP = 400`／`sim/world.js:346 densityStress()`。
- **どちらを正とすべきか：実測を正とする。`13 §4-4` の「ほとんど効かない」を撤回し、
  上限に当たったときの出し方をもっと働かせること。**
  現行の「詰まりの輪1本」は「数え切れる分＋その先がある」としか言わないので、
  5個の一体と13個の一体が同じ絵になる。**せめて詰まりの輪の本数を段にする**（例：8-12個で1本、13個以上で2本）か、
  区画の面積配分を見直して S を上げる（`15 §2-6` が言っている「細胞を削るのは最後」の向き）かの
  どちらかが要る。**これは新しい宿題で、いまどちらの文書にも答えが無い。**

## ★B-2. `13 §9-2` の「人口100が sim の天井」は事実に反する

> `13 §9-2` / `14 §5.3`：「**v2 の実運用は人口100まで**（R-301 と `world.land` 45 × `POP_PER_LAND` 2.6 = 117 が sim 側の天井）」

```js

return clamp(w.people.size / cap - 1, 0, 4);
```

これは `densityStress()`（密度ストレス）の**基準値**であって、人口の上限ではない。
超えるとストレスが 0→4 に上がって民心と寿命に効くだけで、繁殖は止まらない。

`13`/`14` が「そこでは S = 14 以上」と安心している根拠がそのまま崩れる。

- **どちらを正とすべきか：実装を正とする。**
  → `13 §9-2` と `14 §5.3` の「117 が sim 側の天井」を「117 は密度ストレスの基準。実際の上限は

    （いまは `return 9` で終わっていて、S=9 のとき `cellCap(9)=3` `ringCap(9)=1` になる根拠が §4-4 の

```js

if (R >= 9)  return 3;   // 3個までなら1殻でも間隔が広く、混まない
```

**「3個までなら間隔が広い」は成立しない。**
`13 §4-3` の `CELL_SITES` で、席0（中心）と席1・席2は**すべて距離 `s` で並んでいる**
（席1 `[0,-1]`、席2 `[0.866,-0.5]` → 距離 1.0×s）。
**丸の数が何個でも、席の間隔 `s` は殻で決まっていて N では変わらない。**
だから3個のときのすき間も 7個のときと同じ `0.0653R` である。

実際に計算した（`/tmp/probe2.mjs`）:

| R | 1殻のすき間 | 丸の直径 | `cellCap(R)` |
|---|---|---|---|
| 9 | **0.59px** | 3.09px | 3 |
| 11 | **0.72px** | 3.77px | 3 |
| 14 | **0.92px** | 4.80px | 3 |
| 15 | 0.98px | 5.15px | 7 |
| 17 | 1.11px | 5.83px | 7 |

**`cellCap` が 3 を返す帯（9 ≤ R < 15）は、`13` 自身の下限 1.0px を全部割っている。**
そして ★B-1 のとおり、世代の 34%（人口84以上）がこの帯にいる。
**いちばん多い場面で、細胞は数えられない。**

- **どちらを正とすべきか：`13 §4-4` の下限の式（すき間 ≥ 1.0px）を正とし、`cellCap` を直す。**
  直し方は2つ。①`cellCap` を `R ≥ 26 → 19 / R ≥ 15 → 7 / それ未満 → 1`（＝核をべた塗り）にする。
  ②3個のときだけ席の間隔を広げる（`s` を N で変える）。ただし②は「1個増えても他が動かない」を壊すので、
  **①が正しい。** そのかわり ★B-1 の問題（3個の帯が消えるので、より多くの個体が「1個」に潰れる）が悪化するので、
  **B-1 と B-3 は同時に解くこと。**
