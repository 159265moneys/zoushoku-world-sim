# 発展度・衛生・スラム（2026-08-27・裁定待ち）

# 1. 発展度 ── 式ではなく「都市になれるか」の門

**★ 旧 `発展度 ＝ 暮らし向き × ln(拠点の総人数)` は捨てる**（正典3-6b／#17 §6-2）。
ln が人口を潰すので、100人の集落が暮らし向き80で「大都市」になっていた（実測）。

```
発展度 ＝ **食を作っていない働き手の割合 × 100**（0〜100）

  分母 … その拠点の働き手すべて
  分子 … 農夫・牧夫・猟師・漁師・木こり **以外**に就いている者
  ★ 職業一覧「村の15職はほぼ全部が兼業。専業になるのは町から」がそのまま数になる
```

**なぜこれか。**都市とは「食を作らない人間を養える場所」のこと。それ以外の定義は要らない。
そして**食を作らない人を養えるのは、外から食が入るときだけ**（オーナー裁定 D）。
だから発展度は自動的に「交易が効いているか」の指標も兼ねる。

## 段の上がり方 ── 人口が門、発展度が分岐

```
人口が閾値に達した月に判定する:
    発展度が足りていれば → 都市の側へ上がる
    足りていなければ    → **村の側に留まる**（人口だけ増える）
```

| 人が住む建物 | 発展度が足りない | 発展度が足りる | 要る発展度 |
|---|---|---|---|
| 〜9 | 開拓地 | 開拓地 | — |
| 30 | **村** | 村 | — |
| 60 | **大村** | 大村 | — |
| 120 | **大村のまま** | **町** | **20** |
| 240 | 大村のまま | **都市** | **30** |
| 480 | 大村のまま | **大都市** | **40** |
| 960 | 大村のまま | **首都** | **50** |

★ **「大村のまま」が本物の行き先になる。**人だけ増えて何も生まれない、ただ大きい村。
  中世に実在した形で、**失敗の姿が目に見える。**
★ 首都は世界に1つ（正典3-6b）。**発展度50 ＝ 働き手の半分が食を作っていない。**

# 2. 衛生 ── 集落の設備の側。潔癖（個体の性向）とは別物

**既存の疫病の式**（#9-A 厄災の表）：
```
疫病 = 人口密度 × (100 − 潔癖の平均)/100 × 基準       （100人の村で20年に1回）
```
潔癖は **14番B腕の性向（個体）**。ここに **集落の設備の側**が入っていなかった。
下水も風呂も井戸も汚物処理も、アイテム一覧に「感染の伸びが下がる」と書いてあるのに
**掛かる先が無かった。**それが衛生。

```
衛生 ＝ clamp(0, 100,
    50                                   ← 基準。ここで既存の較正が1.00になる
  + 石組みの井戸 5   ＋ 下水 20   ＋ 公衆浴場 10   ＋ 施療院 10
  + 埋葬地が拠点地の外 5              ← 縁にしか建たない決まり（建物一覧）
  + 灰汁石鹸が全戸に届いている 8      ← アイテム一覧「届いている街は疫病の感染の伸びが下がる」
  + 汚物処理に割いた働き手の割合 × 200   ← 職業一覧「衛生が疫病を決める」
  − 密度ストレス × 0.4                ← 民生局「密度の許容」の代金
  − スラムの建築枠の割合 × 120 )

疫病 = 人口密度 × (100 − 潔癖の平均)/100 × **衛生係数** × 基準
  衛生係数 = clamp(0.25, 2.00, (100 − 衛生) / 50)
  ★ 衛生50 で 1.00 ＝ **既存の「100人の村で20年に1回」が1文字も動かない**
```

**検算**
| 集落 | 内訳 | 衛生 | 衛生係数 | 疫病の頻度 |
|---|---|---|---|---|
| 村（井戸だけ） | 50+5 | 55 | 0.90 | 22年に1回 |
| 町（井戸・埋葬地・石鹸／密度10） | 50+5+5+8−4 | 64 | 0.72 | 28年に1回 |
| 手を尽くした都市 | 全部＋汚物処理5%／密度25 | **100** | **0.25** | **80年に1回** |
| スラムの都市（下水なし・スラム20%・密度50） | 50+5+5−20−24 | **16** | **1.68** | **12年に1回** |

→ **手を尽くした都市と、放置した都市で疫病の頻度が 6.7倍違う。**
　 下水（24,000銅・技師と石工と焼物で3年）を建てるかどうかが、そのまま都市の寿命になる。

# 3. スラム ── 罰ではなく、選ぶもの

**★ 湧く条件（裁定：段5以上）**
```
段5（都市）以上で、**空き建築枠が無いのに人が増えようとした**とき、
建築枠2 を勝手に食って「掘立の群れ」が建つ。24人が入る。
  ★ 建てるのではなく湧く。普請キューを通らない。資材ゼロ
  ★ 段4以下では湧かない ＝ **都市だけの現象**
```

**★ 誰が住むか**（職業一覧「外れ者5」がここで居場所を得る）
```
1. 空き建築枠が無いのに生まれた者
2. 逃散した農奴（農奴長屋から出た者。#5「逃散の判定が緩む」の行き先）
3. 職に就けなかった者 ── **乞食・盗賊・娼婦**（外れ者5職のうち3つ）
★ 職業一覧が「職ではなく居場所。どの職にも就けなかった者の行き先」と書いている、その場所
```

**★ 良い面と悪い面（両方ある。だから選ぶ意味がある）**
```
良い : **日雇いの人手が湧く。**普請の人月が 0.7倍で買える
       ＝ 城壁・大聖堂・王城が、スラムのある都市でだけ現実的な年数で建つ
悪い : 衛生 −（枠の割合 × 120）→ 疫病
       盗賊が湧く（柵と番小屋の判定に乗る）
       密度ストレス +20 ／ 火災 ×2.0
       ⑤（世界そのものへ）の不満が溜まる
```

**★ オーナーのレバー（民生局。正典4-1 に既にあるカードの行き先）**
| 手 | 代金 | 効き |
|---|---|---|
| **黙認する** | 0 | 日雇いが安いまま。疫病と盗賊を引き受ける |
| **取り壊す** | **承認カード**（川を潰すのと同じ扱い） | 住人は他の拠点へ散る（人口が減る）。⑤+3 |
| **救貧院を建てる** | 公共枠4・9,000銅・2年 | スラムの人を吸う。⑤の不満を吸う。衛生は戻らない |
| **下水を通す** | 公共枠2・24,000銅・3年 | 衛生 +20。**スラムを残したまま疫病だけ止める** |
| **建築枠を増やす** | 拠点地を1区画 増築（普請） | 根治。ただし畑が1区画減る |

→ **「汚いまま安く建てる」か「金をかけて清潔にする」か**が、都市ごとの選択になる。
　 柱8「勝ち方が1本に決まらない」が、都市の作り方でも立つ。
