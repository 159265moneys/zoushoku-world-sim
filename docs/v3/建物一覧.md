## 2. 仕分けの優先度（★ 裁定 2026-08-27）

```
    「公共か」 ＞ 「金を取るか・商いか」 ＞ 「固定の人が住むか」 ＞ 不明（応相談）

公共 … 集落／国／教会が建てる。誰か1人のものではない          → **公共枠**
商い … 金を取る。売る。貸す                                    → **建築枠**
住居 … 固定の人が住む。公共でも商いでもない                    → **建築枠**
```

**★ 分類と「人が住むか」は別の軸。**
兵舎は**公共**（国が建てる）だが**40人が住む**。宿は**商い**（金を取る）だが**主が住む**。
**段の門は分類を跨いで「人が住む建物の数」で引く。人口はそれに付随する数値。**
