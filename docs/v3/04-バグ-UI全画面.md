## 0. 全画面に共通する穴

### 0-1【致命】ホバー説明が1つも存在しない
`#app` 内で `title` 属性を持つ要素は **速度ボタン4つだけ**（実測。DOM 全走査済み）。
オーナーが名指しした「代謝17ってなんなん？」「誇り10ってなんなん？」は**一切手当てされていない**。
- トップバーの7項目（いま／世代／人口／食べもの／民心／国への恨み／国の強さ）… `main.js:301-309` `el('div',{class:'stat'})` に `title` なし
- 個体パネルの28本のバー（頑健・寿命・代謝・生育速度・繁殖性・感応・知性・可塑・野心・従順・保身・誇り・頑迷・序列意識・柔軟・情愛・世代間伝承意欲・非情・勤勉・信仰性・団結傾向・懐疑・自律・感受性・他責・好奇心・私欲・胆力…）… `inspector.js:203 geneBar()` は `bar(g, v)` を呼ぶだけ
- 個体パネルの4タイル（強さ／熟練／疲れ／不満）… `inspector.js:194 tile()`
- 熟練5軸（恐怖耐性／統率／戦技／農技／狩技）… `inspector.js:136`
- 唯一の説明が `BODY_NOTE` / `MIND_NOTE`（`inspector.js:30-31`）の2行で、**代謝・感応・可塑・他責・私欲・感受性の6語しかカバーしていない。残り22語は0〜100の裸の数字。**

### 0-2【中】唯一のホバー文言が開発者用語
速度ボタンの `title` が「設計値の1倍」「設計値の8倍」（`main.js:388`）。
「設計値」は開発内部の言葉。プレイヤーには意味がない。

### 0-3【中】ESC でモーダルが閉じない
`dom.js:130 modal()` にキーボードハンドラが無い。閉じ方は「背景クリック」だけで、
それを示す表示も無い。`dismissable:false` の戦闘・国境では背景クリックも効かない。

### 0-4【中】個体チップが `div`（キーボードで押せない・支援技術から見えない）
`roles.js:84` / `search.js:110` / `inspector.js:158` の `.chip` は `div + onclick`。
アクセシビリティツリーに出ない（実測：`read_page` で「アダム」「イザナミ」の行が1つも列挙されない）。
村フェーズの主操作「①名前を押して選ぶ」が、**タブキーでは絶対に到達できない**。

### 0-5【中】開発物が本番に同梱・配信されている
- `window.増殖 = { state, api, ctx }`（`main.js:629`）が本番でも露出
- `game/src/ui/main.js.bak`（24KB）、`panels/inspector.js.bak`（8KB）が配信ディレクトリに置かれたまま
- `mock.js`（54KB）は本物の sim を使うときも `api.js:10` で無条件 import される
- `?sim=mock` / `?dev=1` は誰でも打てる

### 0-6【中】`src/ui/cards.js` が完全な死にコード
`main.js:75 seedCards(api, state.world)` は **UI 側の `CARDS`** を回すが、その id
（`send_top_pct` `farm_share` `mercy` `child_protect` …）は sim に1つも存在しない。
実測：`world.cards` のキーは sim 側の12個だけで、UI 側の id は1つも入らない（`setCard` が黙って捨てる）。
つまり `cards.js` の説明文・既定値は**画面にも世界にも一切効いていない**。
「mix_policy の既定を 50 にした」というコメント上の意図も効いていない（sim 側の既定が使われる）。

## 1. 開幕：表紙 → 60問 → 種族結果（`panels/opening.js`）

### 1-1【重大】「答えを直す」が最終問（60問目）にしか戻らない
`opening.js:299` `onclick: () => { qi = ORDER.length - 1; renderQ(); }`。
押すと 60/60 が出るだけ。3問目の答えを直したければ「← 戻る」を57回押すしかない。
ボタンの文言（答えを直す）と挙動（最後の1問だけ）が一致していない。

### 1-2【中】60問の途中に離脱手段が無い
`renderQ()` にあるのは「← 戻る」だけ。しかも1問目は `visibility:hidden`（`opening.js:161`）。
「種族を決める」を押した瞬間から、**表紙へ戻る手段が画面上に存在しない**（リロードのみ）。

### 1-3【中】60問中、6本の軸の名前が一度も出ない
下部のスパイン（`opening.js:121 paintSpine`）は 6 本とも「—／まだ中央」で始まり、
片側に寄って初めて「安定」等の1語が出る。**何の軸を測られているのか、答え終わるまで分からない。**

### 1-4【重大】結果画面に染色体番号が出る
`opening.js:252` `${a.ch}番　${a.side===0?a.aDesc:a.bDesc}`。
画面には「4番　決まった場所を守る」「8番　情報と感情に大きく振れる」「8番　振れた力が外へ向く」。
**8番が2回出る。**「4番」「8番」は初見に何の情報も与えない。

### 1-5【中】「57%」の意味が定義されていない
`questions.js:255` `strength = 50 + |score|*50`。画面では「安定 57%」。
確率でも割合でもない内部量。見出しの「片側に寄るほど、反対側を捨てている」とも結びつかない。

### 1-6【小】「中央」の軸なのに片側だけ白く強調される
`opening.js:245,249` は `a.weak` を見ずに `a.side` で `on` を付ける。
実測：「個 ↔ 群」が **中央**表示なのに「個」だけ白太字。判定と見た目が矛盾する。

### 1-7【中】結果画面を開いただけで前回の種族が上書きされる
`opening.js:210 saveSpecies(...)` は `renderResult()` の中。**「この二匹を置く」を押す前に保存が走る。**
「答えを直す」→ 再回答のたびに `build()`（＝世界生成＋ロスター10国生成）と保存が丸ごと再実行される。

### 1-8【中】表紙の「前回きめた種族」に中身も削除手段も無い
出るのは名前と6文字コード（安己血疑烈外）だけ。結果画面にあった「安定／個／身内…」の読みが付かない。
`save.js:46 clearSpecies()` は export されているが**どこからも呼ばれていない**。捨てる手段が無い。

### 1-9【小】1〜7キーで回答できるが画面に書いていない
`opening.js:187 onKey`。速く答えられる唯一の手段が隠れている。

## 2. 世界画面のシェル（`main.js` / `index.html` / `style.css`）

### 2-1【致命】「村は10体で止まります。これ以上は増えません。」が嘘
`main.js:218` は**世界の値を1つも参照しない固定文**。
実測（種を固定した2回のプレイ）：
- 1回目：第4世代で村のまま **13体**
- 2回目：村のまま **17体**まで増え、そこで部族へ移行（`PHASE_THRESHOLD[1] = 10`）
同じモーダルの `sub` は「隣のシャーレが見えている」、`kv` は「規模 5対5」「連れ帰る数 1体」も固定文。
**画面が数字を嘘にしている。**「事実は常に正確に見える」という原則に正面から反する。

### 2-2【重大】数値とその形容が別々の量を指している
`main.js:296-305`。「食べもの」は**在庫**（`w.food`）を表示し、形容（増えている／ぎりぎり／減っている／危ない）は
**産出÷消費の比**から作っている。実測で「食べもの **118** ぎりぎり」「食べもの **62** 減っている（赤）」が出た。
在庫118で「ぎりぎり」、在庫62で赤警告。初見は必ず在庫の警告だと読む。

### 2-3【中】「国への恨み 0.3」なのに「なし」
`main.js:298` のしきい値が 1.5 / 4.0。0 でないのに「なし」と書く。数字と言葉が食い違う。

### 2-4【重大】「国の強さ」が2つの別物に使われている
- トップバー：`国の強さ` ＝ `nationPower(w)`（実測 10〜50）… `main.js:308`
- 個体パネル：`強さ` ＝ `powerOf(ind)*100`（実測 11〜24）… `inspector.js:76`
実測で **国の強さ10 / 個体の強さ21** が同時に出た。「国より個人のほうが強い」と読める。
さらに相手選択画面では自国だけ「**国力**」（`opponents.js:28`）、相手は「**国の強さ**」（`opponents.js:72`）で、
**同じ1つの数字が同一画面上で2つの名前を持つ**。国境画面では「総合」（`border.js` の軸ラベル）。

### 2-5【重大】モーダル表示中もトップバーが生きている＝裏で時間が進む
`style.css` の `.scrim{top:60px}` はトップバー（高さ60px）を覆わない。
実測：戦闘／国境／相手選択（いずれも `dismissable:false` を含む）を開いた状態で
`document.elementFromPoint()` が「⏸ 止める」を返す＝押せる。
「▶ 進める」を押すと `state.paused=false` になり、**決断待ちのモーダルの裏で世代が進む**。
`onGeneration()`（`main.js:167`）は多重表示を見ていない（`showReport` だけ `!document.querySelector('.scrim')` を持つ、
`announceFirstWar` / `announcePhase2` にはガードが無い）ので、モーダルの上にモーダルが積める。

### 2-6【重大】部族フェーズは1世代60分。実質、時間が止まって見える
`core/model.js:12 GEN_MS = {1: 2分, 2: 60分}`。`announcePhase2`（`main.js:266`）自身が
「1世代が 2分 から 60分 に伸びる」と告知する。×8 でも **7分30秒に1世代**。
実測でトップバーに「1世代 7:30」と出た。SPEC の「P2の1セッションが3〜10分で成立する」と両立しない。

### 2-7【中】帰還報告の自動表示をオフにする手段が無い
`main.js:45 autoReport: true` は**どこからも変更されない**。世代が変わるたびに
勝手にモーダルが割り込み、`showReport()` が世界を一時停止する（`main.js:544`）。

### 2-8【小】ボタン名とトーストの名前が違う
`announceFirstWar` の「もう少し村を見る」を押すと
「『**隣のシャーレへ**』はいつでも押せる」とトーストが出る（`main.js:236`）が、
実際のボタンは「いまやること」の「**戦いに行く**」（`main.js:410`）。同じものを2つの名前で呼んでいる。

### 2-9【小】「閉じる」を押しても配役の選択が残る
`closeIndividual()`（`main.js:522`）は `state.castPick` を消さず `refresh()` もしない。
実測：閉じた後も仕事タブの見出しに「アダム を選んでいる。置きたい場所の…」が残り、チップも光ったまま。

### 2-10【中】描画コストが世代ごとに全再構築
`refresh()` は `#tabbody` を毎回 `clear()` → 再生成。名簿は最大150行、
1行ごとに `portrait()` が `<canvas>` を新規生成（`color.js:165`）。
`renderTodo()` は 250ms ごとに `api.petitions()` を呼ぶ（`main.js:163`）。人口が3桁になると効いてくる。
※ `petitions()` は RNG を消費しないことは実測で確認済み（決定性は壊していない）。

### 4-6【中】数の書式が画面ごとにバラバラ（同じ量なのに）

## 6. きまり（`panels/policy.js`）

### 6-1【致命】カード名にプレースホルダの「N」がそのまま出ている
sim 側 `CARDS` の name が `上位N%を派遣` `N歳以上は温存` `要人にN体を随伴`
`模擬戦にN%を割く` `団結がN%を切ったら降伏具申` `狩猟にN%を割く` `備蓄をN日分確保` `N%の家系を辺境へ`。

（UI 側 `cards.js` は `◯` を使っていたが、そちらは死にコード＝0-6。）
