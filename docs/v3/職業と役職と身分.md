# 職業・役職・身分の区別

**この3つは完全に別物。** 95個の一覧に混ざっていたので割った。

## 見分ける基準

> **「1つしかないか」**

村長は1村に1人＝**役職**。衛兵は何人もいる＝**職業**。

## 3つの違い

| | 職業 | 役職 | 身分 |
|---|---|---|---|
| **ファイル** | `jobs.csv` 74 | `posts.csv` 18 | `ranks.csv` 3 |
| **どう就くか** | 誰でも（ステの閾値次第） | **任命される** | **生まれで決まる** |
| **数** | 何人でも | **1つしかない**（または少数） | — |
| **兼ねられるか** | **村では兼業が普通** | 1人1つ | — |
| **努力値** | **積まれる** | 積まれない | 積まれない |
| **野心** | 変わらない | **上がる。下がらない**（A-16のラチェット） | — |
| **設計上の枠** | スキル | **ポジションランク** | **身分ランク** |

## これが効くこと

**役職は希少で、任命で決まり、就くと野心が積み上がる。**
オーナーが引き上げた者だけが危険になる（A-16）のは、**役職の側の性質**だった。
職業をいくら変えても野心は上がらない。

**職業は兼ねられる。** 村では1人が農夫であり大工であり自警団でもある。
専業になるのは町から。**「置く」という動詞の意味が段階で変わる。**

## 役職18（1つしかないもの）

## 判断に迷ったもの

- **司祭** … 1教区に1人なので役職に入れた。ただし聖職の階梯（学生→修道士→司祭→司教）の一段でもある
- **騎士** … 身分に入れた。軍の役でもあるが、**封を受けること**が本体なので
- **門番・衛兵・牢番** … 何人もいるので職業。**役職ではない**
- **徴税吏** … 何人もいるので職業。憎まれ役
- **裁判官・外交使者・異端審問** … 複数いてよいが**任命される**ので役職

## 残っている宿題

**職業ステ.csv は95行のまま**（職業74＋役職18＋身分3が混ざっている）。
役職と身分は「ステを使う」の意味が違うので、**割り直すか、そのままにするか**の判断が要る。

- 職業 … **その仕事をするのに要るステ**
- 役職 … **その役を務めるのに要るステ**（＋任命される条件）
- 身分 … ステで決まらない（生まれ）
